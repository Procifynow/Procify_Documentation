    Array of CC recipient identifiers (user_id, mobile number, or email address)

    Returns void

    Description

    Sets the carbon copy recipient list for the notification. The cc_list contains secondary recipients who will receive a copy of the notification. CC recipients are typically used for email notifications and are only applicable to email type notifications.

    Example

    notificationBean.setCC(["manager001", "supervisor@company.com"]);
