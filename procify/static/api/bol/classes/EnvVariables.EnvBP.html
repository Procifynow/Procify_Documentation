OnValidate

  • OnValidate(): Promise<any>

  • This method is can be overridden in entity file to write custom logic for validation of entity object. While overriding this method, validate the entity, if any validation failed, push the error to the errors array. ValidationError object should be used to push the error to the errors array. ValidationError constructor takes the following parameters - entity object, property name, error code, error message and error type.

    Returns Promise<any>

    nothing. This method is not expected to return anything.

    Example

    public async OnValidate(): Promise<any> {
     if(this.description == 'haha')
         this.errors.push(new ValidationError(this, "description","ERR_CODE", "Funny description not allowed", ErrorType.ERROR));
    }

deleteP

  • deleteP(): Promise<void>

  • Returns Promise<void>

    , on promise resolve does not returns anything.

    Description

    This deletes the entity, all the primary children also will be deleted recursively till the leaf node, removes from the entity set it belongs (loaded from) to. If it is a new entity this will be simply discarded, else and delete action is performed on DB/batch and the registered rules will be executed for ON_DELETE. All cascade deletions will go as one message per BO. This will mark is_deleted flag TRUE on message exchange so that it is deleted from server and other devices.

    See

    dirtyState returns DirtyState.DELETED or -1 for deleted obejct.

    Example

    await entity.deleteP(); // entity -> entity of an entity set

    Inherited from KloEntity.deleteP

fromP

  • fromP(): Promise<Object>

  • Returns Promise<Object>

    FromObject which is json representation / snapshot of old object.

    Description

    ‘from’ state of an entity is captured during the entity load. It returns the current loaded state of that object. FromObject will have only the properties of the current entity, that means to get the from state of a child relation entity you have to navigate till that entity object and call from. It returns FromEntity object. Transient properties, Relations and entity APIs are not accessible.

    Example

    console.log(entity.short_text); // "Old short text".
    entity.short_text = "New short text";
    console.log(entity.short_text); // "New short text"
    let old_data = await entity.fromP(); // returns snapshot of old object
    console.log(old_data.short_text); // "Old short text"

    Inherited from KloEntity.fromP
