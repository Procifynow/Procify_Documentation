# Unable to compile files (tsc not defined)

**Q: Unable to compile files, showing tsc not defined.**

**A:** If packages are not installed globally, typescript won’t be available for use.
For compiling files in private node(tsc -w), need to install typescript globally( npm install typescript -g)
