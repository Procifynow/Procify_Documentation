# Pre-Requisites

- [**<u>VS Code</u>**](https://code.visualstudio.com/) ≥ 1.95 (alway work on a latest version of vs code unless a particular version is asked to be used)

- **Node.js** [<u>v22.20.0(LTS)</u>](https://nodejs.org/en/download/archive/v22.20.0) ([<u>Windows</u>](https://nodejs.org/dist/v22.13.1/node-v22.13.1-x64.msi)/[<u>Mac</u>](https://nodejs.org/dist/v22.13.1/node-v22.13.1.pkg) )

- [**<u>Git</u>**](https://git-scm.com/) (latest)

- **TypeScript** ≥ 4.9.5 (dev dependency)

  - **Install TypeScript (v4.9.5 or later):  
    > **npm install -g typescript@^4.9.5  
    > TypeScript is required to compile the App’s .ts files. If you aren’t installing packages globally (i.e. you’re relying on a [<u>Local packages installation</u>](#enablingdisabling-local-package-installation)), you need to install TypeScript globally so you can run tsc -w to compile your code.

- In order to execute ProcifynowIDE, the workspace folder has to be opened and it has to be updated as a trusted workspace.

- Application user url: [<u>https://\<domain_Name\>/p6/\<Landscape\>/index.html</u>](https://maven36.com/Klarion/trunkqa/fs/u/index.html)

> Example: [<u>https://dev.procifynow.com/p6/Training/index.html</u>](https://dev.procifynow.com/p6/Training/index.html)

**Note:** URL should be applied according to the server in which the Procify IDE will be set up. URL must be accessible in your browser with a valid SSL certificate. **\[If not, contact the Admin Team\]**
