# Host File Entry

If you encounter issues with the application not opening in the browser, follow these steps:

- Open Command Prompt and type **ipconfig** to check your current IP address.

- Compare the IP address displayed with the one maintained in the hosts file.

- If the IP address in the hosts file does not match the current IP, update the hosts file with the correct IP address.

- After saving the changes, refresh the application and check if the issue is resolved.

- This will help ensure that the correct IP address is mapped for proper application functionality.

**Note: Maintaining a host file entry for procifynowide.com is required in order to open the private node’s url in the Browser. IP addresses change upon changing networks.Only one entry should be present.**

**E.g.: 10.1.1.101 procifynowide.com** and **10.1.1.152 procifynowide.com** are present, then only one needs to be maintained for the **current IP address**.

**Path: system hosts file (common)**

Format per line: IP_address \<whitespace\> hostname \[aliases...\]  
Example: 10.1.1.101 procifynowide.com

### Windows

- Get IP: open **Command Prompt** and run: ipconfig

- Hosts file path: C:\Windows\System32\drivers\etc\hosts

- Edit: run Notepad as Administrator then File → Open that path, or run an elevated shell and:  
  > notepad C:\Windows\System32\drivers\etc\hosts

### macOS

- Get IP: Terminal: ipconfig getifaddr en0 (replace en0 with en1 if needed)  
  > or ifconfig / ip -4 addr

- Hosts file path: /etc/hosts (alias: /private/etc/hosts)

- Edit: sudo nano /etc/hosts (or sudo vi /etc/hosts)

### Linux (Ubuntu, Fedora, etc.)

- Get IP: Terminal:  
  > ip addr show or short ip a  
  > or hostname -I for a quick list of IPs

- Hosts file path: /etc/hosts

- Edit: sudo nano /etc/hosts (or sudo vi /etc/hosts)
