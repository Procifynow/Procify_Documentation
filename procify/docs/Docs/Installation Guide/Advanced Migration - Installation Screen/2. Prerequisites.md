# Prerequisites

- **adm app needs** to be assigned to the user in the 6.0 framework version and upper versions.

- Installation Screen present in flavor **klarion_adm_client** which needs to be assigned in the user app to use this application.

- For a fresh system if an application wants to create all their tables by using the installation screen then **t_schema_def** is not required to be maintained.
