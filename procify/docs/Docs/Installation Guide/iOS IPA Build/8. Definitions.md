# Definitions

- What is **sudo -s:** It is used to get the root privileges ( read and write any files on the system, perform operations as any user, change system configuration, install and remove software, and upgrade the operating system and/or firmware ).

- What is **<u>cordova platforms</u>:** It will give you the list of platforms added to your project.

- What is **<u>cordova platform rm</u> ios:** It is used to remove the ios platform from the current project.

- What is the **<u>cordova platform add</u> ios@7:** It is used to add an ios platform from the current project. And **@7** is nothing but the iOS platform version.

- What is **<u>chmod -R 777</u> . :** It is used to give the full read/write/execute access; absolute permission to do whatever you need to do.

- What is the **<u>cordova plugin add</u> cordova-plugin-fcm-with-dependecy-updated:** It is used to add a plugin to a project and **cordova-plugin-fcm-with-dependecy-updated** is an fcm plugin.

- What is **--force:** It is used to add a plugin to a project by force.

- What is **--allow-root:** It is used to run cocoapods as root user.

- What is **pod install:** It is used to install cocoapods based upon Podfile configuration.
