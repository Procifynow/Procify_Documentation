### 3.3.2.Change the config file

- Go to config.xml. Open the XML file with **TextEdit** as shown in the image below.![Screenshot](./img/ios-ipa-build-image306.png)

- In the config.xml file,

<!-- -->

- **Orange highlight:** Bundle ID/App ID can be changed here.

- **Yellow Highlight:** This will be the Project Name.

- **Red Highlight:** This depicts the App description. App defining name.

> ![Screenshot](./img/ios-ipa-build-image364.png)

If you aren't making any changes, proceed with the build. However, if you're making any changes to the config.xml, be sure to modify and save it first.

### 3.3.3.Remove the platform

- Put the following command in the terminal window.

<!-- -->

- Orange: **sudo -s** current directory to root directory.

- Green: **chmod -R 777** .: This gives the read and write access

- Blue: **Cordova platforms:** when you want to check the platform details.

- Yellow: **Cordova platform rm ios**: this is for removing the platform.

> ![Screenshot](./img/ios-ipa-build-image370.png)
>
> **Note:** After entering **sudo -s** in the terminal, you'll be prompted for a password. Enter the system password in that field (Highlighted with red).

## 3.4.Create IPA file

### 3.4.1.Change the archive type

- As shown below, navigate to the **Scheme screen.**

> ![Screenshot](./img/ios-ipa-build-image356.png)

- Change the **Archive build configuration** to "Debug" as shown below, then click the **close** button.

### 3.4.2.Archive and create the IPA file

- Click on **Archive**.

> ![Screenshot](./img/ios-ipa-build-image356.png)

- Click on the **Distribute app.**

> ![Screenshot](./img/ios-ipa-build-image446.png)

- Select the **Development** option and click the **next** button.

> ![Screenshot](./img/ios-ipa-build-image330.png)

- Select all compatible device variants from the list and click on the **next** button.

> ![Screenshot](./img/ios-ipa-build-image338.png)

- Select the **Automatically manage signing** and click the **next** button.

> ![Screenshot](./img/ios-ipa-build-image288.png)

- Click the **Export** button to export to your folder.

> ![Screenshot](./img/ios-ipa-build-image451.png)

- Select the folder location and **export** it.

> ![Screenshot](./img/ios-ipa-build-image360.png)

- Check your folder; your IPA is ready.

> ![Screenshot](./img/ios-ipa-build-image265.png)
