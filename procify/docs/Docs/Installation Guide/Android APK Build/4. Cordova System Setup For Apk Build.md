# Cordova System Setup For Apk Build

## 2.1.Installation of java 21

### 2.1.1.Install java

- Get the Java MSI installer from the Admin team based on the version we need to install.

**Step 1 - MSI File :**

Double click the installer file (.msi). A setup screen will appear. Click on **Next**.

> ![Screenshot](./img/android-apk-build-image128.png)

- **Step 2 - Accept License:**

> Accept the license agreement and click on **Next**.
>
> ![Screenshot](./img/android-apk-build-image197.png)

- **Step 3 - Installation Path:**

> Keep the default installation path and click on **Next**.
>
> ![Screenshot](./img/android-apk-build-image187.png)

- **Step 4 - Ready to Install:**

> Click on Install button to start the installation of Java and enter the Administrator credentials to start the installation. **\[For Admin credentials, please contact the IT team\]**
>
> ![Screenshot](./img/android-apk-build-image118.png)
>
> ![Screenshot](./img/android-apk-build-image124.png)

- **Step 5:** Click on **Finish,** once it is installed.

> ![Screenshot](./img/android-apk-build-image151.png)

### 2.1.2.Set the JAVA_HOME path

- In the windows search bar, search for **“Edit the system environment variables”** and open it.

- Click on environmental variables and add the JAVA_HOME variable in the system variables.

> ![Screenshot](./img/android-apk-build-image25.png)

- Click on a new variable in the system variables and add the JAVA_HOME path.

  - Variable name: **JAVA_HOME**

  - Variable path: Installation path of java

> ![Screenshot](./img/android-apk-build-image91.png)

- Restart the command prompts / terminals to reflect the java changes.

### 2.1.3.Verification of JAVA

- Open the command prompt and check the java version by using the below command:**java –version**

> ![Screenshot](./img/android-apk-build-image125.png)

## 2.2 Nodejs Installation:

### 2.2.1.Install node

- Get the nodeMSI installer from the Admin team based on the version we need to install.

<!-- -->

- A wizard will guide you through the process, allowing you to proceed by clicking "Next" at each step.

> ![Screenshot](./img/android-apk-build-image135.png)

- Next we need to accept the license agreement

> ![Screenshot](./img/android-apk-build-image150.png)

- The wizard will now prompt you to choose a location to download the Node.js-related files and folders. The default path is: C:\Program Files\nodejs.

> ![Screenshot](./img/android-apk-build-image93.png)

- The wizard will display the items being downloaded. Once the download is complete, click "Next" to continue.

> ![Screenshot](./img/android-apk-build-image145.png)

- Some native modules require compilation using C/C++. To install all the necessary software dependencies, please select the checkbox.

> ![Screenshot](./img/android-apk-build-image183.png)

- This is the final step in the download process. Click "Install" to begin the installation.

> ![Screenshot](./img/android-apk-build-image147.png)

- Once the installation is completed, click on **Finish.**

> ![Screenshot](./img/android-apk-build-image120.png)

### 2.2.2.Verification of JAVA

- Now you can verify installation of node js by using command **node -v**

> ![Screenshot](./img/android-apk-build-image141.png)

## 2.4.Gradle Setup
