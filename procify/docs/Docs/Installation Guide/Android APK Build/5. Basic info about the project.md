# Basic info about the project

### 3.1.Adding or removing Platform to project

- Platform is the environment in which an app is going to be built. It can be Android, IOS, Windows, OSX, Electron etc.

- For this documentation we are only using the Android platform.

- For adding platform run command - **Cordova platform add android**

- For removing platform run command - **Cordova platform rm android**

<!-- -->

- By default cordova version decide which version of android platform to be added but if you want specific version of android platform to be added run below command

> **Cordova platform add android@\<android-version\>**

**Example : Cordova platform add android@13.0.0**

> **NOTE :You cannot add any version of android platform. The required version must be supported by the installed cordova version. For more information**

### 3.2.Adding or removing plugins

- A plugin is an add-on code which provides functionality to cordova app or more precisely cordova web view to communicate with native components or in easy words it is used to provide additional features to cordova app.

- There are various plugins , few example below

  - **Phonegap-plugin-barcodescanner** - to scan barcode

  - **Cordova-plugin-file-transfer** - to upload and download files

<!-- -->

- For adding plugin run command **cordova plugin add \<plugin-name\>**

- For removing plugin run command **cordova plugin rm \<plugin-name\>**

- **Example -**

  - **Cordova plugin add Phonegap-plugin-barcodescanner**

> **Note : Sometimes plugins are not compatible with dependent plugins . Then we have to use - - force at the end of command to add plugins forcefully.**

- Example: **Cordova plugin add Phonegap-plugin-barcodescanner - -force**
