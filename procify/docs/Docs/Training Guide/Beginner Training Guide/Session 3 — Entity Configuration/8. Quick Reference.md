# Quick Reference

## Naming Convention Summary

| **Item**             | **Convention**                | **Example**       |
|----------------------|-------------------------------|-------------------|
| Primary Relation     | pr\_\<child_entity_short\>    | pr_complaint_item |
| Non-Primary Relation | r\_\<entity_short\>           | r_customer        |
| Object Group         | Lowercase, descriptive        | complaint_types   |
| Object Type          | UPPERCASE_WITH_UNDERSCORES    | PRODUCT_ISSUE     |
| Status Value         | UPPERCASE                     | INPROCESS         |
| Status Group         | UPPERCASE_GROUP               | OPEN_GROUP        |
| ID Series ID         | id\_\<entity_short\>          | id_complaint      |
| ID Prefix            | Uppercase abbreviation + dash | CMP-              |
