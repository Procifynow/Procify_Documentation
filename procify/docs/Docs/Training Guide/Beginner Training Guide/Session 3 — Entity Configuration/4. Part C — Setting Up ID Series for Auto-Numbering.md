# Part C — Setting Up ID Series for Auto-Numbering

## D.1 — What Is an ID Series?

An ID Series is a platform-managed counter that automatically generates primary key values when a new record is created. Without an ID Series on complaint_id, a developer would need to generate unique IDs manually — which is error-prone and cannot produce readable, formatted numbers like CMP-00001.

| **ID Series Type** | **Description**                                                                                      |
|--------------------|------------------------------------------------------------------------------------------------------|
| Auto Number        | Returns an incrementing number. Combined with a Prefix pattern to produce CMP-00001, CMP-00002, etc. |
| GUID               | Returns a 32-character UUID. Good for distributed offline scenarios. Not human-readable.             |
| None               | No auto-generation. The developer or rule must set the key manually.                                 |

## D.2 — ID Series to Configure

| **Property** | **Type**    | **Company** | **Pattern/Prefix**              | **Start From** |
|--------------|-------------|-------------|---------------------------------|----------------|
| complaint_id | Auto Number | PROCIFY     | Prefix: P- (generates P-00001)  | 1              |
| complaint_id | Auto Number | MAVENTIC    | Prefix: M - (generates M-00001) | 1              |

## D.3 — Step-by-Step: Creating the ID Series

| **\#** | **Action**                 | **Detail**                                                                                                                                                                        |
|--------|----------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **1**  | **Select d_complaints**    | In the Data Studio tree, click on d_complaints.                                                                                                                                   |
| **2**  | **Go to Properties tab**   | Click the Properties tab in the Detail panel. Locate the complaint_id property row.                                                                                               |
| **3**  | **Open ID Series**         | Click the navigation right arrow (→) at the end of the complaint_id row. The ID Series dialog opens for this property.                                                            |
| **4**  | **Click Add**              | Click the Add (+) icon in the ID Series dialog. A new entry row appears.                                                                                                          |
| **5**  | **Fill ID Series details** | ID: idp_complaint \| Type: Auto Number \| From: 1 \| Prefix: P- \| Chunk Size: 100 \| Increment: 1 \| Scope: Global \| Description: Auto-number for complaint IDs with P- prefix. |
| **6**  | **Click Add**              | Click the Add (+) icon in the ID Series dialog. A new entry row appears.                                                                                                          |
| **7**  | **Fill ID Series details** | ID: idm_complaint \| Type: Auto Number \| From: 1 \| Prefix: M- \| Chunk Size: 100 \| Increment: 1 \| Scope: Global \| Description: Auto-number for complaint IDs with P- prefix. |
| **8**  | **Close dialog**           | Click Close on the dialog. The ID Series entry is saved.                                                                                                                          |
| **9**  | **Save**                   | Click Save in the Data Studio toolbar. The complaint_id property now has an ID Series configured.                                                                                 |

| **📘 ID Series Fields Reference (Procify Data Studio 7.0 User Guide — Section 3.0.1 Creating ID Series)**          |
|-----------------------------------------------------------------------------------------------------------|
| ID: Unique ID of the series. Naming convention: id\_ prefix, all lowercase. Example: id_complaint.        |
| Type: Auto Number = incremental counter. Most common for business records.                                |
| From: Starting number for the series. Use 1 to start from P-00001.                                        |
| Prefix: Text prepended before the number. P- produces P-1, P-2, etc.                                      |
| Chunk Size: Default 100. The server pre-allocates this many IDs per session (important for offline apps). |
| Scope: Global (default) — one counter shared across all users and tenants.                                |
| Pattern: Can be used to produce complex formats. For simple prefix + number, just use the Prefix field.   |
|                                                                                                           |

## D.4 — Testing the ID Series

| **\#** | **Action**              | **Detail**                                                                                                                                                                            |
|--------|-------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **1**  | **Open Data Browser**   | With d_complaints selected, click Test in the toolbar. The Data Browser opens.                                                                                                        |
| **2**  | **Create a new record** | Click Add (+ Execute → Add → select object_type). Leave complaint_id blank — the platform will fill it.                                                                               |
| **3**  | **Fill minimal fields** | complaint_desc: Test auto-number \| priority: Low. Click Save.                                                                                                                        |
| **4**  | **Verify**              | The complaint_id column should show P-00001 for Procify and M-0001 for Maventic (or the next available number). If it shows a blank or an error, revisit the ID Series configuration. |
