# Session 3 Assignment

## Mandatory Tasks

Repeat all the actions performed in the session 03

## Exploration Task (Optional — Bonus)

- Create a d_complaint_voices record for an existing complaint via the Data Browser. Verify the voice record is linked to the complaint via the ticket_id field.

- In the Page Builder, add the s_complaint_voices section to the pa_comp_details tab area (similar to what you did for s_complaint_item). Bind it to the d_complaint_voices relation TransNode. Verify it appears in Full Preview.
