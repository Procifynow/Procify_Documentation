# Part A — BOL Entity Fundamentals: Creating the Remaining Entities

In Session 1, you created d_complaints using the Wizard. In this session, you create the remaining five entities step by step.

### A.1 — Business Object (BO) Hierarchy Explained

A Business Object is a hierarchical tree of entities. The root entity represents the BO. Child entities are dependent on the root via Primary Relations. Standalone entities are linked via Non-Primary (Aggregated) Relations.

| **📘 BO Hierarchy — Customer Complaints**<br/>d_complaints (Root Entity / BO)<br/>d_complaint_item (Root Entity / BO)<br/>d_complaint_voices (Root Entity / BO)<br/>d_complaints_attachment (Root Entity / BO)<br/>d_customers (Root Entity / BO)<br /> d_resp_team (Root Entity / BO) |
|---|

### A.2 — Key Attribute Reference

Primary Key (PK) — unique record identifier.  
Mandatory (❗) — field cannot be empty.  
Unique Key — no duplicate values allowed.  
Parent Key — auto-copies PK from parent entity into child on creation.

### A.3 — Creating d_complaint_item

Stores individual line items raised within a complaint.

| **1** | Open Data Studio → select customer_complaints\_\<prid\>.                                                     |
|-------|--------------------------------------------------------------------------------------------------------------|
| **2** | Click + → Entity. Entity ID: d_complaint_item. Click Create. Primary Key: item_id (Auto Number). Save.       |
| **3** | Go to Properties tab → +. Add: ticket_id (String), product (String — mark Mandatory), issue_observed (Text). |
| **4** | Save → Update Schema. Confirm success toast.                                                                 |

### A.4 — Creating d_complaint_voices

Stores discussion comments and voice records for each complaint.

| **1** | Entity ID: d_complaint_voices. Primary Key: voice_id (Auto Number).                                                                                                 |
|-------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **2** | Add properties: ticket_id (String), customer (String), responsible_team (String), sales_manager (String), rd_team (String), internal_comments (Text), app (String). |
| **3** | Save → Update Schema.                                                                                                                                               |

### A.5 — Creating d_complaints_attachment

Stores uploaded file attachments for a complaint.

| **1** | Entity ID: d_complaints_attachment. Primary Key: attachment_id (Auto Number).                           |
|-------|---------------------------------------------------------------------------------------------------------|
| **2** | Add properties: complaint_id (String), attachment (Attachment), attachment_type (String), app (String). |
| **3** | Save → Update Schema.                                                                                   |

### A.6 — Creating d_customers

A standalone master entity. NOT a child of d_complaints. Will be linked via Non-Primary Relation in Session 3.

| **1** | Entity ID: d_customers. Primary Key: customer_id (String — manually entered, not auto-generated).                    |
|-------|----------------------------------------------------------------------------------------------------------------------|
| **2** | Add properties: customer_name (String, Mandatory), customer_type (String), customer_category (String), app (String). |
| **3** | Save → Update Schema.                                                                                                |

### A.7 — Creating d_resp_team

Holds the list of team members who can be assigned as the responsible team for complaint resolution.

| **1** | Entity ID: d_resp_team. Primary Key: emp_id (String).   |
|-------|---------------------------------------------------------|
| **2** | Add properties: name (String, Mandatory), app (String). |
| **3** | Save → Update Schema.                                   |
