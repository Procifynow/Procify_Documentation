# Session Objectives

By the end of this session, you will be able to:

- Understand what a Business Object (BO) is and how entities are structured in a BO hierarchy.

- Create related entities (d_complaint_item, d_complaint_voices, d_complaints_attachment, d_customers, d_resp_team) with all required properties.

- Understand entity property types, key attributes, qualifiers, and data types.

- Understand the Procify Page Builder page hierarchy: Page → Page Layout → Page Area → Section → Control.

- Build a complaints page manually step by step using the Page Builder.

- Configure TransNodes and bind controls to entity properties.
