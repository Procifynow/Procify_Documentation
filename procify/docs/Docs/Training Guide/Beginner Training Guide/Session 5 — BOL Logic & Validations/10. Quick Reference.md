# Quick Reference

## Entity Hook Summary

| **Hook / Method** | **Signature**                         | **Called When**                                      |
|-------------------|---------------------------------------|------------------------------------------------------|
| onAfterCreate     | async onAfterCreate(): Promise\<any\> | After new entity record created in DB                |
| OnValidate        | async OnValidate(): Promise\<any\>    | On navigation if TransNode setActiveIf = Valid       |
| onDelete          | async onDelete(): Promise\<any\>      | After entity record deleted                          |
| set property      | set propId(new_value: Type)           | When property value is changed (client or server)    |
| get property      | get propId(): Type                    | When property value is read (returns computed value) |
