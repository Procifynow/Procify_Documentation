# Concepts Recap — What You Learned in Session 5

| **Concept** | **What It Does** | **Where Implemented** |
|---|---|---|
| Private Node | Local server instance. Routes browser endpoint's server calls to your VS Code for live debugging. | Procify Workspace Hub → Endpoints → Node ID |
| Entity .ts file | TypeScript class that extends KloEntity. The ONLY place for business logic. | workspace/apps/&lt;app&gt;/d_complaints.ts |
| onAfterCreate() | Server-side hook — fires after every new record is created. Used for auto-setting defaults. | d_complaints.ts |
| OnValidate() | Server-side hook — fires on navigation when TransNode setActiveIf = Valid. Blocks save on error. | d_complaints.ts + Page Builder TransNode |
| onDelete() | Server-side hook — fires after a record is deleted. Used for cascade cleanup. | d_complaints.ts |
| Setter (set property) | Interceptor for property writes. Computes derived fields. Must call this.s() to persist. | d_complaints.ts |
| Getter (get property) | Interceptor for property reads. Returns computed/formatted value. Used with transient properties. | d_complaints.ts |
| ValidationError | Error object pushed to this.errors array. ErrorType.ERROR blocks. WARNING allows with message. | OnValidate in d_complaints.ts |
| this.txn | KloTransaction — server context. Provides getUserID(), hasPermission(), hasCRUDPermisson(). | Inside any entity hook or rule |
| onPageModelReady | Controller hook that fires before data is fetched. Best for applying default search filters. | p_complaints.controller.ts |
| beforeQ (Query Rule) | Server-side hook — fires before a query hits the database. Used for row-level, role-based filtering. | q_complaints.ts |
| afterQ (Query Rule) | Server-side hook — fires after results return from the database. Used to reshape/compute values across the result set via getResults()/setResults().<br/>. | q_complaints.ts |
| Team Group (User Group) | Bundle of users assigned in one action to an App Collection, instead of assigning users one at a time. | Workspace Hub → Team Groups |
