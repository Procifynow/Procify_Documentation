# Session Objectives

By the end of this session, you will be able to:

- Understand the three types of Value Helps (VH Config, VH Query, VH Transaction) and when to use each.

- Create a VH Config for priority (Low / Medium / High / Critical) and nature_of_complaint, complaint_type fields.

- Create VH Query types that fetch data from d_customers and d_resp_team entities as picker suggestions.

- Understand what a KloQuery is and how it differs from a Runtime Entity query.

- Create two Saved Queries for the complaint list: My Complaints (filtered by assigned_to = current user) and All Open Complaints (filtered by s_status = OPEN).

- Assign Value Helps to entity properties in the Procify Data Studio.

- Update the UI — wire VH pickers and query-driven TransNodes into the p_complaints search and detail sections.

| **📘 What This Session Builds On**                                                                               |
|------------------------------------------------------------------------------------------------------------------|
| Session 3 configured Relations, Object Types, Status, and ID Series on d_complaints — the structural foundation. |
| Session 4 makes the user experience intelligent: instead of typing raw IDs, users get dropdowns and pickers.     |
| priority, complaint_type, nature_of_complaint → VH Config (fixed, app-managed lists).                            |
| customer_id, responsible_team → VH Query (dynamic, fetched from d_customers / d_resp_team).                      |
| Saved Queries → drive the different list views per role (My Complaints for Employee, All Open for Manager).      |
|                                                                                                                  |
