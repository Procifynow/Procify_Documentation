## Exploration Task (Optional — Bonus)

## Session 5 Preview — What Comes Next

| **📘 Session 5: BOL Logic &amp; Validations** |
|---|
| With VH and Queries in place, Session 5 introduces server-side business logic via the Private Node TypeScript environment. |
| Entity Lifecycle Hooks: onCreate, onValidate, onAfterSave, onDelete callbacks in the entity .ts file. |
| Validations: Mandatory field checks, custom error messages, business rule enforcement (e.g. planned_resolution_date must be after created_on). |
| Role-based logic: Using hasPermission() and hasCRUDPermission() to enforce who can transition complaint status. |
| Setting default values: Auto-setting s_status = 'OPEN' on complaint creation, auto-populating created_by from $SYSTEM.userID.<br/>Query Rules: beforeQ/afterQ callbacks on the query file — role-based row filtering and post-fetch computed fields. |
