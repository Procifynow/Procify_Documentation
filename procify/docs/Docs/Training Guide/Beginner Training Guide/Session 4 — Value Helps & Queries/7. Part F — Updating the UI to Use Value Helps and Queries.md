# Part F — Updating the UI to Use Value Helps and Queries

With all Value Helps and Queries configured in the Procify Data Studio, the p_complaints page now needs to be updated to use them. In this part you will:

- Update the search TransNode to use q_complaints_list as its data source.

- Add the quick-filter Saved Query buttons (sq_my_complaints, sq_all_open) to the search section.

- Verify that priority, complaint_type, customer_id, and responsible_team fields in the form render as dropdowns/pickers automatically.

- Set the vhType on customer_id and responsible_team controls to F4 (full picker dialog).

## F.1 — Update the TransNode to Use q_complaints_list instead d_complaints

Currently the search TransNode uses the default entity fetch. Switching it to q_complaints_list gives you control over sort order and allows future WHERE customisation.

| **\#** | **Action**                                | **Detail**                                                                                                                                          |
|--------|-------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------|
| **1**  | **Open Page Builder**                     | Navigate to Design Studio → Page Builder. Select your app. Click the Edit icon.                                                                     |
| **2**  | **Select p_complaints → Page Data Model** | Click p_complaints in the tree. Open the Page Data Model panel (right-side tab).                                                                    |
| **3**  | **Update the search TransNode**           | Delete the existing transnode (search → list → detail) and create the same with q_complaints instead of d_complaints and verify bindings once more. |
| **4**  | **Save**                                  | Click Save.                                                                                                                                         |

## F.2 — Verify VH Controls Render Correctly in Full Preview

After the build is triggered by the trainer (required for VH Config changes), verify the following in Full Preview:

| **\#** | **Action**                         | **Detail**                                                                                                                                                                                  |
|--------|------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **1**  | **Click Show Full Preview**        | Click Show Full Preview in the Page Builder toolbar.                                                                                                                                        |
| **2**  | **Verify priority dropdown**       | In the search filter bar, click the Priority field. It should render as a dropdown (ComboBox) showing: Low, Medium, High, .                                                                 |
| **3**  | **Verify complaint_type dropdown** | Click the Complaint Type field in search. Should show: Product Issue, Billing Issue, Delivery Issue, Service Issue, General.                                                                |
| **4**  | **Verify customer_id picker**      | Click a complaint row to load the details. In the detail form, click the customer_id (Employee ID) field. An F4 picker dialog should open listing all d_customers records with their names. |
| **5**  | **Verify responsible_team picker** | In the detail form, click the responsible_team field. The picker should show d_resp_team records (name + emp_id).                                                                           |
| **6**  | **Test a selection**               | Select a customer from the customer_id picker. Save the complaint. Verify the customer_id value is stored correctly (the KEY, not the display text) by checking the Data Browser.           |

| **💡 VH Type (F4 / ComboBox / AutoComplete) Override**                                                                                                 |
|--------------------------------------------------------------------------------------------------------------------------------------------------------|
| The Page Data Model assigns a default vhType to each property with a VH. You can override it per control in the Page Builder.                          |
| To change vhType on a specific control: Click the control in the tree → Detail panel → find vhType property → change to F4, ComboBox, or AutoComplete. |
| For customer_id and responsible_team: use F4 (full picker with search) since the lists may grow large.                                                 |
| For priority, complaint_type, nature_of_complaint: ComboBox is ideal (small fixed list, no search needed).                                             |
