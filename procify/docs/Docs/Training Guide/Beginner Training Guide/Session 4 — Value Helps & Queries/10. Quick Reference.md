# Quick Reference

## Naming Convention Summary

| **Item**          | **Convention**         | **Example**                  |
|-------------------|------------------------|------------------------------|
| VH Config ID      | vhc\_\<name\>          | vhc_priority                 |
| VH Query ID       | vhq\_\<name\>          | vhq_customer                 |
| Modelled Query ID | q\_\<name\>            | q_my_complaints              |
| Saved Query ID    | sq\_\<name\>           | sq_my_complaints             |
| Query parameter   | lowercase, descriptive | current_user                 |
| Desc Format       | :\<key\>--:\<display\> | :customer_id--:customer_name |
