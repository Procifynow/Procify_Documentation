# Part C — Creating VH Query Value Helps

## C.1 — What Is VH Query?

A VH Query fetches its suggestion items from a live entity or modelled query at runtime. Unlike VH Config (which is static metadata), VH Query shows records that are currently in the transactional database. This is the right choice for master entity pickers — where the data comes from d_customers, d_resp_team, or any other entity that can be searched and selected.

| **📘 VH Query Fields (Procify Data Studio 7.0 User Guide — Section 2.2.3 Value Help Detail)**                                                  |
|---------------------------------------------------------------------------------------------------------------------------------------|
| Entity/Query: The entity name or modelled query ID that returns the list of suggestions.                                              |
| Key Property: The property whose value gets STORED in the parent entity when the user selects an item. For d_customers → customer_id. |
| Display Text: The property shown to the user in the dropdown/picker. For d_customers → customer_name.                                 |
| Desc Format: How the display appears. Example: :customer_id--:customer_name shows ID followed by Name.                                |
| Icon: Optional — entity property that holds an icon URL to show alongside each suggestion item.                                       |
|                                                                                                                                       |

## C.2 — Step-by-Step: Creating vhq_customer

| **\#** | **Action**               | **Detail**                                                                                                                                  |
|--------|--------------------------|---------------------------------------------------------------------------------------------------------------------------------------------|
| **1**  | **Click + → Value Help** | Select entity and In the Data Studio toolbar, click + → Value Help. Value Help ID: vhq_customer \| Value Help Type: QUERY. Click Create.    |
| **2**  | **Open vhq_customer**    | Click vhq_customer in the tree. The Detail panel shows the VH Query configuration fields.                                                   |
| **3**  | **Set Entity/Query**     | In the Entity/Query field, select d_customers. This means the VH will execute a runtime query against d_customers to fetch suggestion rows. |
| **4**  | **Set Key Property**     | Key Property: customer_id. This is the value that gets written into d_complaints.customer_id when the user picks a customer.                |
| **5**  | **Set Display Text**     | Display Text: customer_name. This is what the user sees in the dropdown list.                                                               |
| **6**  | **Set Desc Format**      | Desc Format: :customer_id--:customer_name. This renders as 'CUST-001 -- Acme Corp' in the picker field once a value is selected.            |
| **7**  | **Save**                 | Click Save. vhq_customer is ready.                                                                                                          |

Perform the same for vhq_res_team

## C.4 — Assign VH Query to Entity Properties

| **\#** | **Action**                                   | **Detail**                                                                                                                                                                       |
|--------|----------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **1**  | **Select d_complaints → Properties tab**     | Click on d_complaints in the tree and go to Properties.                                                                                                                          |
| **2**  | **Assign vhq_customer to customer_id**       | Click the Value Help cell for customer_id. Select vhq_customer from the picker. Optionally mark Is Restricted = true to enforce that only valid customer records can be entered. |
| **3**  | **Assign vhq_resp_team to responsible_team** | Click the Value Help cell for responsible_team. Select vhq_resp_team.                                                                                                            |
| **4**  | **Save**                                     | Click Save.                                                                                                                                                                      |

| **💡 VH Type in the UI Control (KloControls 7.0 User Guide — KloInput)**                                                                                                     |
|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| After assigning a VH to a property, the KloInput control in the UI renders differently based on the vhType setting in the Page Data Model or the control's properties panel. |
| F4: Shows a full picker dialog when the user clicks the input — best for large datasets (d_customers with many records).                                                     |
| ComboBox: Shows a dropdown list — best for small fixed lists (priority, complaint_type).                                                                                     |
| AutoComplete: Shows suggestions as the user types — best for name-search scenarios.                                                                                          |
| The platform automatically uses the appropriate type based on the VH type. You can override it in the Page Data Model or the control properties.                             |
|                                                                                                                                                                              |
