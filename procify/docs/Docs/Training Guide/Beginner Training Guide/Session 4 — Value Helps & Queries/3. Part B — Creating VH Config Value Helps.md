# Part B — Creating VH Config Value Helps

## B.1 — What Is VH Config and When to Use It?

VH Config stores its values in the metadata database — the same database that stores entity definitions, page structures, and app metadata. These values are part of the application definition itself, not the transaction data. Use VH Config for lists that are defined once by the developer and rarely change: priority levels, complaint categories, nature classifications.

## B.2 — Step-by-Step: Creating vhc_priority

Follow these steps to create the priority VH Config. Repeat the process for vhc_complaint_type and vhc_nature.

| **\#** | **Action**                | **Detail**                                                                                                                                                                                                                                       |
|--------|---------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **1**  | **Open Data Studio**      | Navigate to Design Studio → Data Studio. Select your application customer_complaints\_\<prid\> from the dropdown.                                                                                                                                |
| **2**  | **Click + → Value Help**  | Select entity. Click the Add icon (+) in the toolbar. A menu appears — select Value Help. The Value Help creation dialog opens.                                                                                                                  |
| **3**  | **Fill VH ID and Type**   | Value Help ID: vhc_priority \| Value Help Type: CONFIG. Click Create. The VH appears in the tree on the left.                                                                                                                                    |
| **5**  | **Fill VH detail fields** | Description: Priority levels for customer complaints \| Key Property: key \| Display Text: text \| Desc Format: :text (shows only display text in the field, key stored internally).                                                             |
| **6**  | **Add VH Config items**   | Click the Add (+) icon in the VH Config Items section. Add Row 1: Key: LOW \| Display Text: Low. Add Row 2: Key: MEDIUM \| Display Text: Medium. Add Row 3: Key: HIGH \| Display Text: High. Add Row 4: Key: CRITICAL \| Display Text: Critical. |
| **7**  | **Save**                  | Click Save. vhc_priority is saved. Note: a build is required for this to appear in the UI — proceed to create all VH Configs first, then the trainer will trigger the build.                                                                     |

## B.3 — Assign VH Config to Entity Properties

After creating all three VH Configs, assign each to the corresponding property in d_complaints. This is done in the Properties tab of the entity.

| **\#** | **Action**                                            | **Detail**                                                                                                                                                     |
|--------|-------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **1**  | **Select d_complaints**                               | In the Data Studio tree, click d_complaints.                                                                                                                   |
| **2**  | **Go to Properties tab**                              | Click the Properties tab. Locate the priority property row.                                                                                                    |
| **3**  | **Set Value Help for priority**                       | Click the Value Help column cell for the priority row. A value help picker opens — type vhc_priority and select it. The VH ID is now assigned to the property. |
| **5**  | **Repeat for complaint_type and nature_of_complaint** | Assign vhc_complaint_type to complaint_type property. Assign vhc_nature to nature_of_complaint property.                                                       |
| **6**  | **Save**                                              | Click Save. All three properties now have VH Config assignments.                                                                                               |

| vhc_nature created — 4 items: TECHNICAL, LOGISTICS, COMMERCIAL, GENERAL.       |
| All 3 VH Configs assigned to their respective d_complaints properties.         |
