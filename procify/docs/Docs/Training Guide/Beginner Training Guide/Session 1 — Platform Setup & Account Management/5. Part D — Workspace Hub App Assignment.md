# Part D — Workspace Hub: App Assignment

With the application created and roles defined, you now assign users to the application with their respective roles. Without this step, a user cannot see or open the application even with a valid platform account.

### Assigning the customer complaints to user via employee role

| **1** | **Select the Employee Role**<br/>In the same Roles &amp; Users section, click on Employee. |
|---|---|

| **2** | **Add the Test User**<br/>Click Add. Find da_&lt;your_prid&gt; and select it. Click Save. |
|---|---|

Repeat the same for remaining roles.

### Verifying the Assignment

| **1** | **Open new profile / guest mode**<br/>Open a new Incognito / Private browser window so it does not use your developer session. |
|---|---|

| **2** | **Navigate to Your Landscape URL**<br/>Enter the landscape URL provided by the trainer. |
|---|---|

| **3** | **Log In as the Test User**<br/>Use test_&lt;prid&gt; and the password you set. |
|---|---|

| **4** | **Verify the Application Is Visible**<br/>The Service Request Management app should appear in the test user's menu. It will be empty — no Pages yet — but its presence confirms the assignment is correct. |
|---|---|

| **Troubleshooting — App Not Visible After Assignment** • Confirm the user is assigned to the correct role under the correct app. <br/> Check that the app is Active in the Workspace Hub. <br/> If the test user was already logged in before assignment, log out and log back in. <br/> Ensure the test user's account status is Active (not Locked). |
|---|
