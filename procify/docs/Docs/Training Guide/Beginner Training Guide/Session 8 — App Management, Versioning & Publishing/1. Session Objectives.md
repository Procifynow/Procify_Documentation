# Session Objectives

By the end of this session, you will be able to:

| **\#** | **Objective**                                                                                      |
|--------|----------------------------------------------------------------------------------------------------|
| 1      | Create the application menu using the Navigation Designer — matching the BRD menu structure exactly.       |
| 2      | Configure the HomePage Editor to add screen tiles for all three personas.                          |
| 3      | Understand the App Status Lifecycle: ACTIVE → RELEASED → DEPRECATED, and when to transition.       |
| 4      | Create an App Branch from an RELEASED version and understand the branch-to-version merge workflow. |
| 5      | Run Validate & Publish — identify and fix blockers before triggering a Full Build.                 |
| 6      | Transport the published application from DEV to QA using the Transport tool.                       |
| 7      | Perform an end-to-end smoke test covering all three personas (Employee, Manager, IT Team).         |

| **⚠ Important**<br/>Pre-requisite Check — Trainer will verify ALL of these before Session 8 begins.<br/>✔ p_complaints page is fully built: search, list, detail with all tabs populated.<br/>✔ Status badges (OPEN/INPROCESS/etc.) are rendered with correct colours.<br/>✔ Vienable is configured: Edit/Save/Cancel button visibility by Role, Mode, and Status Group.<br/>✔ Dashboard (p_complaint_dashboard) is set as Landing Page for all three roles.<br/>✔ formatPriority formatter renders priority with emoji labels.<br/>✔ OnValidate blocks V001–V005 violations correctly.<br/>✔ All three test users (emp_&lt;prid&gt;, mgr_&lt;prid&gt;, it_&lt;prid&gt;) can log in and see the application.<br/>If any item above is incomplete, resolve it BEFORE starting Session 8. |
|---|

| **📘 Reference / Tip**<br/>BRD Quick Reference for Session 8 (from Session 1 Part A)<br/>Menu structure: ONE item — 'Complaints' → p_complaints Icon: sap-icon://customer-and-contacts Roles: ALL<br/>Pages defined in BRD: p_home_page (home screen tiles) and p_complaints (main screen).<br/>p_complaint_dashboard = Landing Page (Session 5) — auto-loads on login. Does NOT need a menu entry.<br/>App ID format: customer_complaints_&lt;your_prid&gt; e.g. customer_complaints_pr0045 |
