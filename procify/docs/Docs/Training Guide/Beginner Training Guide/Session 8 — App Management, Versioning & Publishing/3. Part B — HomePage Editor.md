# Part B — HomePage Editor

## B.1 — What Is the HomePage Editor?

The HomePage Editor configures which screen tiles appear on the application's built-in Home grid — accessible via the Home (🏠) icon. This is separate from the Landing Page (p_complaint_dashboard configured in Session 5). The Landing Page loads automatically on login. The Home grid gives users tile-based navigation to frequently used screens.

| **📘 Reference / Tip**<br/>Three 'home' concepts — don't confuse them<br/>Landing Page (Session 5): Configured via Landing Page Settings. Auto-loads after login. Shows p_complaint_dashboard.<br/>HomePage Editor: Tile grid shown when user clicks the Home (🏠) icon. Configure p_complaints and p_complaint_dashboard tiles here.<br/>p_home_page (BRD): A screen defined in the BRD. Can be built as an additional home screen — not required for this session's delivery. |
|---|

## B.2 — HomePage Editor Fields Reference

| **Field**  | **Description**                                                         |
|------------|-------------------------------------------------------------------------|
| HomePageID | Unique ID for this tile. Convention: hp\_\<screen_short_name\>.         |
| Screen     | The Page ID this tile navigates to. Use VH to select.                   |
| Position   | Where the tile appears on the home grid. Use 'Body' for standard tiles. |
| Sequence   | Order of the tile. Lower = appears first.                               |
| Role       | Restrict tile visibility to specific roles. Leave blank = all roles.    |

## B.3 — Step-by-Step: Adding Tiles to HomePage Editor

| **1** | Open HomePage Editor<br/>Hamburger menu (☰) → App Builder → HomePage Editor.<br/>Select customer_complaints_&lt;prid&gt; from the App dropdown.<br/>Click the Edit icon (✏). |
|---|---|
| **2** | Add the Dashboard Tile<br/>Click Add (+).<br/>HomePageID: hp_dashboard<br/>Screen: p_complaint_dashboard (select via VH)<br/>Position: Body<br/>Sequence: 5<br/>Role: leave blank (all roles)<br/>Click Save (do NOT navigate away yet). |
| **3** | Add the Complaints Tile<br/>Click Add (+).<br/>HomePageID: hp_all_complaints<br/>Screen: p_complaints (select via VH)<br/>Position: Body<br/>Sequence: 10<br/>Role: leave blank (all roles)<br/>Click Save. |
| **4** | Save All<br/>Click the Save icon (💾) in the toolbar.<br/>Wait for busy dialog to close. Success toast confirms. |
| **5** | Verify<br/>Log out. Log in as emp_&lt;prid&gt;.<br/>Click the Home (🏠) icon.<br/>Two tiles must appear: 'Dashboard' and 'Complaints'.<br/>Click each tile — verify it navigates to the correct screen.<br/>Repeat with mgr_&lt;prid&gt; and it_&lt;prid&gt;. |
