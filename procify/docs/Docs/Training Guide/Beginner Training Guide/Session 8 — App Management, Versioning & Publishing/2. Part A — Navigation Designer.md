# Part A — Navigation Designer

## A.1 — What Is the Navigation Designer?

The Navigation Designer (also called Menu Builder per PROC-26419) is the tool you use to define the navigation structure visible to users in the hamburger menu of the application at runtime. Without a menu entry, users cannot navigate between screens — they would need to know URLs manually.

Access path: Running app → Hamburger menu (☰) → App Builder → Navigation Designer.

## A.2 — Menu Fields Reference

| **Field**       | **Description**                                       | **Rules / Notes**                                                                                                           |
|-----------------|-------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------|
| Menu ID         | Unique identifier for this menu item.                 | ONLY alphanumeric + underscores. NO hyphens ( - ). NO spaces. Case-sensitive. Wrong: mn-complaints. Correct: mn_complaints. |
| Target Page     | Page ID the menu item navigates to.                   | Use the Value Help (VH) icon to pick from existing pages. Do NOT type the page ID manually.                                 |
| Menu Text       | Label shown to the user in the hamburger menu.        | Keep it short. Title case. Localisation supported.                                                                          |
| Page Parameters | Optional JSON for navTo params (SS, QP, D, Mode).     | Leave blank for simple page nav. Not needed for the Complaints entry.                                                       |
| Menu Icon       | SAP icon URI displayed alongside the text.            | Format: sap-icon://\<icon-name\>. Must be a valid SAP UI5 icon name. Example: sap-icon://customer-and-contacts.             |
| Sequence        | Sort order in the menu. Lower number = appears first. | Use multiples of 10 (10, 20, 30) to leave room for future items.                                                            |
| Roles           | Restrict visibility to specific application roles.    | Leave BLANK = visible to ALL roles. Fill role IDs (comma-separated) to restrict.                                            |
| Test Navigation | Validates the menu item navigates correctly.          | Always click Test Navigation before saving — catches target page errors early.                                              |

## A.4 — Step-by-Step: Creating the Application Menu

| **1** | Open Navigation Designer<br/>In the running application, open the hamburger menu (☰ top-left). Go to App Builder → Navigation Designer. |
|---|---|
| **2** | Select the Application<br/>In the App dropdown at the top of the Navigation Designer, select customer_complaints_&lt;prid&gt;.<br/>Click the Edit button (pencil icon ✏). The menu table becomes editable. |
| **3** | Add a Header Group<br/>Click Add (+) → Add Header.<br/>Fill in:<br/>Menu ID: hdr_main<br/>Menu Text: Main<br/>Sequence: 10<br/>Roles: leave blank<br/>Click OK.<br/>(A Header groups child items visually in the menu.) |
| **4** | Add the Complaints Child Menu Item<br/>Select the hdr_main row in the table.<br/>Click Add (+) → Add Child.<br/>Fill in:<br/>Menu ID: mn_complaints<br/>Target Page: p_complaints (use VH picker)<br/>Menu Text: Complaints<br/>Menu Icon: sap-icon://customer-and-contacts<br/>Sequence: 10<br/>Roles: leave blank<br/>Click OK. |
| **5** | Test the Navigation<br/>Click Test Navigation on the mn_complaints row.<br/>p_complaints should open correctly.<br/>If a 'Page not found' error appears — check that the Target Page is exactly p_complaints (no typos). |
| **6** | Save<br/>Click the Save button (disk icon 💾).<br/>Wait for the busy dialog to close. A success toast confirms the menu is saved. |
| **7** | Verify with All Personas<br/>Log out and log in separately as emp_&lt;prid&gt;, mgr_&lt;prid&gt;, and it_&lt;prid&gt;.<br/>In each session, open the hamburger menu. The 'Complaints' item must be visible and navigate to p_complaints for ALL three test users. |

| **⚠ Important**<br/>Common Navigation Designer Mistakes<br/>Hyphen in Menu ID: mn-complaints causes the item to save but NEVER appear in the app. Always use underscore: mn_complaints.<br/>Typing Target Page manually: Always use the VH picker. Manual typos cause silent navigation failures.<br/>Saving without testing: Always click 'Test Navigation' before saving. It catches missing pages early.<br/>Role restriction accident: If the menu item is set to a specific role, other personas cannot see it. Leave Roles blank for all-role visibility. |
