# Concepts Recap — Session 8

| **Concept**                | **What It Does**                                                                  | **Where to Configure**                                          |
|----------------------------|-----------------------------------------------------------------------------------|-----------------------------------------------------------------|
| Navigation Designer (Menu Builder) | Defines hamburger menu structure. Roles blank = all users. NO hyphens in Menu ID. | App Builder → Navigation Designer → select app → Edit                     |
| Header + Child Item        | Header groups child menu items visually. Children point to actual screens.        | Navigation Designer → Add → Add Header, then Add → Add Child            |
| sap-icon://                | SAP UI5 icon URI format used in menu and controls.                                | Navigation Designer → Menu Icon field                                   |
| HomePage Editor            | Adds tiles to the Home (🏠) grid. Separate from Landing Page.                     | App Builder → HomePage Editor                                     |
| Landing Page Settings      | Sets auto-load screen after login. Configured in Session 5.                       | App Builder → Landing Page Settings                               |
| App Status: RELEASED       | Locks development. Enables transport. New version must be created from RELEASED.  | Procify Workspace Hub → My Apps → Status field                        |
| Branch                     | Parallel ACTIVE copy for next-phase development. Not transportable directly.      | Procify Workspace Hub → My Apps → Branch button (ACTIVE only)         |
| App Compare & Merge        | Compares two ZIP exports; per-component merge decisions; produces merged ZIP.     | Procify Workspace Hub → App Compare & Merge                           |
| Validate                   | Checks for errors. Safe — nothing deployed. Download XLSX report.                 | App Builder → Build & Deploy → Action: Validate             |
| Publish (Full Build)       | Validates then builds. VH Config changes REQUIRE Full Build.                      | App Builder → Build & Deploy → Action: Publish → Full Build |
| Transport (Pull)           | QA pulls RELEASED app from DEV. Requires config, host, transport_1 app.           | QA system → Deployment Center → App Migration                           |
