# Part D — App Branching and Merging

## D.1 — Why Branch?

A Branch creates a parallel ACTIVE copy of your application. Use it when you need to work on next-phase enhancements while the current version is being tested in QA. The branch is fully isolated — changes in the branch don't affect the main RELEASED version until you explicitly merge them.

| **Scenario**                                   | **Use Branch?**                                          |
|------------------------------------------------|----------------------------------------------------------|
| Bug fix on the current version in QA           | ❌ No — fix directly in main, create new minor version   |
| New feature development while current is in QA | ✅ Yes — branch from current ACTIVE version              |
| Experimental UI changes for client review      | ✅ Yes — branch lets you show without committing to main |

## D.2 — Step-by-Step: Creating a Branch

| **1** | Go to Procify Workspace Hub → My Apps<br/>Locate customer_complaints_&lt;prid&gt;. The app must be in ACTIVE status to create a branch. |
|---|---|
| **2** | Click Branch<br/>In the app detail view, click the Branch button (visible only when status = ACTIVE).<br/>The platform creates a new Branch Flavor automatically.<br/>The branch version appears in the My Apps list with a branch indicator. |
| **3** | Assign Users to the Branch<br/>Click the branch version to open its detail.<br/>Go to the Roles &amp; Users tab → click Edit.<br/>Assign ALL three test users and your developer account to their respective roles.<br/>⚠ Users are NOT copied automatically from the parent — you must assign them manually in the branch. |
| **4** | Develop in the Branch<br/>Open Data Studio or Page Builder.<br/>In the App dropdown, select the BRANCH version (not the main version).<br/>Make your changes. Save and test independently. |

## D.3 — Branch Merge Workflow (Summary)

When the branch is ready to be merged back into the main release cycle:

| **1** | Export Both ZIPs<br/>Procify Workspace Hub → Export section.<br/>Download ZIP of the main RELEASED version (Set 1) and the branch version (Set 2). |
|---|---|
| **2** | Open App Compare &amp; Merge<br/>Procify Workspace Hub → App Compare &amp; Merge.<br/>Upload Set 1 (main) as Left and Set 2 (branch) as Right.<br/>Click Compare. |
| **3** | Review the Differences<br/>The tool lists differences per component: entities, pages, queries, VH, menus, etc.<br/>For each difference, select which version to keep: Set 1 (main), Set 2 (branch), or a Custom combination. |
| **4** | Download Merged ZIP<br/>Once all decisions are made, click Download to export the merged ZIP. |
| **5** | Create New Version and Import<br/>In Procify Workspace Hub, create a new Major or Minor version from the current RELEASED main version.<br/>Import the merged ZIP into the new version.<br/>Run Update Schema, Full Build, and test before releasing. |
