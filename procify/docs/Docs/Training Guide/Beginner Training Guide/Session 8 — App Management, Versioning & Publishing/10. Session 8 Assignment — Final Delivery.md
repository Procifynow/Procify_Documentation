# Session 8 Assignment — Final Delivery

| **🎓 This Is the Final Session of the Beginner Training Track**<br/>The Customer Complaints Application is now a fully published, transportable product.<br/>All three personas (Employee, Manager, IT Team) have correct access, menu, and data visibility.<br/>After this assignment you will have built and shipped a complete enterprise application from scratch. |
|---|

## Mandatory Tasks

| **\#** | **Task**                                                                                                                                         | **Verify By**                                                                 |
|--------|--------------------------------------------------------------------------------------------------------------------------------------------------|-------------------------------------------------------------------------------|
| 1      | Configure the Navigation Designer with hdr_main header and mn_complaints child item pointing to p_complaints with icon sap-icon://customer-and-contacts. | All 3 test users see 'Complaints' in hamburger menu after login.              |
| 2      | Add HomePage tiles: hp_dashboard (Sequence 5) and hp_all_complaints (Sequence 10) for all roles.                                                 | Home (🏠) icon shows both tiles and each navigates correctly.                 |
| 3      | Run Validate → fix ALL errors → re-run until 0 errors.                                                                                           | Validation report shows 0 errors.                                             |
| 4      | Publish (Full Build) → wait for PUBLISHED status.                                                                                                | Logout and login — app loads correctly with all features working.             |
| 5      | Change app status to RELEASED in Procify Workspace Hub.                                                                                                | Status badge shows RELEASED. Edit icon is disabled.                           |
| 6      | Create a Branch from the ACTIVE version (if instructed). Assign all 3 test users to the branch.                                                  | Branch appears in My Apps list. Users can login to branch version.            |
| 7      | Transport to QA (trainer-guided). Assign users in QA.                                                                                            | App is ACTIVE in QA. All test users can login. p_complaints loads end-to-end. |
| 8      | Run the full 10-step smoke test above on DEV and on QA.                                                                                          | All 10 smoke test checks pass on both environments.                           |
