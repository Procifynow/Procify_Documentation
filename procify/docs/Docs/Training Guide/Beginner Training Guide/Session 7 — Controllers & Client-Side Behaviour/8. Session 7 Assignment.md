# Session 7 Assignment

| **⚠ Complete ALL mandatory tasks before Session 8**                                                          |
|--------------------------------------------------------------------------------------------------------------|
| Session 8 finalises the menu, home page, versioning, and publishing — the application must be fully working. |
|                                                                                                              |

## Mandatory Tasks

| **\#** | **Action**                          | **Detail**                                                                                                                                                         |
|--------|-------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **1**  | **Verify formatPriority formatter** | Full Preview: complaint with priority = VERY_HIGH shows '🚨 Very High — Immediate Action'. All 4 priority values formatted correctly.                              |
| **2**  | **Verify Vienable — Edit button**   | CLOSED complaint (COMPLETED group): Edit button absent. OPEN complaint (DISPLAY mode): Edit visible → click → disappears.                                          |
| **3**  | **Verify complaint_desc by role**   | emp\_\<prid\>: OPEN complaint → Edit → complaint_desc editable. INPROCESS complaint → Edit → complaint_desc is Show As Label. mgr\_\<prid\>: always Show As Label. |
| **4**  | **Verify responsible_team by role** | emp\_\<prid\> in EDIT mode: responsible_team is Show As Label (cannot assign). mgr\_\<prid\> in EDIT mode: responsible_team is editable.                           |
| **5**  | **Verify dashboard counts**         | p_complaint_dashboard shows live counts. Create/close complaints and reload — counts update correctly.                                                             |
| **6**  | **Verify screen size Vienable**     | Page Builder Preview In → Phone: grid shows only ticket_id, priority, s_status. Desktop: all columns visible.                                                      |

| **Session 8— App Management, Versioning &amp; Publishing**<br/>Duration: Full day \| Pre-requisite: Session 8 assignment verified |
