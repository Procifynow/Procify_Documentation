# Concepts Recap — What You Learned in Session 7

| **Concept**             | **What It Does**                                                                     | **Where**                                         |
|-------------------------|--------------------------------------------------------------------------------------|---------------------------------------------------|
| Controller TypeScript   | UI orchestration only: formatters, model reads/writes for display, dashboard counts. | workspace/apps/\<app\>/p_complaints.controller.ts |
| TransNode setProperty() | Updates a model property — triggers UI re-render immediately.                        | Controller function body                          |
| Vienable — Role         | Visibility by role ID: EMPLOYEE, EMPLOYEE_MANAGER, IT_TEAM.                          | Vienable Dashboard → Role column                  |
| Vienable — Status Group | Visibility by status group: OPEN, INPROCESS, ACCEPTED, COMPLETED.                    | Vienable Dashboard → Status Group column          |
| Vienable — Page Mode    | Visibility by DISPLAY/EDIT/CREATE.                                                   | Vienable Dashboard → Page Mode columns            |

| onPageEnter             | Controller hook fires after page data loads. Use for dashboard count calculations.   | p_complaint_dashboard.controller.ts               |
