# Part C — Controller APIs: Complete Reference

## C.1 — TransModel APIs (this.tm.*)

| **API**                           | **Signature**                                              | **Returns**     | **Description**                                                                                                                                      |
|-----------------------------------|------------------------------------------------------------|-----------------|------------------------------------------------------------------------------------------------------------------------------------------------------|
| getTN()                           | this.tm.getTN(relationId: string)                          | TransNode       | Get a TransNode by its relationId (as configured in Page Data Model). The gateway to all TransNode operations.                                       |
| commitP()                         | this.tm.commitP(success, failure, validate, isDisplayMode) | Promise\<any\>  | Save all dirty objects in the Transaction Model to the database. validate=true triggers OnValidate. isDisplayMode=true resets to DISPLAY after save. |
| rollBackTxn()                     | this.tm.rollBackTxn()                                      | Promise\<void\> | Revert ALL unsaved changes across all TransNodes back to last commit state. Used by Cancel button.                                                   |
| getAllTransNodes()                | this.tm.getAllTransNodes()                                 | TransNode\[\]   | Get all TransNodes on the page. Useful for bulk operations.                                                                                          |
| getTransactionFromTransnodeData() | this.tm.getTransactionFromTransnodeData(tn)                | any             | Get the raw transaction object from a TransNode. Advanced use only.                                                                                  |

## C.2 — TransNode APIs (this.tm.getTN('id').*)

| **API**               | **Signature**                              | **Returns**                         | **Description & Example**                                                                                                                                                        |
|-----------------------|--------------------------------------------|-------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| getData()             | .getData()                                 | KloEntitySet / KloEntity / KloQuery | Get all data from the TransNode. For list TransNodes returns the full entity set. Call .toArray() on the result to iterate. data = this.tm.getTN('list').getData();              |
| getActiveData()       | .getActiveData()                           | KloEntity                           | Get only the currently active (selected/highlighted) entity. data = this.tm.getTN('detail').getActiveData();                                                                     |
| getProperty()         | .getProperty(path: string)                 | any                                 | Get a single property value from the TransNode model. For list rows: getProperty('0/complaint_id') — index/propertyId format. For detail: getProperty('complaint_desc').         |
| setProperty()         | .setProperty(path, value)                  | TransNode                           | Set a property value — triggers immediate UI re-render. For transient/display properties. setProperty('t_open_count', '5').                                                      |
| setData()             | .setData(val, index?)                      | Promise\<void\>                     | Set the entire dataset for a TransNode. Replaces current data. Used after manual data fetch. this.tm.getTN('list').setData(entitySet);                                           |
| setActive()           | .setActive(index)                          | Promise\<bool\>                     | Set the active row by index. Triggers onArrive and updates all child TransNodes. await this.tm.getTN('list').setActive(0);                                                       |
| getActiveIndex()      | .getActiveIndex()                          | number                              | Get the current active row index. Useful before navigating away. idx = this.tm.getTN('list').getActiveIndex();                                                                   |
| getSelectedEntities() | .getSelectedEntities(ssID?)                | KloEntity\[\]                       | Get all checked rows in a grid section (multi-select). selected = this.tm.getTN('list').getSelectedEntities();                                                                   |
| executeP()            | .executeP()                                | Promise\<void\>                     | Re-execute the query associated with a query-type TransNode. Use to refresh data without full page reload. await this.tm.getTN('search').executeP();                             |
| applySortP()          | .applySortP(property, order)               | Promise\<void\>                     | Sort the TransNode data by a property. order: 'ASCENDING' or 'DESCENDING'. await this.tm.getTN('list').applySortP('created_on', 'DESCENDING');                                   |
| createEntityP()       | .createEntityP(json, successMsg, errorMsg) | Promise\<KloEntity\>                | Create a new entity and add to the TransNode. Triggers onAfterCreate hook server-side. await this.tm.getTN('list').createEntityP(\{complaint_desc: 'test'\}, 'Created', 'Failed'); |

## C.3 — Controller Navigation & UI APIs

| **API**            | **Signature**                                                   | **Description**                                                                                                                               |
|--------------------|-----------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------|
| navTo()            | await this.navTo(params, oEvent?)                               | Navigate to section or page. See Part D of Session 6 for full parameter reference.                                                            |
| setMode()          | this.setMode('EDIT' \| 'DISPLAY' \| 'CREATE')                   | Set the screen mode for all TransNodes bound to the detail area. Used by Edit button press event.                                             |
| saveTransaction()  | this.saveTransaction(successMsg, errorMsg, validate, resetMode) | Commit dirty data, optionally trigger OnValidate, and optionally reset to DISPLAY. Standard Save button handler.                              |
| refreshTransnode() | this.refreshTransnode(nodeId, mode, discard)                    | Refresh a named TransNode, set its mode, and optionally discard unsaved changes. Standard Cancel button handler.                              |
| showBusy()         | this.showBusy(msg?, id?)                                        | Show the platform busy/loading indicator. Use during async operations. this.showBusy('Loading...');                                           |
| hideBusy()         | this.hideBusy(id?)                                              | Hide the busy indicator. Always call in a finally block to ensure it's dismissed even on error.                                               |
| getAppData()       | this.getAppData()                                               | Retrieve AppData passed from the source page's navTo call. Returns the object passed as AppData: \{...\}.                                       |
| getPathFromEvent() | this.getPathFromEvent(oEvent)                                   | Get the model path string from a press event. Use with getTN().getProperty(path.split('/')\[2\] + '/propertyId') to get a specific row value. |
