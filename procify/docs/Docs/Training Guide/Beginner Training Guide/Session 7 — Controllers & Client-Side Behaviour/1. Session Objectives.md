# Session Objectives

By the end of this session, you will be able to:

Configure Vienable for all four dimensions: Screen Size, Page Mode, Role Rollup, and Status Group.

Understand and correctly use all five controller page lifecycle hooks.

Use the full TransNode and TransModel controller API set.

Implement client-side validation using expression binding and OnValidate controller integration.

Apply Procify coding standards for controller and entity files.
