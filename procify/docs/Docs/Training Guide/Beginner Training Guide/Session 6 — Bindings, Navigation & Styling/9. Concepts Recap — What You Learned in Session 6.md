# Concepts Recap — What You Learned in Session 6

| **Concept**                      | **What It Does**                                                                       | **Config Location**                              |
|----------------------------------|----------------------------------------------------------------------------------------|--------------------------------------------------|
| \$M path binding                 | Binds a control to a TransNode property value.                                         | Properties tab → Path field: \{\$M\>/detail/prop\} |
| Expression binding               | Inline ternary for conditional visible/enabled.                                        | Path field: \{= condition ? true : false\}         |
| navTo (Events tab / press event) | Navigates to a section or page on control interaction.                                 | Events tab → press → NavTo function              |
| Layout type = header             | Pins s_detail_header at top of pa_complaint_details.                                   | Detail panel → type = header                     |
| Layout type = section            | Sets pa_comp_details as scrollable body area.                                          | Detail panel → type = section                    |
| saveTransaction                  | Controller function. Saves dirty data, triggers OnValidate, resets to DISPLAY.         | press event inline function                      |
| refreshTransnode                 | Controller function. Reverts unsaved changes, resets mode to DISPLAY.                  | press event inline function                      |
| Status Group badge               | Format Rule Text Contains using group-level IDs: OPEN, INPROCESS, ACCEPTED, COMPLETED. | Style Classes tab → Format Rule                  |
| Quick Add style                  | Pre-defined style bundle for Grid or Card sections.                                    | Style Classes tab → QuickAdd                     |
