# Session Objectives

> By the end of this session, you will be able to:
>
> Understand and apply all four binding modes in Klobase: Value, Path, Parts (with formatter), and Expression.
>
> Write expression bindings for visibility, enabled state, and dynamic text.
>
> Write and wire formatter functions in the controller.
>
> Implement all navigation scenarios using navTo: section nav, page nav, key-based nav, query-param nav.
>
> Apply pre-defined and user-defined style classes to controls, sections, page areas, and layouts.
