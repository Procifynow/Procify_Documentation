# Note for the App Team Developers/Managers

There is an ask from Google Play store to upgrade our Mobile App to latest API versions and existing App will be stopped from 1-Sep-2025. To address this there is a Mobile App update also released and it works on Klobase version 7-2-208 or higher.

The new Mobile App version will be uploaded to Play store by 5-Sep-2025

\*\*\*Please make sure all the systems are upgraded to klobase version 7-2-208 or higher.

Reference: [<u>https://support.google.com/googleplay/android-developer/answer/11926878</u>](https://support.google.com/googleplay/android-developer/answer/11926878)
