| Feature | Adoption | Tool & Short Description |
| ----- | ----- | ----- |
| PROC-27362 OData BO Support – Deep Update (Header \+ Child updates in a single call) | No | **BOL** Extended OData support to allow deep update operations where both header and child entity data can be updated in a single API call. Previously, multi-level updates required sequential requests, increasing round trips. Clients can send nested JSON payloads containing parent entity properties along with child entity arrays. Child entities are automatically matched by parent key \- existing children are updated, and new children are created.All operations are committed in a single transaction with full validation support. This significantly reduces overhead for complex entity hierarchies. [Document Link](https://docs.google.com/document/d/1MK-jn3r0JLE08lMg0N1-YZMTqM9vP-7g-slPAiKCmT0/edit?tab=t.0#heading=h.ugxatbswrqr5) Status: Tested |
| PROC-27343 BOL Node 512 MB Stability Verification & Issue Resolution | No | **BOL** Verified stability of the BOL Node running under a 512 MB memory constraint and resolved all identified issues. Ensures the platform operates reliably within constrained memory environments for applicable deployments. Status: Done \- Closed |
| PROC-27366 Middleware: 1000 messages with no\_sequence=0 took 17 minutes to process | No | **BOL \- Middleware** Resolved a middleware throughput issue where 1000 messages with no\_sequence=0 took 17 minutes to complete against only 1 minute of actual processing time (16 minutes idle). Queuing and dispatch logic has been optimized to eliminate idle wait between message batches. Status: Tested |
| PROC-26465 Middleware: Default retry delay for deadlock/lock wait should be increased | No | **BOL \- Middleware** For the middleware retry settings for Inbound Messages, the RetryDelaySeconds default value has been changed to 1 second in the config.json file. Status: Tested User Guide link: [https\://docs.google.com/document/d/1oNQqNsgTLLFqtPn7914ggasXzJTDXc-oSo6QBYq9T6Y/edit?tab=t.0](https://docs.google.com/document/d/1oNQqNsgTLLFqtPn7914ggasXzJTDXc-oSo6QBYq9T6Y/edit?tab=t.0) |
