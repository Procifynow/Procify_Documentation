## **Important Notes**

The following manual steps are required after taking the Klobase 7-2-365 update:

- api.json has changed — WildFly restart is mandatory on all target landscapes

- VSIX has changed this sprint — VSIX pipeline run is required

- Template files have changed (index.html, package.json, index.ts) — update package.json and run npm install to update node_modules on all systems

- mf_7-0-18 update must be taken to all landscapes

- Restart WildFly after all changes have been deployed

- AI box landscape servers (aibox1, etc.) must be updated from the 133 system to the 135 system after release (langchain server update). For Business AI ([<u>PROC-28315</u>](https://procifynow.atlassian.net/browse/PROC-28315)), the new Qdrant environment variables (QDRANT_URL, QDRANT_COLLECTION_PREFIX, and QDRANT_API_KEY where required) must be added to the langchain server env file

- Remove the manually added idx_user_landscape index from madm_user_permissions on systems where it was added ([<u>PROC-27532</u>](https://procifynow.atlassian.net/browse/PROC-27532))

**Please review all release notes between your current version and the latest one, as there may be important changes or adoptions in the interim.**
