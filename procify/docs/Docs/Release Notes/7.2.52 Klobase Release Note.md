**For Application Team: [<u>App Utility Screen Enhancement</u>](#module-dev-tools)**

**Please be aware of the important changes to the Publish and Validate process. The validation of the flavor will occur first, and if any metadata inconsistencies are detected, validation errors will be triggered, preventing the build from proceeding. The build can only continue once all metadata issues are corrected. Additionally, validation for multiple flavors is now supported. This is a critical change, and the app team should take note, as they will not be able to build the application until all validation errors are resolved.**
