## **Important Notes**

The following manual steps are required after taking the Klobase 7-2-374 update:

- api.json has changed — WildFly restart is mandatory on all target landscapes

- Update the transport tool before taking the Klobase update

- VSIX has changed — update to VSIX 7.0.25 and run the VSIX pipeline

- package.json has changed — update package.json on all systems, then update node modules (Node.js version 22.23.3); on Business AI (aibox) landscapes, install the node modules while taking the update

- Template files (index.html, index.ts, etc.) have changed — update the theme to procify_default if not already updated; shared app change in index.ts

- The mm_protected_field config must be maintained by the infra team after the update and before the restart (required for encryption/decryption of data)

- Restart WildFly after all changes have been deployed

**Please review all release notes between your current version and the latest one, as there may be important changes or adoptions in the interim.**
