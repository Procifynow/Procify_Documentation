## **Important Notes**

**Post-Update Action Required – Dedicated Cache Master:**

Since the new dedicated Cache Master spawns a new process internally, after taking the Klobase update the following steps must be performed manually:

1.  Take Klobase update

2.  Stop the services

3.  Kill the Cache Master process

4.  Start the services
