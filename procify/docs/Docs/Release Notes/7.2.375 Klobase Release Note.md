## 1.1 What are the changes?

This Release contains new features/changes for the below areas of the framework.

| Area | Has Changed? | Adoption Required? |
| :---: | :---: | :---: |
| App Builder | No | No |
| Platform Settings | No | No |

| Feature | Adoption | Tool & Short Description |
| ----- | :---- | ----- |
| [PROC-28513](https://procifynow.atlassian.net/browse/PROC-28513): Screen performance degrades with prolonged use | No | **mTouch:** Improved screen performance so that screens no longer slow down the longer they are kept in use. **Status: Tested** |
| [PROC-30419](https://procifynow.atlassian.net/browse/PROC-30419): Error-change subscribers not removed | No | **KloTouch, Procify Data Studio:** Event subscriptions registered for error-change tracking are now released correctly, so they no longer accumulate across instances. **Status: Tested** |
| [PROC-30421](https://procifynow.atlassian.net/browse/PROC-30421): Scroll delegate cleanup and splitter pane navigation | No | **KloTouch:** Scroll delegate references are now removed from the screen scroll manager when a screen is destroyed. Navigating inside a splitter pane re-renders the section correctly. **Status: Tested** |
| [PROC-30422](https://procifynow.atlassian.net/browse/PROC-30422): Single-instance screen option | No | **KloTouch:** Adds an option to allow only one instance of a particular screen to be open at any point while using the application. **Status: Tested** |
| [PROC-30153](https://procifynow.atlassian.net/browse/PROC-30153): Planning Board Gantt date alignment after rerender | No | **mTouch:** Dates in the Planning Board Gantt chart now stay aligned with their Gantt bars after the chart is rerendered. **Status: Tested** |
| [PROC-30202](https://procifynow.atlassian.net/browse/PROC-30202): Filters respected in work center levelling and tree table | No | **mTouch:** Filters applied in the Planning Board are now respected in both work center levelling and the tree table. **Status: Verified by Application Team** |
| [PROC-30340](https://procifynow.atlassian.net/browse/PROC-30340): Date issue in Gantt PDF | No | **KloTouch:** Corrected the dates shown when the Gantt chart is exported to PDF. **Status: Tested** |
