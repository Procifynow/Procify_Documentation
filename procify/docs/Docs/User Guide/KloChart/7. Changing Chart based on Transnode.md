# Changing Chart based on Transnode

If chart doesn’t change, needs to call onDataChange() function on the control when triggering transnode’s data change manually.

*Needs to write code in the controller to trigger onDataChange(). Valid for both chats and report*

*Steps to attain the same:*

- *In Search add config*

- *add onAfterSearch event in the config(Eg:- onSearch())*

- *in the event call the control and add onDatachange()
  > *

***const oKloChart = \<KloChart\> this.getActiveControlById(\<controlid\>,\<subscreenid\>);***

***await oKloChart.onDataChange();***

*Eg:-
**public async onSearch()\{***

***//For recalculating the aggregate for KloReport on demand***

***const oKloReport = \<KloReport\> this.getActiveControlById('report01','section03');***

***await oKloReport.onDataChange();***

***//For recalculating the aggregate for KloChart on demand***

***const oKloChart = \<*KloChart*\> this.getActiveControlById('report01\_\_chart,' ‘section03');***

***await oKloChart .onDataChange();***

***
\}***
