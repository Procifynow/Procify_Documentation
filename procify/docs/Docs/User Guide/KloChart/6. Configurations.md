# Configurations

## Members

### (static) properties

**Properties**

| **Name**                 | **Type**            | **Attributes** | **Default** | **Description**                                                                                                                                                                                                        |
|--------------------------|---------------------|----------------|-------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **data**                 | object              | \<optional\>   | true        | Defines the data to be represented on the chart.                                                                                                                                                                       |
| **chartConfig**          | object              | \<optional\>   | true        | Defines the config for creating the chart                                                                                                                                                                              |
| **chartType**            | string              | \<optional\>   | XYChart     | Defines the type of chart. Example: column, line, bar, pie & area.                                                                                                                                                     |

| **height**               | sap.ui.core.CSSSize | non-bindable   | 100%        | Defines the height of the chart.                                                                                                                                                                                       |
| **width**                | sap.ui.core.CSSSize | non-bindable   | 100%        | Defines the width of the chart.                                                                                                                                                                                        |
| **title**                | string              | \<optional\>   | NULL        | Defines the title of the chart.                                                                                                                                                                                        |
| **series**               | Array.\<string\>    | \<optional\>   | \[\]        | Defines series of the data.                                                                                                                                                                                            |
