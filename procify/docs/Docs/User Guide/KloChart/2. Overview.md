# Overview

The KloChart is used for condensing large amounts of information into easy-to-understand formats that clearly and effectively communicate important points. This User Guide will help you with the usage of different properties of KloChart.

**Note:** There was an old control named **KloChartOld** which has been deprecated and subscreens using it have to be discarded as well so, new subscreens have to be constructed with the new KloChart
