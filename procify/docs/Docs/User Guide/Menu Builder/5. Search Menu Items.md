# Menu Builder — Search Menu Items

The Menu Editor table includes a search field above the menu tree to help locate a specific Menu ID or Menu Text quickly.

**How search works:**

- The search matches against both **Menu ID** and **Menu Text**, and applies partial/fuzzy matching — you don't need to type the exact full value.

- If your search term matches a **parent** menu item only, the filtered tree shows just that parent row (its children are not pulled into the result unless they also match).

- If your search term matches a **child** menu item, the filtered tree shows that child along with its parent, so you always retain context of where the item sits in the hierarchy.

**Note on the child-count indicator:** The number shown next to a parent menu item always reflects the **total number of children that parent actually has** in the full menu tree — not just the ones currently visible in your search results. This count does not change based on your search filter. For example, searching for a parent's name may show a count of 3 even though none of those 3 children match your search text and are therefore not shown below it.

**Tip:** To view all children of a parent, clear the search field (or expand the node directly) rather than relying on the search result or the count next to it.
