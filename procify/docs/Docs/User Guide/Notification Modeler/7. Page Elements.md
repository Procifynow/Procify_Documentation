# Notification Modeler — Page Elements

The elements on the Notification Modeler screen have been explained below:

| **Elements**       | **Description**                                                                                                                         |
|--------------------|-----------------------------------------------------------------------------------------------------------------------------------------|
| Template ID        | A Unique ID for each Notification.                                                                                                      |
| Description        | This is the description or implication for the Notifications.                                                                           |
| Module Type        | Notifications are used in two places, BOL and Workflow. To differentiate these two categories Module type has been introduced.          |
| Entity             | An entity is a data object created to store information about the entity in a table format. An entity can be created in the BOL Editor. |
| Entity Object Type | Object type is a unique identifier that helps understand the entities' possible behaviour.                                              |
| Channel            | It denotes the types of Notifications (e.g.: Email, App, SMS)                                                                           |
| FO                 | Owning app.                                                                                                                             |
