# Notification Modeler — Email Template User Guide

**Working with Template Variables and Rich Text Formatting**

### Understanding Template Variables

When creating email templates, you can use **template variables** to insert dynamic content. Template variables look like this:

\<%= variable_name %\>

**Common Examples:**

- \<%= rfx_no %\> - Shows the RFx number

- \<%= rfx_description %\> - Shows the RFx title

- \<%= new Date(rfx_closing_date).toLocaleString() %\> - Shows the closing date

- \<%= supplier_name %\> - Shows the supplier name

### 

### Important Rule: Formatting and Template Variables

DO NOT apply text formatting (bold, italic, underline, etc.) to template variables themselves.

The rich text editor inserts invisible HTML tags when you format text. These tags break the template variables and cause errors.

### Refer ejs official documentation - *https://ejs.co/#docs* for advanced ejs tag formatting options 

### Correct Usage

Example 1: Bold label, normal variable

Steps:

Type your text:

Closing Date: \<%= new Date(rfx_closing_date).toLocaleString() %\>

Select only "Closing Date:" (not the \<%= %\> part)

Click the Bold button

Result: Closing Date: \<%= new Date(rfx_closing_date).toLocaleString() %\>

Example 2: Variable within formatted sentence

Steps:

Type: The RFx \<%= rfx_no %\> has been closed.

Select "The RFx" (before the variable) and click Bold

Select "has been closed" (after the variable) and click Bold separately

Leave the \<%= rfx_no %\> part unformatted

###  Common Mistakes to Avoid

| **Wrong**                                       | **Right**                                        |
|-------------------------------------------------|--------------------------------------------------|
| Select entire line with \<%= %\> and click Bold | Select only the text labels, not \<%= %\>        |
| Type \<%= rfx_no %\> then format it             | Type it, leave it unformatted                    |
| Copy-paste formatted text containing \<%= %\>   | Paste as plain text, then format around \<%= %\> |
| Use bullet points that include \<%= %\>         | Put \<%= %\> on separate line or outside bullets |

### Step-by-Step: Creating a Formatted Template

Step 1: Switch to HTML View

If available, switch to HTML view to see your template variables clearly.

Step 2: Type your content with variables

RFx Title: \<%= rfx_description %\>

Closing Date: \<%= new Date(rfx_closing_date).toLocaleString() %\>

Step 3: Format carefully

- Highlight only "RFx Title:" (exclude the \<%= %\> part)

- Click Bold button

- Repeat for "Closing Date:"

Step 4: Verify in HTML view

\<strong\>RFx Title:\</strong\> \<%= rfx_description %\>

\<strong\>Closing Date:\</strong\> \<%= new Date(rfx_closing_date).toLocaleString() %\>

Step 5: Test before saving

- Use "Preview" button if available

- Check for error messages

### Troubleshooting

**Error Message: "Unexpected token '\<' while compiling ejs"**

**Cause:** You accidentally formatted a template variable.

**Solution**:

1.  Switch to HTML view

2.  Find the template variable mentioned in the error

3.  Look for HTML tags like \<strong\>, \<em\>, \<span\> inside \<%= %\>

4.  Remove the HTML tags from inside the template variable

5.  Reapply formatting only to the text outside \<%= %\>

### Quick Reference Card

| **Task**               | **How To**                                            |
|------------------------|-------------------------------------------------------|
| Make a label bold      | Select label text only (not \<%= %\>), click Bold     |
| Add new variable       | Type \<%= variable_name %\>, leave unformatted        |
| Format around variable | Format text before and after separately               |
| Fix error              | Switch to HTML view, remove tags from inside \<%= %\> |
| Verify template        | Check HTML view: no tags between \<%= and %\>         |

### Need Help?

If you see template errors:

1.  Switch to HTML View

2.  Check that no \<strong\>, \<b\>, \<em\>, \<i\>, \<span\> tags are inside \<%= %\>

3.  **Use HTML view for templates** - It's easier to see what's happening

4.  **Format first, add variables later** - Format your static text, then insert \<%= %\> variables in unformatted areas

5.  **Keep variables simple** - Don't try to format dynamic content; format the labels instead

6.  **Test with sample data** - Always test your template
