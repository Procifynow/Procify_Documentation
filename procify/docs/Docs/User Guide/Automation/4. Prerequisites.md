# Prerequisites

To initiate automation, whether on a private or public node server, you must replace the existing openUI5_1_120_27 within the closedmodules directory with the new [<u>openUI5_1_120_27</u>](https://drive.google.com/file/d/1GcO73tl--yI3r5wBtgB1IR1K0S4geNWf/view?usp=drive_link). Additionally, ensure the [<u>sap-ui-version.json</u>](https://drive.google.com/file/d/1Qa9TzR9_bv8aijOoQm0YNtZbFyXnTdsQ/view?usp=sharing) file is copied into closedmodules. Following these steps, if operating on a private node, restart the server and proceed with re-registration.
