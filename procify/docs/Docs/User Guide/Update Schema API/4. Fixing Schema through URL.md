# Fixing Schema through URL

**Note:** This API should be triggered, whenever there is an inconsistency between the entity metadata and the actual table in the DB. Also, in case of unexpected error from UpdateSchema/Validation of an entity through Data Studio.

Please run the below script in the console:

Kindly mention the **domain, landscape, flavor, and entity** accordingly.

If “is_config” is false, then it fixes the transaction table of the entity, else it fixes the status/config table of the entity in metadata DB.

1.  Entity level fix

(()=\>\{

//Maintain the DOMAIN, LANDSCAPE and params accordingly

const DOMAIN = 'dev.procify38.com';

const LANDSCAPE = 'tools_dev6';

let params = \{

landscape: LANDSCAPE,

fix_level: 'entity',

fv_list: \[\{fl:'eam',ver:'1'\}\],

entity_name: 'd_no_header',

is_config: false, // true or false

\}

const fixSchemaURL = \`https://\${DOMAIN}/node/\${LANDSCAPE}/core_fw_6-0/fixSchemaDef?meta=\${encodeURIComponent(JSON.stringify(params))}\`;

window.open(fixSchemaURL, '\_blank');

\})()

2.  App-level fix (It fixes all the entities inside the app)

(()=\>\{

let baseUrl = 'https://maven90.com/node/\<tools_dev\>/core_fw_6-0/fixSchemaDef';

let params = \{

fix_level: 'flavor',

landscape: '\<tools_dev\>',

fv_list: \[\{fl:'\<eam\>',ver:'\<1\>'\}\],

is_config: false, // true or false

\}

let finalUrl = baseUrl + "?meta=" + encodeURIComponent(JSON.stringify(params));

window.open(finalUrl, '\_blank');

\})()
