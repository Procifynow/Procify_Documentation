# Update Schema through URL

Please run the below script in the console:

Mention the domain, landscape, and flavor accordingly.

(()=\>\{

//Maintain the DOMAIN, LANDSCAPE and params accordingly

const DOMAIN = 'dev.procify38.com';

const LANDSCAPE = 'tools_dev6';

const params = \{

landscape: LANDSCAPE,

update_level: 'flavor',

consider: 'table', //table or index

is_config: false, // true or false

fv_list: \[\{fl:'wf_apps',ver:'1'\}\]//flavor list has to be in proper sequence i.e parent, child

\}

const updateSchemaURL = \`https://\${DOMAIN}/node/\${LANDSCAPE}/core_fw_6-0/createTable?meta=\${encodeURIComponent(JSON.stringify(params))}\`;

window.open(updateSchemaURL, '\_blank');

\})()

This step is required to encode the url.
