# How this property gets generated

This feature is auto-generated in theWorkspace Hub. It generates 3 unique characters on each app creation for maintaining **fo_alias** for entities. But, for different versions and branches, the same fo_alias will be maintained. It is maintained in the table named **madm_app** and **mf_fv** with a column **r_fo_alias.**
