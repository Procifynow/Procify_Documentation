# Overview

Upgrade and Transport application is used to EXPORT metadata of any application version and IMPORT onto any other application version. It also helps in merging two apps' metadata into one.

App inheritance is another powerful feature which is a part of this application, that allows users to manage the application hierarchy. Read more about App Dependencies here
