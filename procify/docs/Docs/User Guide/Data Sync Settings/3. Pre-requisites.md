# Pre-requisites

Users should understand how **query parameters**, **saved queries**, and **initial sync** work together.

To set this up:

1.  Create a **saved query** for the entity.

2.  Use this saved query to configure the **initial sync**, which loads the filtered data into the local database.

3.  Create a **local archive**, which removes data from the local database based on the archive conditions.

4.  Build is required after completing these steps.

A saved query must exist for the entity to maintain initial sync. The initial sync loads data defined by the saved query, and the local archive cleans up data according to the specified rules. Local archive triggers 3 mins after registration.
