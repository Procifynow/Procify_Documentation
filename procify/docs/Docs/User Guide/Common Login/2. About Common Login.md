# About Common Login

Common Login gives you the liberty to use a single login ID for multiple landscapes. Individuals will be given the option to choose the landscape they want to work in with one single ID.

**Note:** The list of landscapes comes from the **madm_user table**.

Also, the User should not assign a common landscape.
