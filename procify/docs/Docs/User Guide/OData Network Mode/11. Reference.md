# Reference

1.  Metadata URL: If your service root is [https://services.odata.org/V3/OData/OData.svc](https://services.odata.org/V3/OData/OData.svc) get the metadata from the [https://services.odata.org/V3/OData/OData.svc/\$metadata](https://services.odata.org/V3/OData/OData.svc/$metadata). You get the metadata URL from adding \$metadata to your service root.
