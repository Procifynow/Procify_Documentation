# Creating Property Types

Supported property types and oData to klarion property mapping are listed below:

**Property type map:**

| **ODATA**               | **KLARION**                                                                   |
|-------------------------|-------------------------------------------------------------------------------|
| Edm.Boolean             | Boolean<br />No conversion required (oData will provide proper boolean value) |
| Edm.Byte                | Integer(8)                                                                    |
| Edm.Date / Edm.DateTime | Date                                                                          |
| Edm.DateTimeOffset      | Date                                                                          |
| Edm.Decimal             | Decimal                                                                       |
| Edm.Double              | Decimal                                                                       |
| Edm.Duration            | String                                                                        |
| Edm.Guid                | String (length = 36), guid is 32 digits separated by 4 hyphens                |
| Edm.Int16               | Integer (16)                                                                  |
| Edm.Int32               | Integer (32)                                                                  |
| Edm.Int64               | Integer (64)                                                                  |
| Edm.SByte               | Integer (8)                                                                   |
| Edm.Single              | Decimal (n,7)                                                                 |
| Edm.String              | String / Clob                                                                 |
| Edm.TimeOfDay           | TimeStamp                                                                     |

Use these above references to create the appropriate domain, length and precision in Klarion.
