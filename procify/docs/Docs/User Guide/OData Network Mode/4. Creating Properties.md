# Creating Properties

**Rule to follow:**

1.  The entity property name should match exactly the oData properties (case sensitive).

2.  Create entity property for all the fields you are going to use from the oData service response. Create all property as in the service is all is used.

3.  All the primary keys in the oData service should be created and marked as primary keys.

4.  If any property is created which is not in the OData service, it has to be explicitly marked as **is_fw**.

**Note:** Qualifier properties are not supported.
