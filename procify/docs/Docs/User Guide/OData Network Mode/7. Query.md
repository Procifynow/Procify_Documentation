# Query

## Supported Features

### Where conditions

1.  Greater than & Greater than or Equal to (TESTED)

2.  Lesser than & Lesser than or Equal to (TESTED)

3.  NOT equal to (TESTED)

4.  Equal to (TESTED)

5.  Is null (TESTED)

6.  Is not null (TESTED)

7.  and (TESTED)

8.  or (TESTED)

9.  not (TESTED)

10. in, not_in (Experimental) based on the oData service support this may or may not work.

11. Like (Experimental) - will only support ‘%string%’,‘%string’, ‘string%’.

### Select class

1.  Partial select (selecting only a specific set of properties) (TESTED)

2.  Limit (TESTED)

### Order by

1.  Single property order is supported (TESTED)

2.  Multiple property order is supported (TESTED)

## Not Supported

### Select class

1.  Selection operators are unsupported (eg. SUM, MIN, MAX…)

2.  Aliases in selection are not supported.

### Other features

1.  Joins are not supported.

2.  Groupby is not supported.

3.  Having is not supported.

4.  Expandall is not supported.

5.  Native query is not supported.

### Query APIs

1.  GetCountP is not supported.

2.  groupByP is not supported.
