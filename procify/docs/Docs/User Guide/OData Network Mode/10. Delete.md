# Delete

Deletion of oData entry is supported by deleteP API.

**Note:** All the modifications which go in a single batch, are split into individual requests. Thus, if any request fails, requests which are successful before the failed request will be committed, and the rest will be rejected. Thus it is suggested that all saves go in individual commits.
