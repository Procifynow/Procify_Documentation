# About oData Adapter

This Adapter is mainly written in the scope of oData v4. As most of the features supported in oData v2 are retained in oData v4, it should work seamlessly with the oData v2 system.

## Features supported

oData provides standard features for CRUD operations on the system. This adapter provides the ability to communicate with any oData service via Klarion’s query and data manipulation features. However, some FW features are not supported for this oData network mode.
