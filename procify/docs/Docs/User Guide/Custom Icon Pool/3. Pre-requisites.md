# Pre-requisites

For registering custom icon pool, following are required:

1.  Any writable app (flavor)

2.  woff2 file and with icons to be registered (we are supporting only woff2 file extension)

3.  JSON file with Icon name and code points

4.  Either **woff2** file or **JSON** file size must not cross 19 MB.
