# Prerequisite

- The user should be assigned to **mf** to access this app.

- The user should be assigned to **uwl** to access this app.

- The workflow_admin flavor is no longer required, so users should be assigned only the **mf** flavor.

## Role assignment per environment

In the DEV environment, mf should be assigned as **TESTER**.

In the QA and PROD environments, mf should be assigned as **WF_ADMIN**.
