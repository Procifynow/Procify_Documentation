# Introduction To Workflow

## 1.1. What is a Workflow?

A Workflow is defined as a sequence of tasks that processes a set of data through a specific path from initiation to completion. It helps users to manage business processes efficiently.

Workflows are useful for processes that include several people, a sequence of tasks and coordination between different objects.

## 1.2. What is a Workflow Modeler?

This is a tool which allows users to create workflows for entities of a particular app, which get executed during runtime based on the action taken on the entity i.e. Create/Update/Delete.

To perform a complex business process such as ‘Employee Onboarding’, involves going through different steps. Users can define those steps in the workflow in the form of tasks and manage the sequence by connecting them.
