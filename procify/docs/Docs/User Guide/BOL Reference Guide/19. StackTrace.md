# StackTrace

A stack trace (also known as a stack backtrace or stack traceback) is an incredibly useful tool when it comes to debugging code. A stack trace shows the call stack and provides information on the query/transaction save that your code called.

The stack trace contains the information,status and list of all the queries and exits called during execution of a query or on transaction save.

**Information provided for Query in stack trace :**

- queryID

- queryParameters

- querySQL

- queryResult

- totalTime taken

**Information provided for Exits in stack trace:**

- entitykey

- eventType

- exitID,

- channelType

- exitClass

- resolved status

Stack trace information will be available in the transaction. Application developers can enable or disable the stack trace for an application.

Stack trace can be enabled by specifying the following url parameter “**enableStackTrace**” as true.

*\<URL\>/index.html?enableStackTrace=true#*

**Example:**

*transaction = new Transaction().getTransaction(“txn”));*

tansaction.stackTrace will return a stack trace of the queries and exits called in that transaction.

**clearStacktrace**: clearStacktrace method can be used for clearing the stack trace in the transaction.

**Example:**

*transaction.clearStackTrace();*
