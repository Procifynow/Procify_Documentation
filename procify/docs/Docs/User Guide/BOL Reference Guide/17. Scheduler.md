# Scheduler

KloScheduler is a program that schedules any operations that are required to be executed at any particular time period.

Schedulers are of two types namely, **server side scheduler** and **client side scheduler**.

**Server side scheduler** handles all events or tasks that are scheduled on the server side. This is generally used for monitoring tasks, notifying task completion, scheduling reports, and monitoring performance etc. This is also used to notify any open notifications or work orders to responsible users through app, email or sms.

**Client side scheduler** runs on applications and browsers. When an application is loaded after registration or after refresh in the browser, the scheduler automatically gets triggered and continuously runs from there until it faces any error or the application gets closed. Client side scheduler works both in online and offline mode. When the device is in offline mode it receives data or task reminders through push notification. The scheduler also clears unwanted data from devices (**Eg:** closed or completed notifications or work orders from client side databases).
