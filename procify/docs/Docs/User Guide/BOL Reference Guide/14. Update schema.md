# Update schema

Once an entity is defined in the meta model, run the Update schema to convert an entity to a physical database table. All the entity properties and the system fields as per entity definition are part of the Database table.

- Create a new table.

- Add new fields in a table.

- Add/Remove any field (existing) from the primary key set.

- Unused table: show unused (not defined in meta model) table list.

- Show unused (not defined in meta model) fields in a table.

- Datatype change of any field.

- Create and drop DB indices.

Run update schema on:

- All Entities (Landscape).

- One Entity.

Update Schema can be run in two ways:

- **Direct Run:** update the schema without preview.

- **Preview & Run:** see the changes list before updating the schema.

**Not supported:** Unused tables and fields are listed in the output. Deletion of table/fields to be done manually after verification.

- Drop table

- Delete field

Updated schema UI is part of Admin.
