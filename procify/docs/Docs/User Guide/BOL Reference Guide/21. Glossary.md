# Glossary

**A**

### Abstraction: This is used to hide background details or any unnecessary implementation about the data so that users only see the required information. It is one of the most important and essential features of object-oriented programming

### API: Application Programming Interface. A software intermediary that allows two applications to interact with each other. Each time we use an app like Facebook, send an instant message, or check the weather on our smart device, we are using an API

**B**

### Business Logic: The custom rules or algorithms that handle the exchange of information between a database and user interface

### Business Rules: Business Rules provide a true abstraction level and separation from the user interface. The business rule is not actively selecting user interface elements to collect input values, which allows flexible modification of the presentation and the rule itself. The same business rule can service any number of data controller views regardless of the view types

**C**

### Class: This is a blueprint that defines the variables and the methods common to all objects of a certain kind

### Commit: A command that is used for storing changes performed by a transaction

**D**

### Deprecated: This is the process of taking older code and marking it as no longer being useful within the codebase, usually because it has been replaced by newer code. The deprecated code is not immediately removed from the codebase because doing so may cause regression errors

**E**

### Entity: An entity is a real time object that is different from others. An entity can be defined using its attributes. They are a part of an entity

### Entity set: It is a collection of similar entities

**F**

### Flush Current Transaction: Flushing is the process of synchronising the underlying persistent store with persistable state held in memory. It will update or insert into your tables in the running transaction, but it may not commit those changes

**G**

### Getter: A getter is often associated with a setter. Together they are known as accessors. Getter returns the value of the private member variable

**K**

### kloBroker: KloBroker is also known as Middleware/ MW. It is a broker in between tenants, clients, and external systems

### kloTuner: It is an application used for configuration of and maintaining data under the object types. It maintains the number of users, number of roles as well as Business partners

### kloIDE: It is an integrated development environment for kloBase for developing applications and websites

**L**

### Lisp: Lisp is the second-oldest high-level programming language after Fortran and has changed a great deal since its early days, and a number of dialects have existed over its history. Today, the most widely known general-purpose Lisp dialects are Common Lisp and Scheme

**M**

### Method: A method in object-oriented programming (OOP) is a procedure associated with a message and an object. An object consists of data and behaviour; these compose an interface, which specifies how the object may be utilised by any of its various consumers

### Multi-Tenant Cloud: This is a cloud computing architecture that allows customers to share computing resources in a public or private cloud

### Meta Model: A metamodel or surrogate model is a model of a model, and metamodeling is the process of generating such metamodels. Thus metamodeling or meta-modelling is the analysis, construction and development of the frames, rules, constraints, models and theories applicable and useful for modelling a predefined class of problems

**O**

### Object: An entity that contains both attributes and actions is its object. It is defined by its life span, name and object identifier. Every object has two components: State and Behaviour

### ORM: Object Relational Mapping is a computer programming technique for converting data between incompatible type systems (Object to Relational), using object-oriented programming language

**P**

### Pagination: A storage allocation technique in which programs or data are divided into fixed length blocks called pages, main storage/memory is divided into blocks of the same length called page frames, and pages are stored in page frames, not necessarily contiguously or in logical order, and pages are transferred between main and auxiliary storage as needed

### Property: A property is a special class member, intermediate in functionality between a field (or data member) and a method

**Q**

### Query: A query is a request for data or information from a database table or combination of tables

### Query tree: It is an internal representation of an SQL statement where the single parts that it is built from are stored separately. These query trees can be shown in the server log if you set the configuration parameters debug_print_parse, debug_print_rewritten, or debug_print_plan

**R**

### Rollback: A transactional control language that is used to undo the transactions that have not been saved in the database

**S**

### Schema: A representation of a plan or theory in the form of an outline or model

### Setter: Setter is a method to set the value of any property of a private member variable. It is accompanied by Getter

### Stateless Model: In simple terms, a client program makes a request to an application server, which sends data back to the client. The server treats all client connections equally and saves no information from prior requests or sessions. A website that serves up a simple static web page is a good example of the stateless model

**U**

### UTC: Coordinated United Time. Prior to 1972, this time was called Greenwich Mean Time (GMT)
