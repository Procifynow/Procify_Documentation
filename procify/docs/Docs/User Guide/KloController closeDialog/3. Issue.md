# KloController closeDialog — Issue

Dialogs opened via the **KloController.openDialog** API should be closed using the **KloController.closeDialog** API, not the **sap.m.Dialog**'s **close** method. The **sap.m.Dialog's close** method should only be used when the dialog was opened via the **sap.m.Dialog.open()** method.
