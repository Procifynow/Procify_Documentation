# KloController closeDialog — Action Items for the Application Team

### Identify the dialogs opened using KloController.openDialog:

- Review the code to identify all instances where dialogs are opened using the **KloController.openDialog** API.

- Ensure that dialogs opened using **KloController.openDialog** are only closed using **KloController.closeDialog**.

### Replace incorrect close method usage:

- If you find any occurrences of **sap.m.Dialog.close()** being used on dialogs that were opened using **KloController.openDialog,** replace these calls with **KloController.closeDialog**.

### Dialogs opened using sap.m.Dialog.open() should use sap.m.Dialog.close():

- If the dialog was opened using **sap.m.Dialog.open()**, it is correct to call the **close()** method directly on the **sap.m.Dialog** instance.

### Ensure consistency:

- After making the changes, test your application to ensure dialogs open and close as expected without causing any inconsistencies.

- If there are any other custom dialog handling mechanisms or libraries involved, ensure that their behavior aligns with the standard usage of **KloController.openDialog and KloController.closeDialog.**
