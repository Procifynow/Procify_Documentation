# KloController closeDialog — Overview

It has been noted that some applications are using the sap.m.Dialog's close method to close dialogs that were opened via the KloController.openDialog API. This can result in inconsistencies and potential issues. To maintain uniformity and prevent problems, it is essential that the KloController.closeDialog API is used to close dialogs opened by the KloController.openDialog API.

**This document provides guidance on how to correct this issue and ensure that your code follows the correct API usage patterns.**
