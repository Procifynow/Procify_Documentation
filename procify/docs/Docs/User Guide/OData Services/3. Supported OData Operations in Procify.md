# Supported OData Operations in Procify

The following OData operations are fully supported and tested in the Procify platform:

## CRUD Operations

| **Operation**     | **HTTP Method** | **Description**                       |
|-------------------|-----------------|---------------------------------------|
| **CREATE**        | POST            | Create new entity with JSON body      |
| **READ (All)**    | GET             | Retrieve all entities from collection |
| **READ (By Key)** | GET             | Retrieve single entity by primary key |
| **UPDATE**        | PATCH           | Partial update of entity properties   |

## Query Options

| **Query Option** | **Description & Usage**                                                                                                                                                                                                                                                           |
|------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **\$filter**     | Filter results using logical operators<br />Example: GET https://stest.procifynow.com/odata/dev/flavor1/People?\$filter=Age gt 30<br />Example with multiple conditions:<br />GET https://stest.procifynow.com/odata/dev/flavor1/People?\$filter=Age gt 25 and Status eq 'Active' |
| **\$select**     | Select specific fields to return<br />Example: ?\$select=FirstName,LastName<br />GET https://stest.procifynow.com/odata/dev/flavor1/People?\$select=FirstName,LastName,Email,Department                                                                                           |
| **\$orderby**    | Sort results by field(s)<br />Example: ?\$orderby=LastName asc<br />GET https://stest.procifynow.com/odata/dev/flavor1/People?\$orderby=Department asc,LastName asc<br />GET https://stest.procifynow.com/odata/dev/flavor1/Orders?\$orderby=created_on desc                      |
| **\$top**        | Limit number of results returned<br />Example: ?\$top=10<br />GET https://stest.procifynow.com/odata/dev/flavor1/People?\$top=5&\$orderby=created_on desc                                                                                                                         |
| **\$count**      | Include total count in response<br />Example: ?\$count=true<br />GET https://stest.procifynow.com/odata/dev/flavor1/People?\$count=true&\$filter=Status eq 'Active'                                                                                                               |

## Supported Filter Operators

| **Operator** | **Meaning** | **Example** |
|---|---|---|
| **eq** | Equal to | Age eq 30<br />GET /odata/dev/flavor1/People?$filter=Age eq 30<br />GET /odata/dev/flavor1/Orders?$filter=OrderTotal eq 1500.00 |
| **ne** | Not equal to | Status ne 'Inactive'<br />GET /odata/dev/flavor1/People?$filter=Status ne 'Inactive' |
| **gt** | Greater than | Age gt 30<br />GET /odata/dev/flavor1/People?$filter=Age gt 30<br />GET /odata/dev/flavor1/Orders?$filter=OrderDate gt 2026-01-01<br /> GET /odata/dev/flavor1/Orders?$filter=OrderDate gt 2026-02-17T01:00:00.000Z<br /> <br /> For date supports both edm.Date and edm.DateTimeOffset format. |
| **ge** | Greater than or equal | Age ge 30<br />GET /odata/dev/flavor1/People?$filter=Age ge 30 |
| **lt** | Less than | Age lt 40<br />GET /odata/dev/flavor1/People?$filter=Age lt 40 |
| **le** | Less than or equal | Age le 40<br />GET /odata/dev/flavor1/People?$filter=Age le 40 |
| **and** | Logical AND | Age gt 25 and Status eq 'Active'<br />GET /odata/dev/flavor1/People?$filter=Age gt 25 and Status eq 'Active' |
| **or** | Logical OR | Status eq 'Active' or Status eq 'Pending'<br />GET /odata/dev/flavor1/People?$filter=Status eq 'Active' or Status eq 'Pending' |
| **not** | Logical NOT | not (Status eq 'Inactive')<br />GET /odata/dev/flavor1/People?$filter=not (Status eq 'Inactive') |
| **contains** | String contains | contains(Email, 'example')<br />GET /odata/dev/flavor1/People?$filter=contains(Email, 'procify') |
| **startswith** | String starts with | startswith(LastName, 'Sm')<br />GET /odata/dev/flavor1/People?$filter=startswith(LastName, 'Sm') |
| **endswith** | String ends with | endswith(Email, '.com')<br />GET /odata/dev/flavor1/People?$filter=endswith(Email, '.com') |
