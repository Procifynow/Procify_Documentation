# Overview

This document provides a comprehensive reference for OData services in the Procify platform. It clearly outlines which operations are supported, which are not supported, and provides practical examples for the application development team.

## Purpose and Scope

This user guide is designed to help application developers understand and correctly implement OData service calls It includes authentication mechanisms, supported query operations, error handling, and best practices.

## Service Information

| **Service URL Pattern** | https://\{customer\}.procifynow.com/odata/\{landscape\}/\{fvid\}/\{entityname\} |
|-------------------------|-------------------------------------------------------------------------|
| **Authentication**      | Bearer Token (OAuth 2.0)                                                |
| **Content-Type**        | application/json                                                        |
| **OData Version**       | OData v4.0                                                              |
