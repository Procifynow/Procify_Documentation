# Unsupported OData Operations in Procify

The following OData features are **NOT currently supported** in the Procify platform. Please avoid using these in your applications:

## Unsupported HTTP Methods

| **Operation**          | **Reason / Alternative**                                                                                                                             |
|------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------|
| **DELETE**             | **NOT SUPPORTED.** Procify does not support entity deletion via OData. Use alternative deactivation/soft delete mechanisms provided by the platform. |
| **PUT (Full Replace)** | Not supported. Use PATCH for partial updates instead.                                                                                                |

## Unsupported Query Features

| **Feature**             | **Reason / Alternative**                                                    |
|-------------------------|-----------------------------------------------------------------------------|
| **\$batch**             | Batch operations not supported. Submit individual requests.                 |
| **\$apply**             | Data aggregation is not supported. Perform aggregations on the client side. |
| **\$search**            | Full-text search is not supported. Use \$filter with contains() function.   |
| **Actions & Functions** | Custom actions and functions not supported. Use standard CRUD operations.   |
| **\$skiptoken**         | Server-driven pagination not supported. Use \$filter                        |
| **\$format**            | Only JSON format supported. XML, ATOM formats not available.                |
| **\$expand**            | Use flat entity and filters                                                 |

## Partially Supported Features

These features have limited support with specific constraints:

| **Feature**             | **Limitations**                                                         |
|-------------------------|-------------------------------------------------------------------------|
| **Date/Time Functions** | Only year(), month(), day() functions supported. No hour/minute/second. |
