# URL Parameters

## Domain

This depicts the domain name for which the build needs to be executed.

**Examples:** demo.com, aws.demo.com, maven.com, dev.procify.com, testing.procify.com

## Flavor_version

**Format:**

*\<flavor\>\_\<version\> (**underscore** between flavor and version)*

Parameter values can be **allFlavor** or any individual flavor name or multiple flavors separated by a comma.

| **Parameter Values** | **Functionality**                                                                                                    |
|----------------------|----------------------------------------------------------------------------------------------------------------------|
| allFlavor            | This will build all the flavors maintained in the flavor master table, excluding **account** and **core_fw flavor**. |

## build_type

build_type also known as task_type defines the behavior of flavor build. The build type defines the type of build being generated. The available options are below in the list ;

| **Build type** | **Functionality**                                                                                                          |
|----------------|----------------------------------------------------------------------------------------------------------------------------|
| devBuild       | Build files will be unminified i.e., the codes and script files are not minimized.                                         |
| prodBuild      | Build files will be minified i.e., minimizing code and script files.                                                       |
| checkStatus    | It will check the status of the current build process.(can also be used with an empty string to return the current status) |
| cancelPending  | It will terminate the build process, if multiple flavors are in the queue it will remove those flavors from the queue.     |
| applyChange    | It will identify duplicates, and inconsistencies in the metadata and align them.                                           |

**Note:** The default value of buildtype is **checkStatus**.

## Include_dependent (optional)

It provides all the dependent flavors' names and details for the specified flavor.

Supported values : 0 / 1

When the value is 1, the mentioned fv’s dependent flavors will be built. If the value is 0 it will not include the dependent flavors.
