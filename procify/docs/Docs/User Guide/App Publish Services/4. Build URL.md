# Build URL

When creating a build URL, the current klobase version (known as bol_version) must be included for the **core_fw** component. The bol_version indicates the version of the build running on the system and should be included in the URL to generate the correct build.

### Example

Suppose the current **bol_version** running in the system is **7-2-27.**

#### Previous Build URL

Before adopting the **current_bol_version,** the build URL would look like this:

https://dev.procifynow.com/node/EAM/core_fw_6-0/generateBuild?fv=my_test_6-0-1&buildtype=

#### Current Build URL (7-- onwards)

After updating to the current **bol_version (7-2-27),** the build URL format will be updated as follows:

https://dev.procifynow.com/node/\<landscape\>/core_fw\_\<current_bol_version\>/generateBuild?fv=\<flavor_name\>\_\<flavor_version\>&buildtype=\<typeofBuild\>

For the example provided with a **current_bol_version** of **7-2-27**, the updated URL would look like this:

https://dev.procifynow.com/node/EAM/core_fw_7-2-27/generateBuild?fv=my_test_6-0-1&buildtype=devbuild

**Note:
** To generate a build URL for the core_fw version:

1.  Retrieve the current bol_version from the system using clientGlobalObj.\_bolVersion.

2.  Update the URL with the correct core_fw version and the appropriate build type.

3.  Use the following format:
    > https://dev.procifynow.com/node/\<landscape\>/core_fw\_\<current_bol_version\>/generateBuild?fv=\<flavor_name\>\_\<flavor_version\>&buildtype=\<typeofBuild\>
    > This ensures the build URL points to the correct version and build type for the system.
