# Overview

App Publish is a service that reads the flavor details from a database, creates the necessary files for each app flavor, and then packages them into ZIP files. These ZIP files are ready for publishing the app on different platforms or for different audiences.

**It is recommended to follow this document, as the build URL is required only if the App Utility screen is not functioning.**

For instructions on using the app utility screen to build an app, please refer to [App Utility User Guide.](https://docs.google.com/document/d/1YW8ZVccJiTqwA-SSyrM0rFlRG-BkzdCgJmPctJZQHaE/edit?tab=t.0)
