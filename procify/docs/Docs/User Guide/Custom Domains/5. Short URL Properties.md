# Short URL Properties

The screen elements contain an edit button.

| **Properties** | **Description**                                                                                                                                                                             |
|----------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Short URL      | The short url key can be used as \<domain\>/s/\<short url\> to redirect to the long url.<br />Example: dev.procifynow.com/s/my_short_url                                                    |
| Long URL       | The long url to which the server will redirect. It is the actual URL for which the short URL has been created.                                                                              |
| Landscape      | The landscape for which the url will work.                                                                                                                                                  |
| App Data       | It is the custom JSON data for short URL. Currently, it is an optional field, we don't have any specs regarding this. It is the field to maintains particular app data for each url to link |
| Max Count      | Maximum number of times it can be accessed. After the max count is reached user will not be able to use the short URL which means the URL will be unlinked.                                 |
| Current Count  | The number of times the URL has been accessed presently.                                                                                                                                    |
| Goes Live on   | Time from which the short url will go live.<br />Until this time, the short url will not be accessible. After this time, it will be accessible.                                             |
| Expire on      | Time till which the short url will be live. After this time, the short url service will not be accessible.                                                                                  |
| Enabled        | This determines whether the URL is workable or not. If set to enable, it will work. When set to disable the link won't work.                                                                |
