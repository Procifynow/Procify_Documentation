# Overview

Applications developed need to be changed frequently to adapt to changing requirements as well as to add new functionalities.

This document will teach you how to enhance your existing applications in these scenarios.

## Pre-requisites

- One must be assigned a Cockpit app to get full access to the Workspace Hub.

- The Private Node setup should be done in the user's system.

- VS code should be available in your system.

## Steps

To enhance your application, you need to go through the following steps:

1.  Create a new version of the application

2.  Assign version to users (Automatic)

3.  VS Code initialisation

4.  Rollout of new application

5.  Publish the new version
