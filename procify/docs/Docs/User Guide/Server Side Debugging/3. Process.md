# Process

- For Server Debugging in the server, a ticket needs to be raised to the Infra team in Jira with the below information in the case of local/AWS servers.

  - Reason for debugging and ticket no of the issue if exists.

  - Timeline for debugging.

- In the case of customer servers, send a mail to the customer team to enable the http debugging port in the firewall.

- After providing the above information, approval from Piyush is required in the case of local/AWS servers.

- Once Approval is provided, the Infra will provide the access to debugging http port i.e. opening the http debugging port in the firewall in case of local/aws servers and the Customer team will allow the port for customer servers after taking the necessary approvals from their teams.

  - Infra Team → AWS servers

  - Infra Team → Local Servers

  - Customer Team → Customer servers

**Note:** AWS DEV Server debugging is possible only within the Jump server(AWS).
