# Overview

- Msg Enquire (KloSystem) is the sub-system of the kloregistry system. Msg Enquire (KloSystem) helps us know the number of systems running at present and also we get all information regarding the systems like; url, responsible person, Mac ID, and expiry date for our software in the Msg Enquire (KloSystem).

- The kloregistry system url must be publicly exposed and outbound needs to be enabled for accessing the klosystem URL.

- The Msg Enquire (KloSystem) URL also should be available to be accessed from the kloregistry system.
