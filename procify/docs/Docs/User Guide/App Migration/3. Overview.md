# Overview

Transport is a tool that deploys applications from one server to another. It is mainly aimed at deploying from a dev system to QA system and from QA to PROD system but can be used across any system.

Transportation of an application can be from:

- DEV to QA

- QA to PROD

- DEV to DEV

Steps involved:

- DEV to QA

  - **Setup** **-** Doing entries in tables like madm_app, madm_app_grp etc.

  - **Download-** Downloading and extracting application zips from the source.

  - **Update Schema -** Creating tables on the server for entities of that app.

  - **Finalizing -** Making the app ACTIVE so that everyone can use it.
