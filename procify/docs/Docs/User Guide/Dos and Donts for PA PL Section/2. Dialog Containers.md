# Dialog Containers

- Flexible columns should not be used inside the Dialog container.

- Object Page Should not be used inside the Dialog Container.

- In the case of Dialog footer buttons.

  - Action buttons should be added to Page Area’s section toolbar.

- In the case of Dialogs section level actions, action buttons should be added to the sections (which are rendered inside the Dialog).
