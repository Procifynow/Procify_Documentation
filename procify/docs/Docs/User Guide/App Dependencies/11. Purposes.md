# App Dependencies — Purposes

This screen can be used for;

1.  To summarize all the overridden elements along with their root elements in a tree hierarchy.

2.  To categorize the overridden elements (based on entity/page/menu etc.).

3.  To display and compare all the properties of the selected element with its parent flavor and other versions of the same flavor.

4.  To represent all the modified versions of the parent and child app and compare their element's properties.

5.  To navigate to the respective element's page.
