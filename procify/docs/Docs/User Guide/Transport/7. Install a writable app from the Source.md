# Transport — Install a writable app from the Source

Installing an app as writable means moving all the metadata from the source system to the target system. In this case, a user can start developing the currently installed app in the target system.

To install a writable app follow the steps below: 

**Step 1:** Navigate to the KloTransport screen.

**Step 2:** Click on the install detail button. 

**Step 3: Click on Install** 

Another screen will appear. From the available updates click on the install button.



**Step 4: Download writable app**

Click on the As writable button from the pop-up. Wait for the app to download. 

**Step 5:** Click on the **Finish** button.

### 5.1 Manual Source Code Movement 

App transport moves an app’s package and, for Writable installs, its metadata. It does **not** move the app’s source code. After installation, move the source code for each required flavor from the source landscape to the target landscape yourself.

#### **For a Read-Only installationStep 1:** Identify the flavor(s) and version just installed.

**Step 2:** Source code (Read-Only installs)

In a Read-Only installation, the source code is compiled and minified inside the zip files, which are moved during transport.

#### **For a Writable installationStep 1:** Identify the flavor(s) and version just installed.

> **Note:** Shared flavors are always moved as Read-Only, so they are not covered by these steps.

**Step 2:** Copy the source code to the target landscape

How you copy the source code depends on where it is maintained:

* **Source code maintained in Git:** Set up the Git configuration at the app level in the target landscape. No manual copying is needed.  
* **Source code maintained in Procify:** Set up a private node, manually copy the source code from the source landscape, and commit it in the target landscape.

**Step 3:** Build the app in the target landscape using **App Publisher** .

**Step 4:** Verify that the app opens and runs as expected.

> **Note:** Move the same version of the source code that you installed. If they don’t match, the app can behave unexpectedly in the target landscape.
