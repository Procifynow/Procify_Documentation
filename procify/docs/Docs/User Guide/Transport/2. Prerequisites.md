# Transport — Prerequisites

1. **Maintain this configuration in target’s config file. (present in \<landscape\>/kloconfig/config.json)**

 "mm\_klo\_online\_server": {

    "serverUrl": "https\://dev.procify38.com",

    "Landscape": "tools\_dev6",

    "username": "transport",

    "password": "1",

    "realm": "cloud\_app"

  },

Where,

 serverUrl is the source system’s url,

landscape \- source System’s landscape,

username \- one specific user should be there with transport flavor assigned to it.

password- password for that user

realm \- keycloak’s realm

2. **Maintain host file entry for the source system in the target system**  
3. **transport\_1** app should be assigned to the user.
