# Transport — Usage

Transport takes care of the following: 

* Maintaining entries of applications in tables like madm\_app,mf\_fl,mf\_fv etc.,  if any.

* Moving application zips across the system (QA or PROD system) and extracting them. 

* Getting the metadata of the application from the source DEV system and extracting it in the target DEV system. 

* Running automated scripts if maintained.

* Track manual scripts and run when required.

* Publishing Application. 

* Doing an updated schema on the application.
