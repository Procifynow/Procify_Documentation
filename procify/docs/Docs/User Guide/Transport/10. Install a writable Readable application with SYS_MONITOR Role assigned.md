# Transport — Install a writable/Readable application with SYS_MONITOR Role assigned

**Step 1**: Go to the account console app and assign your user to the SYS\_MONIOR role. If the role is not present then execute the below script to create a new role in the transport app.

[Script](https://docs.google.com/document/d/1zQGbdqfRIj3PwnZPGmyyO6CJ8rpv0Rx9MqXyfGepX7I/edit?usp=sharing)

**Step 2 :** follow these [steps](#4.-install-a-readable-app-from-the-source) to install an app.

**NOTE : Before installing the app make sure the Transport is assigned only as SYS\_MONITOR role to the current user.**
