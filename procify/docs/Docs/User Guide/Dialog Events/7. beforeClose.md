# beforeClose

## Overview

This event can be used to trigger a user defined function before the dialog box has closed.

One can refer to this documentation for further details : [<u>OpenUI5 Before Close Documentation</u>](https://sdk.openui5.org/api/sap.m.Dialog#events/beforeClose).

## How to use the feature

1.  In the events tab of Dialog config, select the beforeClose event and provide the name of the user defined function.  
    > ![Screenshot](./img/dialog-events-image6.png)

2.  Write the application logic in your controller file.
