# Workspace Hub — Handling Version and Branch.

1. ### How to check whether a branch or version is prioritized for users? {#how-to-check-whether-a-branch-or-version-is-prioritized-for-users?}

   Let’s take an example app and examine it. As you can see, both the version and branch are assigned to the user.

   Navigate to the user screen and the **'AssignedApps'** tab. There, you can see whether a branch or version is assigned, as shown below;  

2. ### How to assign Branch if version is assigned? {#how-to-assign-branch-if-version-is-assigned?}

   Users need to be removed from all roles from the version in order to get a branch.  

1. **Remove users from individual groups.**  Navigate to the **roles and users** section of the version and remove users from every role.  
2. **Remove users from User Collections:**

   Navigate to App Collections and check any App Collections with group type as **‘group’** is present. If present and user is mapped with that app group remove it from app group screen.

   The user is removed from the version and the branch is prioritized.

3. ### How to re-assign the version? {#how-to-re-assign-the-version?}

   Navigate to the **app Authorization** screen and select the user and add the required app to the user which will provide manager access of the app to the user.

   **Note:**  In order to use the App Authorization screen, the user needs to be assigned to the cockpit as superAdmin and not as any other role.
