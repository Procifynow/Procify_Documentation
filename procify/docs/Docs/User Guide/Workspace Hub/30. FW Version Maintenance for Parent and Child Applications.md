# Workspace Hub — FW Version Maintenance for Parent and Child Applications

1. All flavors within a single application hierarchy must use the same FW version to ensure compatibility and consistency.  
2. If any application in the hierarchy (that has dependencies with other flavors) requires a FW version upgrade, **all associated flavors within that hierarchy must also be updated to the same new FW version**.

**Example:**

 If `em4_6-0-1` plans to upgrade to a newer FW version (e.g., `6-1-0`), then every other flavor under the same hierarchy must be versioned accordingly and updated to use `6-1-0`.  
 However, independent flavors that do not belong to this hierarchy are not required to update their FW version.
