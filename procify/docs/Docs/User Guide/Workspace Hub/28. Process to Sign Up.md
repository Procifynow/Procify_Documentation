# Workspace Hub — Process to Sign Up

Sign Up with the user that we created and added to the user group having OTP config as **NONE** and user approval config as **User Approval**. 

**Note:** If no apps are assigned to the user, the signup process fails with an internal server error. Even after assigning the apps, signup starts working only after approximately one hour.

**Step 1:** Go to the browser url (like [https\://dev.procify38.com/p6/tools\_dev6/index.html](https://dev.procify38.com/p6/tools_dev6/index.html))

 Click on the Sign Up link. The following registration page will open. Click on **Sign Up Now**. 

You then need to fill in some credentials like Mobile number, BP ID and User ID. 

**Step 2:** Give the mobile number, BP ID and User ID (login ID) and click on **next**.



In case it fails, it will show **“Oops\!”.** (Approval required should show up currently not handled).

**Step 3:** Navigate to the user section from the manager's account. Here the status of the user will be as **“Approval required”**.



**Step 4:** Click on the **Approve User** button. A pop-up will appear. Click on the **OK** button.



**Step 4:** The user is now **Approved**. Now you can proceed with the signup. Again go to the signup page, fill in the details and click on the next button. A registration box will appear with password fields.



**Step 3:** Fill in the password and confirm the password then click on the Register button. This will take you to the **Terms and Conditions** dialog.



**Step 4:** Check the **Accept Terms and Conditions** checkbox and click on **Accept** Button.



It will start loading the application.
