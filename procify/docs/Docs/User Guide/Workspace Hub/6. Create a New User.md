# Workspace Hub — Create a New User

**Step 1:** Click on the Create button on the **Users** screen.



A **new detail page** will appear as shown below:

**Step 2:** In the detail screen fill in the user details. 

1. Title, Designation and Name should be as per your discretion.

   2. Mobile and email should be unique.

   3. A login ID will be used during app registration. 

   4. BP ID (Business Partner ID) segregates users based on the vendors they belong to. It is a mandatory field.

   5. Auth Code indicates a group of apps that manage the user/User Collections/app/App Collections for the particular app. It is a segregation process for users and apps.

**Step 3:** Click on the **Save** button. Users newly created will have the status as **New**. 

**Note:** Newly created users will be created in the common auth code group irrespective of the auth code while creating user and auth code provided while creating the user will tell that **users who are present in provided authcode group can only see the user in users screen.**

### User Creation via Excel Upload {#user-creation-via-excel-upload}

Another process to create a new user is via the Excel upload method.

**Step 1:** In the **Users** section, click on the Upload icon on the right-hand top of the screen.



**Step 2:** An Excel upload pop-up will appear. This pop-up will consist of a download template. It is recommended to download the template on your device; Fill in the required details and then upload it.

**Step 3:** Once you download the template. You save it in your desired location.

 **Step 4:** Open the Excel sheet and fill in the details in the template. **\[The status field was not mandatory hence you can keep it blank \]**

**Step 5:** Now in the portal, click on the **Browse** option. 

Fetch the file and upload it.  Once uploaded you will find the user names listed on the screen and the details auto-filled in the details section.

### Activate User {#activate-user}

**Step 1:** In the User Management Page, select a new user. 



**Step2:** Click on **Activate** User Button

The user is Activated and status will be changed to Active. This operation will help for users whose user\_is will be present in keycloak.



### Password Reset  {#password-reset}

The passwords for any active user can be changed or renewed using the **Reset Password** action button.

**Step 1:** In the User Management Page, select an active user. 

**Step 2:** Edit the screen. 

 **Step 3:** The Reset Password action button will appear on the screen. 

**Step 4:** Click on the action button. A pop-up will appear. Provide new and confirm password(mandatory ) and click on reset button 

Temporary password  will be created for user and on new registration of user use temporary password and create permanent password.

| Elements | Description |
| :---- | :---- |
| New Password | A new password can be set by the users by overriding the previous password.  |
| Confirm Password | The new password is to be rewritten for confirmation. |
| Temporary Password | This checkbox will be marked as default. The user will get a message about setting a permanent password.  If the checkbox is not marked then the password you have set will be set as a permanent one.  |
| Deboard User Endpoints | When one marks this checkbox it will deboard the user's endpoints and the user will be required to proceed with fresh registration.  |

### Add User to User Group {#add-user-to-user-group}

**Step 1:**  go to the User Collections tab of any user present in user detail and click on **Edit** button.

**Step 2** :  click on **Add** button and select User Collections in which user needs to be added and click on Add, user will be added to selected User Collections.

### Remove User From User Group {#remove-user-from-user-group}

**Step 1:**  go to the User Collections tab of any user present in user detail and click on **Edit** button.

**Step 2** :  select User Collections from which user needs to be removed and click on Remove, user will be removed from selected User Collections.

### Assign Apps from User {#assign-apps-from-user}

**Step 1:**  go to the Assigned Apps tab of any user present in user detail and click on **Edit** button.

**Step 2** :  click on Assign Apps From User button it will open a dialog. Select the user from whom apps should be assigned and click on **Assign** button.

**Step 3:**  select User Collections and click proceed .

**step3 :**  click on Save. user will get all the apps that are mapped with selected user individual App Collections and selected User Collections.
