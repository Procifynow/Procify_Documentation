# Workspace Hub — Remove User from the app

**Step 1:** Click On the **Edit button**. Select the users to be removed from the app.

**Step 2:** Click on the User from your required section (Application Role or System Role). Select the User you want to remove and click on the **Remove** button.

**Step 3:** Click on **save**.
