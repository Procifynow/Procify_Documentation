# Workspace Hub — Deboard endpoints of a user

Deboarding a user means removing the user. 

**Step 1:** Navigate to the endpoints tab in the user detail screen.

**Step 2:** Select the endpoints and click on the **“Deboard”** button. A pop-up will appear. Click on the **“OK”** button.

**Step 3:** Another pop-up will appear. Give a reason/remark for deboarding.

**Step 4:** Click on the submit button. Refresh the screen by clicking on the Refresh action button. The endpoint will get deboarded.

**Deboard user by using scheduler ➖**

## **Deboard Inactive Users** {#deboard-inactive-users}

* **Implemented a Scheduler for ADM Deboard Scenario from Scheduler.**  
* **Implemented a CRON Job Expression: 0 0 0 ? \* SUN \***  
* **Having a class name of**  deboardInactiveUsers  
* **With a priority as Normal and Is Long Running as true.**  
* **Two parameter it has1st. No\_of\_inactive\_days  {default :15}2nd. Channel\_type  {default : BOTH}**
