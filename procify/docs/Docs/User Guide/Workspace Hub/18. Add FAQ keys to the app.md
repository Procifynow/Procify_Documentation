# Workspace Hub — Add FAQ keys to the app

**Step 1:** Go to the **FAQ Keys** tab in the app detail screen.

**Step 2:** You can choose the existing keys or create new ones.

**Step 3:** To choose the existing keys, select the keys from the drop-down.

**Step 4:** To create a new key, click on the **add** button next to the dropdown.

**Step 5:** A pop-up will appear. Give a description and click on the **Create** button at the bottom.

**Step 6:** Click on the **Save** button.

#### **See Statistics Regarding the App** {#see-statistics-regarding-the-app}

Click on the **Artifacts** tab in the app detail section.

Here, one can see the number of screens, entities, and menus created in the app.

#### **Test the App using the test section** {#test-the-app-using-the-test-section}

Here, you can scan the QR code for downloading the app on your mobile device or use the app in your web browser using the link given on the screen under Web Application.
