# Workspace Hub — Activate/ Deactivate a User

**Deactivate a User (This restricts Restricted from accessing apps. The user account will become inactive)Step 1:** Go to the user detail page. Click on the **Edit** button.

**Step 2:** Click on the **Deactivate action**.



**Step 3:** A pop-up will appear.Provide the deactivation reason and click on deactivate.



Users' accounts will be Deactivate.



**Activate the user: (Lifting restriction from accessing the app. The user account will become active)Step 1:** Click the **Activate actionStep 2:** A pop-up will appear. Click on **OK**.



The user account will be Activated.
