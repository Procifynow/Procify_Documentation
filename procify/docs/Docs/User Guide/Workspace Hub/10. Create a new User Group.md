# Workspace Hub — Create a new User Group

**Step 1:** Go to the **User Group** screen and click on the **Create** group button present at the top. 

Add the ID. It is mandatory to fill in the ID as it suggests the Group name ID.

You can give the auth code from the dropdown available (this will be dependent on the currently logged-in user).

**No. of Logins Allowed Section \-** It specifies the number of devices/ browsers the users of the user group can log in to at a single time. After exceeding the limit, users will be deboarded from the previous endpoints.

**Registration Settings Section \-** It specifies the signup procedure for the users of that user group.

**OTP Config \-** It indicates the number of OTP required for the user to sign up.

	I. **None:** No OTP will be required.

	II. **ONE:** The user will have to provide the OTP sent to him.

	III. **TWO OTP:** The user will have to provide two OTPs (one sent to him and the other sent to his manager).

**Approval Config \-** This specifies the process via which the user will be approved before signup.

1. **User Approval:** Indicates that the manager of the user has to approve the user.  
2. **Automatic:** It indicates the user will automatically get approved at the time of sign-up.

**Notification Template ID:** Notification Templates are maintained in adm flavor.

Notification Template i.e is provided in the User Group is being used for sending invitations to users from apps screen via email sms.

**Save** the process.
