# Workspace Hub — Details

| Component/File | Changes |
| :---- | :---- |
| **Scheduler File** | **scheduler/deboardInactiveUsers.ts** |
| **Usage** | **If  any user is inactive after a given number of days in parameter, that user all endpoints will get deboarded.  To run this scheduler you just need to go to the job-instances page and import the job from cockpit and enable this job, This job will automatically run on given cron expression time. This scheduler will deboard all the users who are inactive since given days and it will delete the entry of all deboarded endpoints from madm\_ep\_apps. After successfully running off this scheduler, this returns the endpoints which got deboarded in log.** |
| **User Interface** | **No Changes from UI Side** |
