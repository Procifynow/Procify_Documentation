# Workspace Hub — Usage

Workspace Hub is a versatile app that serves various purposes such as follows: 

* User Creation and user details modification.

* User Group Creation; Addition/Removal of Users to/from any user group. 

* App Creation and app details modification. 

* Creation of App group; Add/remove the app to/from the App Collections. 

* Creation of application roles. 

* Assignment of apps to users via application/system roles.

* Removal of assigned apps for users.

* Map user group to app group.

* Get statistics related to the number of pages, menus, and entities created in an app.

* QR code for scanning apps.
