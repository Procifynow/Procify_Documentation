# Workspace Hub — Create a New Role

Each user can be provided with a designation or role. 

**Step 1:** In the  **Apps** section, once an App is created click on the app ID from the app list. 

 **Step 2:** Go to the Roles & Users tab, and click the **Edit** button. 

**Step 3:** Go to the application roles’ section toolbar and click on the “**\+**” Button, a new row will appear in the grid table.

**Step 4:** Add the role ID and description and click **Save**.

#### **User Assignment** {#user-assignment}

Users can be assigned to apps via roles. The roles can be as follows:

* **Application Roles:** These are mainly custom-created roles meant for the users who will use the application. Tester is the default role provided by the framework.  
* **System Roles:** These are the default roles provided by Framework. It will be 

  **Developer:** Users assigned as developers can create entities and relations in the particular app.

  **Manager:** Users assigned as managers can create new apps and assign users to those apps.
