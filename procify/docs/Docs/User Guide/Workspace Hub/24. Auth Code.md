# Workspace Hub — Auth Code

When a new user is created in the Workspace Hub, that user will be automatically assigned to an Auth Code named “**Common**”



**Note:** If your user is old, you might not be assigned to this Auth Code. 

### 21.1. Add Auth Code {#21.1.-add-auth-code}

**Step 1:** In the **Auth Configuration** you will find unique groups which will consist of specific groups of users. Click on the **Add** button.



**Step 2:** In the details section, create an **Auth code** for your group and **save** it.

**Step 3:** Next go to the **Users** section and add users with the help of the **Add** button.

**Step 4:** Select the users you want to add to your newly created group.

**Step 5: Save** the process.

**Note:** Please add your account (Manager) as well in the **Users** section otherwise the group will not reflect. **For example:** Here the **demo test** is my user name. Hence my account needs to be added to this group. Users present in any auth code group can see users, App Collections and User Collections having the same auth code.
