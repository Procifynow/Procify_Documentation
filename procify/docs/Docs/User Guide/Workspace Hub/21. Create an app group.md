# Workspace Hub — Create an app group

**Step 1:** Navigate to the **App Collections** screen.

**Step 2:** Click on the **Create Group** button. A new detail section will appear.

**Step 3:** Fill in the details 

**ID:** Depicts the app group name you are giving. This will reflect on the top of the screen. 

**Description:** Describe in a few words or phrases about your App group.

**Auth Code:** Select the Auth Code from the drop-down.

**Step 4: Save** the process.
