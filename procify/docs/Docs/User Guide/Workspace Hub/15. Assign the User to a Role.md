# Workspace Hub — Assign the User to a Role

**Step 1:** In the **Roles\&Users** tab of the **Apps** page, make the screen **editable** then click on the “0 users” link (or whatever the number of users it shows). 

**Step 2:**  A pop-up will appear.

 From the additional buttons of the third column’s section toolbar select **Add**.

**Step 3:** A pop-up will appear, search for the user and select it then click on **Add**. 

The selected user/s will be added to the app.

**Step 4:** Click on the **Save** Button. Users will be added to the app with selected roles.
