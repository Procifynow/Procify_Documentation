# Workspace Hub — Tools Assignment in QA and PRD landscapes.

Applications are categorized into three categories based on their purpose and ownership:

* Application Administrators \- used by application administrators to manage their applications  
* Monitoring Apps – Used by application/client teams to monitor their respective applications.

* Admin Apps – Used by application/client teams to manage and move their respective applications.

* Super Admin Apps – Used by the Infra team to manage and oversee the entire process.

  #### **App & User Group Mapping** {#app-&-user-group-mapping}

* App Collections and User Collections share the same name for consistency.

* Apps are maintained in App Collections, and corresponding User Collections are created with the same name.

* Users must be manually assigned to the relevant User Group by the team handling the landscape (QA/PRD).

| Category | App Group / User Group | Purpose  |
| ----- | ----- | ----- |
| Application admin Apps | app\_admin | For Application managing  |
| Monitoring Apps | Sys Monitoring | For monitoring respective applications |
| Admin Apps | App Management | For managing and moving respective applications |
| Super Admin Apps | Super Admin | For Infra team to manage the entire process |
