# Workspace Hub — Functionality of Endpoint

The endpoint is used to check and manage account log-in. Whenever any new user registers in the application, a new endpoint ID is created against that account. This can be checked in the endpoint section.

The Endpoint table consists of the following information: 

| Attributes | Description |
| :---- | :---- |
| Endpoint ID | It is a unique ID generated each time an account logs in |
| Login ID | This is the ID of the user. |
| Channel Type | This implies the channel or mode via which the user has logged in. It can be via a browser or device. |
| Status | Once a user does fresh registration they become a **New** user and then when they log in again the status becomes **Active** for them. Also if any user is **Deboarded** from the console it reflects here.  |
| Remark | It gives remarks relevant to the endpoint. |

When you click on any particular endpoint ID on the screen, it will open a detailed screen for that Endpoint ID.

In this detail screen, there are two sections:

1. Details  
2. About 

There is also a **Deboard** action button available on the right-hand side of the screen in case a user needs to be removed.

The **About** section, consists of  App Name, Role ID and version. The app name shows the number of apps that have been assigned to the user, for that particular Endpoint. Role ID puts forth the role this user is playing against each app and the Version shows the version, framework and Build Number. 

**Note** : To check the user activity, click on the check **login history** button. It will get navigated to a new screen to show logs of user login activity.
