# Workspace Hub — Best Practices

**Using User group and App group**:  usage of using user group and App Collections and mapping them is the best policy, Instead of assigning in the apps screen.

Example: Imagine an organization having 100 users to whom we need to assign two apps.

Without User Collections and App Collections: to add users we have to select 100 users to assign for each role to assign and viceversa for removal of users. It needs more effort.

With User Collections and App Collections:  to add users add apps into the App Collections with all the roles, add 100 users into User Collections. Map the user group with the app group and for removal just remove apps from App Collections. It needs less effort.

**Mapping user group and App Collections :**  go to App Collections tab in  user group detail and add app group to the user group or go to user group tab in any app group and add user group.

**How to maintain Hierarchy of users? :** 

 User with tester access need to be assigned to the tester role

Users with development access need to be assigned to the development role.

Users with manager access need to be assigned to a manager role.

If a user is assigned to all the roles, application roles will take precedence over developer role and manager role. In application role precedence will be taken based upon role\_precedence.
