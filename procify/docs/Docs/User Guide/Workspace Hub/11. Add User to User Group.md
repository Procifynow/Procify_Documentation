# Workspace Hub — Add User to User Group

**Step 1:**  Go to the **Users** tab that is present in the detail section of the **User Collections**. Click on the **Edit** button. 

**Step 2:** Click On the **Add** button.

Only user’s having the same auth code as the user group can be added to the user group.

A pop-up will appear.

**Step 3:** Select the users to be added to the particular group.

**Step 5:** Click on the **“Add”** button present at the bottom of the popup. 

Users will be added to the group.

**Excel upload and download for user group:-**
