# Workspace Hub — Map the user group to the app group

**Step 1:** Go to the **User Collections** tab in the app group detail screen.

**Step 2:** Click on the **Edit** button.

**Step 3:** Click on the **Add** button. A pop-up will appear with a list of App Collections having the auth code same as user group auth code.



**Step 4:** Select the required User Collections and click on the **Add** button.



**Step 5:** A user group will be added to the app group.



#### **appTest the app on a Mobile or Browser** {#apptest-the-app-on-a-mobile-or-browser}

In this screen, we have links to the application both for browser and mobile app. One can scan the QR Code in the Mobile app to run the application.



After creating entities and screens in the app, to make it get reflected in the device we publish an app. Click on the **Publish** button in the detail section of the app to publish the App.
