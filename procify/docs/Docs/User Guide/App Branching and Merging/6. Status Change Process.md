# Status Change Process

The Status Change Process is used for segregating the version and branch hierarchy process to identify each dependent app and sequence.

- **From Active, status can be changed to Released, Discarded.**

- **From Released, status can be changed to Deprecated.**

- **Deprecated: No users should be assigned to the App.**

- **Discarded: All the changes in the app will be discarded and not be considered in the main branch.**

- **Only from the Released version, a new version can be created.**

- **Only from Active Version, a new Branch can be created.**

- **Development can be only done in the App with Active Status.**

- **A branch can be ACTIVE, DEPRECATED, or DISCARDED.**
