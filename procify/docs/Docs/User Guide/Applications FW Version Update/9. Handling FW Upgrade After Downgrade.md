# Handling FW Upgrade After Downgrade

If the application was initially developed using the downgraded FW version and the latest FW version becomes available in the QA and production environments, the following steps should be followed:

1.  **Upgrade the FW Version in the Development Environment:  
    > **

    - Update the development environment to match the latest FW version used in QA and production.

2.  **Validate Application Compatibility:  
    > **

    - Test the existing application, which was developed with the previous FW version, to ensure it is compatible with the latest FW version.

3.  **Make Necessary Updates:  
    > **

    - Update the application code or configurations as needed to support the latest FW version.

4.  **Conduct Thorough Testing:  
    > **

    - Perform end-to-end testing in the development environment to ensure the application functions correctly with the upgraded FW version.

5.  **Transport the Updated Application:  
    > **

    - After successful testing, move the updated application to the QA and production environments.
