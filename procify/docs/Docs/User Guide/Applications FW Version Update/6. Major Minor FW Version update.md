# Major/ Minor FW Version update

Whenever there's a change in the major or minor versions of the FW platform, the apps that use the FW platform version need to be updated manually by the Application/Implementation team.

**For Example:**

We have an app named **eam_6.0.1** that uses **FW version 7_2_30**. A major enhancement is required for this app due to the recent update to the FW version.Therefore, we will create a branch for this app and all the adoptions will be done in this branch, using the latest **FW version 7_3_1**.

By reviewing the release notes for the FW update, the application team will learn about any adoptions or new features in the FW.

Once the enhancement is complete, the branch app will be merged with the latest version into a single major app version, resulting in a final product, such as **eam_6.0.3,FW version 7_3_1**. Once all necessary fixes and updates are made to the app, it will be moved to the QA branch/environment for testing.

If testing is successful, the updated app will be deployed to the production environment.

Note: [<u>How to do the app branching and merging is mentioned in the UG</u>](https://docs.google.com/document/d/1ulu71U7-0T6iVrZqulKEvVacEo-DZBf_m2Rf3hFh-sU/edit?tab=t.0).

When the FW version is upgraded(major/minor) and is deployed,the applications that work on the FW version should be changed to the latest version.For that to achieve,create a [<u>branch</u>](https://docs.google.com/document/u/0/d/1ulu71U7-0T6iVrZqulKEvVacEo-DZBf_m2Rf3hFh-sU/edit) and update the FW version as explained [<u>above</u>](#how-to-change-the-framework-version-for-apps). Once done with all the adoptions and changes, it is merged to the main branch and then the FW version is updated to transport it further to QA. Once the test is passed, the FW version will be updated in the application with the new FW version.

As shown in the above diagram, if the test fails, then the app will not be taking the FW update and it will downgrade to the most recent functioning version of FW to ensure everything functions properly.
