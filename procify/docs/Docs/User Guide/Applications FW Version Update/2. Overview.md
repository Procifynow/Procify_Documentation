# Overview

**Every Application / App version built on the Procify platform uses a FW/Platform version. The platform releases a new version every month with new features and bug fixes reported. It is recommended for users to stay updated with the latest version of the platform.**

**This document serves as a guide for users on the understanding of Framework version updation(upgrade/downgrade) for applications. If an app running on the latest Framework version requires adjustments, users can use this guide to revert to an earlier version. This process involves either upgrading or downgrading the FW version.**

**Note:Framework version can be changed only for ACTIVE Apps.**

**App FW version cannot be changed by users when it's in QA/production.**
