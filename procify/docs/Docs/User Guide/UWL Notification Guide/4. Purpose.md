# Purpose

## 2.1. Why is it used?

The Approver can see the requests/tasks and decide on the necessary actions to be taken for the tasks accordingly. The Requester, on the other hand, can see the updates or actions taken on the tasks or requests.

For Example: If a requester applies for a leave give the reason for the leave and the duration of the leave. Whoever is the approver for the request will see the request verify the reason and take necessary actions (like Approved or Rejected). The same way the UWL screen works but it can have different workflows.
