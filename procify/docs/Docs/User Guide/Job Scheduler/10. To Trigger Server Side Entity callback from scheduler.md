# To Trigger Server Side Entity callback from scheduler

To trigger server side entity callback, call addendpoint with endpoint id as ‘1’ and endpoint type as endpoint.

**Note: Below is the sample code;**

public async onExecute()\{

let txn = this.eventContext.getTxn();

let b = await txn.createEntityP('d_ver_tst',\{

name: 'pavan',

address: 'aadada'

\})

txn.addEndpoint('1' , EndpointType.ENDPOINT , ChannelType.BOTH,b);

\}
