# Debugging and testing Scheduler

Steps to debug:

1.  Create the Scheduler File for the job created in the Job screen.

2.  Save and Compile the file.

3.  Start the private node in Javascript debugger.

4.  Put debuggers where you want to debug(put debugger in the Scheduler file in src and also in cdn_app just in case).

5.  Start the job from the Job screen.
