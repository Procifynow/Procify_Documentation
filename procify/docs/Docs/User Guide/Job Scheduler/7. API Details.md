# API Details

## Jobs Details

Entity name : ma_scheduler

Property Details:

| **Property Id** | **Description** |
|---|---|
| scheduler_id | Job definition class name |
| flavor | App name |
| params | Parameters for the Jobs |
| mandatory | Mandatory or Not<br /> e.g, If any job was scheduled at 12 AM, the server stopped at that time due to some circumstances. Later, when the server starts, it will execute the job if mandatory is marked. |
| priority | Priority of the job<br /> S-System \| A-Critical \| B-Normal \| C-Low<br />Read this for more info: Job Priority |
| is_long_running | if is_long_running is not marked, then after 2 minutes, txn will be expired. |
| job_name | Name of the job |
| description | Description for the Job |
| fvid |   |
| expression | CRON expression |
| curr_status | To get the current status of the instance. |

### Creating a new Instance

New instance of a job definition can be created by getting the instance of ma_scheduler and creating a new Entity

Code Snippet :

import \{ GUIDGenerator \} from 'kloBo/kloCommon/GUIDGenerator'

public async createJobInstance()\{

let jIsId = GUIDGenerator.uuidGenerator();

let flavor = this.getFlavor();

let flavor_version = this.transaction.getParsedFv( this.getFlavor(),this.getFlavorVersion());

let cronExp= "0 0 0 ? \* \* 2025/1";

let scheduler_id = "testing_job";

let job_name = "updateData";

await this.transaction.createEntityP("ma_scheduler", \{

is_disabled: 0,

is_long_running: 1,

mandatory: 1,

priority: "A",

r_source: "DEV",

next_schedule_at: null,

curr_status: "created",

expression: cronExp,

flavor: flavor,

fv_id: flavor_version,

job_instance_id: jIsId,

job_name: job_name,// Job Frequency should be same name as job name in job definition

params: JSON.stringify(\{

jobid: jIsId,

\}),

scheduler_id: scheduler_id,

job_instance_name: "JIN -" + new Date().getTime().toString(),

\});

await this.transaction.commitP();

\}

Note: After creating a Job, need to trigger [schedulerTaskEnable](#schedulertaskenable) If the job is enabled and [Restart](#restart). Disabling the job in the same job logic will show error in the logs “Execution was cancelled by admin”.

### schedulerTaskStop

This API is used to **stop** the job for the next schedule.

**Client side Execution:**

//import kloAjaxhandler

import \* as KloAjaxHandler from 'kloBo/kloCommon/KloAjaxHandler';

public async startJob\{

let params = \{

action: 'schedulerTaskStop',

job_instance_id: "\<instance id\>", //can get by firing a query to ma_scheduler

service: 'scheduler',

landscape: this.getLandScape()

\}

try\{

let kloAjax = await KloAjaxHandler.KloAjax.getInstance();

await kloAjax.perFormApiAction('jobAction',params);

\}catch(e)\{

console.log(e);

\}

\}

**Server side Execution**:

const \{ SingletonSrvController \} = await import("kloBolServer/\_singleton/SingletonSrvController");

let reqParams: any = \{

data: \{

action: "schedulerTaskStop",

job_instance_id: "\<instance id\>", //can get by firing a query to ma_scheduler

service: "scheduler",

landscape: this.getLandscape(),

\},

\};

await SingletonSrvController.gI().jobActionAPI(this.transaction, reqParams);
