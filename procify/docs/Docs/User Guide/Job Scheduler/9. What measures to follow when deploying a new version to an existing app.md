# What measures to follow when deploying a new version to an existing app?

When someone deploys the new version of an existing flavor in Q/A or PROD after modifying the scheduler (metadata/files), the scheduler will continue to run on the older version.

To make the scheduler run on the newer version, the old job should be disabled. Use the Import button provided on the page to import the jobs for the new version of the application). For private node debugging, jobs should be imported for the latest version.
