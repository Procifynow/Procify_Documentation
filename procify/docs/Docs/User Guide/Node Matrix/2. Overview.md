# Overview

Node matrix is a screen where one can see the details of the node and landscape i.e

- List of nodes and landscapes in a particular time period.

- Percentage of CPU used by node.

- Memory is used by nodes and memory is available for nodes.

- Details of the landscape and node like total queries to the database and total time taken for queries.

- Node matrix consists of 7 pages.
