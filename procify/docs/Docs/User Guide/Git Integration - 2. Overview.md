# Git Integration — Overview

*This document provides a complete guide for enabling and using **Git integration** within the Procify platform. It explains how to configure GitHub or Bitbucket repositories, set up SSH access, connect them to your Procify flavor, and work with Git-based version control during development.*

*It covers the end-to-end process—including repository setup, user access, configuring Git details in the Workspace Hub, checking out flavors, and using Git-linked workflows within the Procify environment.*
