# Role Permissions Overview

- The "**Role Permissions**" screen has been added under the **Security & Permissions** menu.

- This screen lets you create and manage their own permissions groups, and assign users and permissions to each group.

- Permissions are used to permit who can access what content of the Application.

- Permissions can only be created/Generated in the DEV environment

- The permissions are owning app specific and will inherit to child Apps.

- There are two types of permissions,

  - **CRUD Permissions:** Entity permissions are used to restrict CRUD operations by users for an entity.

  - **CUSTOM Permissions:** Developers can maintain the custom permissions using the permission master screen and use it for controlling menu and home page visibility. Permissions can also be used in application logic to make decisions based on whether the current user has the particular permissions or not.
