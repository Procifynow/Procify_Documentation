# Best practices

1.  Enable permissions for all entities of the application and provide only necessary permissions for the users.

2.  Avoid providing all permissions, even if it is an admin user. Only provide permissions which should be intended for that particular user.

3.  If permission is used for restricting an action, always make sure the prevention is done also from the server-side. Any client side i.e. screen / controller / client callbacks. restrictions are not considered secure. When adding a server side validation, make to add in both D2K_SERVER (ONLINE save) and D2K_MSG (OFFLINE save).
