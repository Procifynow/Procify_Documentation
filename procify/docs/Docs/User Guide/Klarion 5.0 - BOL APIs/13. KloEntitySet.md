# KloEntitySet

EntitySet is a collection of Entity objects. KloEntitySet extends Array prototype.

KloEntitySet have three behavior.

- Query result: direct result of query execution.

- Part of primary relation: by accessing primary relation on entity returns KloEntitySet.

- Part of non Primary relation: by accessing non primary relation on entity returns KloEntitySet.

Deprecated**:** add(obj, position,executeCreateRules) use **newEntityP instead**

Deprecated**:** newEntity(insertAt: number=0, executeCPMRules: boolean=false, underlyingObject: \{\}=\{\}) use **newEntityP instead**
