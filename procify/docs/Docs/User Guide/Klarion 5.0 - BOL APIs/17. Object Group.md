# Object Group

Collection of Object Types is Object Group. Screen usage Object Group which defines the behaviour of particular screen/object. Object types of similar kind of behavior and going to be used in one screen has to be bundled in one Object Group.

- Object Group to Object Type mapping(m:n): One object type can be part of multiple Object Groups.

- One screen can have only one Object group.

- 

Constants for Object Group?

**Abbreviation :** define object group abbreviation like ‘i’ for invoice and ‘o’ for order. This abbreviation can be used in ID series as prefix or some other cases where you want to differentiate the object.

Usage:

- Screen

- Rule execution

Example:

> Object groups in Order:

- Sales Order

- Purchase Order

- Stock Transport Order
