# Domain

KloBase Datastore supports a variety of data types for property values. Domain represents data type following domain types are supported

| **Domain ID** | **JS Type**   | DB type      | MsgType               | Remark                |
|---------------|---------------|--------------|-----------------------|-----------------------|
| I8            | number        | Number(3,0)  | number                | number                |
| I16           | number        | Number(5,0)  | number                | number                |
| I32           | number        | Number(10,0) | number                | number                |
| L / I64       | number        | Number(13,0) | number                | number                |
| DEC           | number        | Number(p,s)  | number                | number                |
| B             | boolean       | Number(1,0)  | number (0/1)          | Returns true / false  |
| C / chr       | string        | VarChar(n)   | string                | string                |
| anum          | string        | VarChar(n)   | string                | string                |
| cwns          | string        | VarChar(n)   | string                | string                |
| BLOB          | string        | VarChar(n)   | string                | string                |
| D             | Date          | Number(13,0) | number (milliseconds) | number (milliseconds) |
| T             | milliseconds  | Number(13,0) | number (milliseconds) | number (milliseconds) |
| DT / TS       | Date          | Number(13,0) | number (milliseconds) | UTC enabled           |
| clob          | Not supported |              |                       |                       |
| GUID          | Not supported |              |                       |                       |
| JSON          | Not supported |              |                       |                       |
| duration ?DU  | Not supported |              |                       |                       |

Application must use the JS Type for all the coding purpose.

Please note DT / TS is UTC based date time hence must not be compared with local time as hard coded time.
