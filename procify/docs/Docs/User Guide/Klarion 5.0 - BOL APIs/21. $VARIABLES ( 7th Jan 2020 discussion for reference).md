\$GLOBAL

**Usage**

All the above global variables are accessible on the event object, \$Global is only available in client.

When used as string literal in meta model in query, id series, authorization it is replaced with real value. E.g. **\$USER.login_id** will be replaced with currently logged in user id.

Syntax: \$\{\<Variable name\>.\<property id\>\}

API

EnvironmentalVariable.getEnvironmentMap(flavor,version) will return the env variable map, which will have all the ENV objects as key- value pairs, use the ENV variable name to get the actual Variable Entity.
