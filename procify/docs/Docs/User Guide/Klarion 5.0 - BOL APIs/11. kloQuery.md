# kloQuery

## Overview

kloQuery is a meta model for fetching the data from the data store, like SQL in RDBMS. For example, the entity ( table) name “d_order” has multiple columns including “s_status”. To fetch all the record for open order in RDBMS need SQL as “Select ord_id, qty, ord_date from d_order WHERE d_order.status = ‘open’ Orderby ord_date ASC” and execute to get the desired result.

kloQuery behaves similarly with a few value added services, it gives the ability to fetch the data seamlessly for offline applications and online applications. Abstracts out multiple syntax of Odata, SQl, Json etc. so that programmers can concentrate on the business logic. It gives a few short hand optimization like pagination column select. Security features like authorization etc..

Runtime Query does not need modeling. It inherits behavior from entity and BO definition and operates with API. Later we will consider more control on query by modeling the kloQuery.

kloQuery is made with Query, QueryProperty, PropertyType, Select, orderby etc.. It returns kloEntityset. kloEntityset is an array of kloEntities.  
For e.g. consider following SQL

| SELECT ord_id, qty AS ord_qty, ord_date FROM d_order WHERE <u>d_order.status = ‘open’</u> Orderby ord_date ASC” |
|---|
| Let q = await oController.getQueryP(“<u>d_order”</u>);<br/>q.setProperty(“<u>d_order.status”, ‘open’</u>);<br/>q.setOrderBy([\{fieldname:”<u>d_order.</u>ord_date” , sort_type:”ASC”\}]);<br/>Let result: kloEntitySet = await q.ExecuteP(); |

Above SQL needs to be represented by kloQuery. WHERE clause of SQL d_order.status is the input search criteria modeled as query property and property type of the query property will describe the type(string) caption and value help. Similarly kloQuery also has OrderBy and Select together with other constructs to hold the SQL constraints. Query objects are directly bindable in UI for user input and capable of providing label and value help. kloQuery can be represented by premodeled query by name and at runtime enhancing with constraints.
