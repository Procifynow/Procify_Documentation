# End Point

End point enables the klobroker to send and receive the message across various participants. Endpoints are identified by end point ID. When a user logins into an application, installed app, needs to communicate with the server hence each installation (apk) gets a unique endpoint ID. Similarly each browser also gets endpoint id. Individual tenants on the server also get endpoint ID. and external system also have endpointID.
