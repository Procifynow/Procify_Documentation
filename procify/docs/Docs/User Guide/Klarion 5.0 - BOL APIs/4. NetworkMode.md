# NetworkMode

kloudBase supports a rich set of network modes. Two most frequent network modes are online and offline.  
**OnLine** network mode refers to the capability of running the program in a browser or installed mobile app (client) communicating with server for every need. Network connectivity from client to server is a must. If Screen needs to show open Orders, kloBO will go to the server to get the data for Open Order and give it to UI for display. Similarly all the changes on the browser or device app will be collected and sent to the server for validating and saving.  
**Offline** network mode refers to the capability to run the program with weak or infrequent network availability. Application stores the relevant data locally and keeps the local cache and server data updated as and when finds the connectivity. Browser and installed mobile app both are offline capable.

**Cached Online** network mode refers to the capability of client communicating with server for every need but speedup the interaction by suggesting data from local cache.

**Commit Online** network mode refers to the capability of client serving the data from local cache but save always goes thru online and also modifies local cache.

**SAP Online** refers to the capability of all the transaction goes to SAP via gateway server.
