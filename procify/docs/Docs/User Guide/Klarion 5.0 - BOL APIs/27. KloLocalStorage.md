# KloLocalStorage

Klarion Specific Local storage API, all the below API’s will operate on the **current logged in user context.**

**Do not mix use localStorage API directly.  
**getItem(k): return the value in Localstorage for k;  
setItem(k,v): sets the value v in Localstorage for key k;  
removeItem(k) : removes the item with key k from Localstorage ;

getGlobalItem(k): return the value in Localstorage for k;  
setGlobalItem(k,v): sets the value v in Localstorage for key k;  
removeGlobalItem(k) : removes the item with key k from Localstorage ;
