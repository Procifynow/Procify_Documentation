# Transaction

Every attempt to create, update, or delete an entity takes place in the context of a [transaction](https://cloud.google.com/appengine/docs/python/datastore/transactions). A single transaction can include any number of such operations. To maintain the consistency of the data, the transaction ensures that all of the operations it contains are applied to KloBase Datastore as a unit or, if any of the operations fails, that none of them are applied. Furthermore, all strongly-consistent reads (ancestor queries or gets) performed within the same transaction observe a consistent snapshot of the data.
