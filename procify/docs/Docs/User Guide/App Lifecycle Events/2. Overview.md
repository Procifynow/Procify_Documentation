# Overview

This **App Lifecycle Events - User Guide** provides a structured way for developers to handle various stages of the application's lifecycle. The **AppLifeCycleEvent class** contains methods that are triggered by the framework to respond to key lifecycle events such as:

- App start

- App moves to the foreground

- App goes into the background

- App close

This allows an efficient and organized management of application behavior in response to above mentioned events.

**Method Details & Description:**

**Note:**

1.  All the methods discussed below are Case-sensitive. Please make sure the methods are typed exactly as shown below.

2.  No import / export parameters are needed for the below mentioned methods.
