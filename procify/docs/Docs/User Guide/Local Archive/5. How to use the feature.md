# How to use the feature

| **SN** | **Steps**                                                                                                                      |
|--------|--------------------------------------------------------------------------------------------------------------------------------|
| 1      | *Go to the local archive screen, and create an archive for an entity.*                                                         |
| 2      | Provide the query parameters which describe the data to be archived.                                                           |
| 3      | This will be triggered on opening the application and data satisfying the query parameters will be archived in the background. |
