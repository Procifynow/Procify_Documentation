# About App Cache Settings

App Cache Settings, as the name suggests, is for developers as a helping tool while developing applications.

Previously, if any offline entity was created, any metadata was updated, or any entry was made in the server-side database, it required developers to clear their cache and do registration again to get it reflected in the browser. To resolve that issue, a App Cache Settings is introduced.

Now, developers can update zip, drop and create web SQL tables, update configs (eg: vh configs), and do initial sync to get server data without any middleware sync (sync of data in the background whenever the device/browser is online).

**Note:** The App Cache Settings should be handled by developers only to avoid any inconsistency or failure in the application.
