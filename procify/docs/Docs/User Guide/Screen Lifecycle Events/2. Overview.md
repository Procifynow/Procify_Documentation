# Overview

In the past, the framework has provided the application with screen lifecycle events like onScreenEnter, onModelCreate, onTranscationEnter, onAfterTransactionEnter, onTranscationExit, onModelDestroy, and onScreenExit. But in the applications which run with version 6.0 or higher, the above-mentioned events are removed and new events have been introduced.

## Screen Lifecycle events

- onPageInit

- onPageModelReady

- onPageEnter

- onPageExit

- onPageDestroy
