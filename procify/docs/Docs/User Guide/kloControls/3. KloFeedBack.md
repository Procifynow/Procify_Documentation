# KloFeedBack

**Class**: KloFeedBack

## Overview

Extended from **sap.m.Input**.

KloFeedBack control will render on the UI as a feedback icon. On click of the icon, a new dialog with screenshot & textArea field will open. In the new dialog, there will be two buttons. 1st to cancel the feedback and 2nd to send/save the feedback. Users will also be able to edit a screenshot by clicking the text "Click to highlight & Hide Info".

## Framework Version Information

5.7 and 6.0

## Usage

The Usage of this control is to capture the screenshot of the screen and send feedback with text messages.

When the user wants to send feedback with a screenshot.

To use this control, the user needs to select the control type as KloFeedBack.
