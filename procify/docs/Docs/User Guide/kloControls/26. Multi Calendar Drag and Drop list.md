# Multi Calendar Drag and Drop list

## Overview

From the grid the user will be able to drag schedules to Team calendar drop grid item/ schedule to create multiple calendar appointments.

## Framework Version Information

6.0

## Usage

This is an implementation of drag and drop from grid list to multi calendar. A multicalendar section and a grid section is required for this integration.

In controller onSectionEnter(eg. onMulticaEnter) method of multicalendar is added.

There the control instance is stored with the “getActiveControlById” method of the controller.

This is required because while creating the drag and drop config of the grid the target element Id should be provided which in this case will be the multi calendar’s internal table.

With this setup the drag and drop should work. To create an appointment in the multi calendar on drop check out the “onDrop” method in the below given code example.

For more info check out this [link](https://community.neptune-software.com/topics/tips--tricks/blogs/how-to-enable--drag---drop-from--list-to--planning--ca).

**Note:** For safari or iOS cordova the ‘event.dataTransfer.setData('text/plain', "")’ is required in onDragStart event otherwise the drag and drop won’t work.

public onMulticaEnter() \{

const oGrid = this.getActiveControlById('','section01');

const oMultica = this.getActiveControlById('','s_people\_\_list02');

const oDND = new sap.ui.core.dnd.DragDropInfo(\{

sourceAggregation: "rows",

targetAggregation:"items",

targetElement: oMultica.getId() + "-Table",

dragEnter: (oEvent) =\> \{

event.dataTransfer.setData('text/plain', ""); //Safari Specific \*\*IMPORTANT: Here event is browser event not oEvent.

this.onDragEnter(oEvent);

\},

dragStart: (oEvent) =\> \{

this.onDragStart(oEvent)

\},

drop: (oEvent) =\> \{

this.onDrop(oEvent)

\}

\});

oGrid.addDragDropConfig(oDND);

\}

public async onDrop(oEvent)\{

let oDroppedControl = oEvent.getParameter("droppedControl");

let cliId = oDroppedControl.getId();

let rowId = cliId.replace("-CLI", "");

let calRow = (\<sap.ui.core.Control\>sap.ui.getCore().byId(rowId));

let sPath = this.getPathFromControl(calRow);

const iIndex = sPath.split("/").pop();

const oChildEnt = (this.tm.getTN('r_appoint').getData())\[iIndex\];

let calendarRow = "";

let rowStartDate = "";

let targetObj = oEvent.getParameter("droppedControl")

let browserEvent = oEvent.mParameters.browserEvent

let browserTarget = "";

let intervalNumber = "";

if (browserEvent.target) \{

browserTarget = browserEvent.target;

//@ts-ignore

if (browserTarget?.id) \{//@ts-ignore

if (browserTarget?.id.indexOf("CalRow-AppsInt") !== -1) \{//@ts-ignore

intervalNumber = browserTarget?.id?.split("CalRow-AppsInt")\[1\] \|\| 0;

\}

\}

\}

if (targetObj.getAggregation("cells").length \> 1) \{

calendarRow = targetObj.getAggregation("cells")\[1\];

if (calendarRow) \{//@ts-ignore

rowStartDate = calendarRow?.getStartDate();

\}

\}

let iIntervalNumber = isNaN(+intervalNumber) ? 0 : +intervalNumber;

let startdate = new Date(new Date(rowStartDate).getTime() + iIntervalNumber \* 60 \* 60000);

let enddate = new Date(startdate.getTime() + 60 \* 60000);

await oChildEnt\['r_appoint'\].newEntityP().then(ent =\> \{

ent\['startdate'\] = startdate;

ent\['enddate'\] = enddate;

ent\['title'\] = "Drop Appointment"

ent\['text'\] = "Created by drop from list"

ent\['icon'\] = "sap-icon://background"

\});

\}
