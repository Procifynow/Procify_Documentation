# KloInput

**Class**: KloInput

## Overview

Extended from **sap.m.Input**,

KloInput combines the behaviour of **KloInputF4 (used for selecting an item from a list of suggested items in a valuehelp dialog)**, and **KloInputAutoComplete (used for autocomplete of a text from the suggestion items)**, **KloComboBox (used for selecting an item from a dropdown list)**, [**sap.m.Input**](https://sdk.openui5.org/api/sap.m.Input). To Behave as KloInputF4 KloInputAutoComplete or KloComboBox the entity property must have a **value help** otherwise no value help will be displayed for the control.

We need to set the **vhType** either in the **Page Data Model** section or in the properties panel with the options **(F4**, **AutoComplete**, **ComboBox** or **None)** specified on the KloInput control so that it can behave as per the users’ requirements.

However, the vhType specified in the properties panel **overrides** the vh_type in the PageDataModel section.

**dependantProperty** is used the same way as KloInputF4 and KloInputAutoComplete.

When a dependent property is provided, it clears the set's value for that dependent field. If any field is dependent, it clears the field for that input control.

**keyList**, **textList** and **additionalTextList** properties determine if the key, description or additional description is to be displayed as value in the input control.

For vhType **Combobox**, hitting down arrow button on the keyboard within the focused input control, opens the dropdown with the suggestionItems

## Framework Version Information

5.5 and above

## Properties

| **NAME**               | **TYPE** | **DEFAULT VALUE**                | **DESCRIPTION**                                                                                                                                                                                                               |
|------------------------|----------|----------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **vhType**             | string   | .NONE                            | Determines the behaviour of the kloInput.<br />Valid vh_type is:<br />VhType.NONE, VhType.AUTOSUGGESTION, VhType.COMBO, VhType.F4, VhType.POPUP |
| **dependantProperty**  | string   | “”                               | Value of the dependant property that is to be used in the value help                                                                                                                                |
| **textList**           | string   | Value in VH metadata displayText | Property to be displayed in the text property of ListItem from suggestion item.                                                                                                                     |
| **keyList**            | string   | Value in VH metadata key         | Property to be considered as a key property of ListItem from suggestion item.                                                                                                                       |
| **additionalTextList** | string   | “”                               | Property to be displayed in the additionalText property of ListItem from suggestion item.                                                                                                           |

## Usage

The user can use kloInput instead of kloInputF4 or kloAutoComplete or as a simple input field. Users just need to supply the **vh_type**.

NOTE: When using KloInput with vhtype then it will display the description in the screen.

**When to use:** Use the control for FW valuehelps and autocomplete when data is huge. (Recommended)
