# KloChart

The [KloChart](https://docs.google.com/document/u/0/d/1UeSJM1mbrJIAbr9lGTs9KNrWkhJwiYO3ZIZNDzza8u8/edit) is used for condensing large amounts of information into easy-to-understand formats that clearly and effectively communicate important points.
