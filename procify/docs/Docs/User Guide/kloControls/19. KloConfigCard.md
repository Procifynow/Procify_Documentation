# KloConfigCard

**Class**: KloConfigCard

## Overview

Extended from **sap.ui.layout.cssgrid.CSSGrid**.

Refer [sap.ui.layout.cssgrid.CSSGrid openui5 api reference](https://sdk.openui5.org/api/sap.ui.layout.cssgrid.CSSGrid) for all the possible properties, aggregations and events.

KloConfigCard has one property autoHeight added to enable or disable the autoHeight on the control.

If autoHeight is false, then the row height in the card is **33px** otherwise it is auto.

## Framework Version Information

5.7 and 6.0

## Properties

| **NAME**       | **TYPE** | **DEFAULT VALUE** | **DESCRIPTION**                                                 |
|----------------|----------|-------------------|-----------------------------------------------------------------|
| **autoHeight** | boolean  | true              | Enable or disable the row autoHeight. |
