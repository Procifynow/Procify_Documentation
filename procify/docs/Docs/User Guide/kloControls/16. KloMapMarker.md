# KloMapMarker

**Class**: KloMapMarker

## Overview

Extended from **sap.ui.core**.**Control**

This control will be used as a subscreen type. A preview of the section in which this control is added will display the map with the added pins. For using this control first select the subscreen type of the section as a **map.** Then for using the properties of the map add config to the respective section. In config, you can use the properties mentioned below in the properties section.

KloConfigMap has markers as a hidden aggregation. For adding markers drag a property (which has a geoLocation qualifier) from the transNode and drop over configMap.

## Framework Version Information

5.7 and 6.0

## Properties

| **NAME**              | **TYPE** | **DEFAULT VALUE**                         | **DESCRIPTION**                                                                                                         |
|-----------------------|----------|-------------------------------------------|-------------------------------------------------------------------------------------------------------------------------|
| **lat**               | float    |                                           | It will set the position of the marker latitude-wise.                                         |
| **lng**               | float    |                                           | It will set the position of the marker longitude-wise.                                        |
| **pin**               | boolean  |                                           | If true will display the pin as a marker.                                                     |
| **description1**      | string   |                                           | This property is used to display the title of the popover which will open on click of marker. |
| **color**             | any      |                                           | Colour of the icon.                                                                                                     |
| **pinColor**          | any      |                                           | Colour of the pin.                                                                                                      |
| **icon**              | any      |                                           | If the pin value is true, the icon will be displayed inside the pin else only the icon will display as a marker.        |
| **enabled**           | boolean  | false                                     | If true markers will be draggable.                                                                                      |
| **time**              | object   |                                           | For storing the time of location capture.                                                                               |
| **size**              | int      |                                           | Size of the icon( if png path is provided ).                                                                            |
| **value**             | object   |                                           | The value must be an iLocation qualifier.                                                                               |
| **tooltip**           | string   |                                           | The tooltip will display over a marker                                                                                  |
| **infoIcon**          | string   | "sap-icon://kloFontg/info"                | For setting marker’s popover info icon.                                                                                 |
| **directionIcon**     | string   | “sap-icon://kloFontg/assistant_direction” | For setting marker’s popover direction icon.                                                                            |
| **showInfoIcon**      | boolean  | true                                      | Shows or hides the info button in marker popover.                                                                       |
| **showDirectionIcon** | boolean  | true                                      | Shows or hides the direction button in marker popover.                                                                  |

## Usage

The Usage of this control is to display the locations on the map. For using this control an entity with a **“Location”** qualifier property is required. Set the latitude and longitude in the location property object.

Create a screen with a section, screen type as **map**. Bind the entity and add config to it.

Now the location property should be dropped inside the config. This will be of class “KloMapMarker”. It will show all the pins for location for each entity.

## Aggregations

| **NAME** | **TYPE**                         | **DESCRIPTION**                                       |
|----------|----------------------------------|-------------------------------------------------------|
| **pins** | KloPin | This aggregation is hidden. |

## Events

| **NAME**     | **DESCRIPTION**                                                                                                   |
|--------------|-------------------------------------------------------------------------------------------------------------------|
| **press**    | Event will fire on the click of the pin.                                                                          |
| **onChange** | Event will fire on change of lat & lng by dragging the pin.                                                       |
| **info**     | Event will fire on click of the info icon present in the header of the popup which will open on click of the pin. |
