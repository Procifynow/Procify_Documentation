# KloSearchConfig

**Class**: KloSearchConfig

## Overview

Extended from **sap.ui.core.Control**.

KloSearchConfig lets the developer provide configuration for the search section.

## Framework Version Information

6.0

## Usage

KloSearchConfig control can be used if the developer wants to provide additional settings (properties, events,...) to the search section.

If the screen toolbar is not added then the search panel is shown otherwise the search button is added directly to the screen toolbar.

If the search popUpStyle property is my_width, then we get a pin.

If search is pinned then the remaining content (e.g. list) comes after the search panel.

If the search is unpinned then the search panel overlays the remaining content.

The mandatory can be controlled using the control property and not picked from property type for search subscreen.

If mandatory is marked for the control, then without filling it, search cannot be triggered.

On hitting the reset button, mandatory highlight is also removed.

Busy Indicator is shown when the search is in progress.

afterSearch event is fired after the search is completed.

Count should be shown only if the count is greater than 0.

**NOTE**: If the search section is to be used inside the dialog, since search with popupstyle my_width ( unpinned ) is shown as an overlay, will not provide height and width to the dialog. Desired height and width needs to be given to the dialog which contains search section.

## Properties

| **NAME**            | **TYPE** | **DEFAULT VALUE** | **DESCRIPTION**                                                                                           |
|---------------------|----------|-------------------|-----------------------------------------------------------------------------------------------------------|
| **showToken**       | boolean  | true              | Determines if the search tokens should be shown or not.                         |
| **popUpStyle**      | string   | \-                | Determines the popUpStyle for the search section (my_width, full_width, inline) |
| **pinned**          | boolean  | false             | Determines if the search section is pinned or not.                              |
| **isCountRequired** | boolean  | false             | Determines if the search count required in the search panel.                    |

## Events

| **NAME**          | **DESCRIPTION**                                                                                                   |
|-------------------|-------------------------------------------------------------------------------------------------------------------|
| **onAfterSearch** | Event will fire after the search is completed.                                                                    |
| **onAfterReset**  | Event will fire after the search query is reset..                                                                 |
| **info**          | Event will fire on click of the info icon present in the header of the popup which will open on click of the pin. |
