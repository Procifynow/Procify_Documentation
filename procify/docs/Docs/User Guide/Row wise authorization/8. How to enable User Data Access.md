# How to enable User Data Access

- In the Data Studio, open the Access Management tab. Turn on the row-wise authorization flag for the entity, then click **‘+’** to add a token template. Developers can add more than one template if needed.

- Tokens are generated based on the application's code in the entity.ts file and the data available in that entity.

- **Refer** [<u>Row wise authorization - User Guide</u>](https://docs.google.com/document/d/1P7tZZMgIySIxgkiEWIOFUyvq36MP5yUXi-mfZ2KzTn8/edit?usp=sharing) **for detailed explanations.**

| **Columns**             | **Description**                                                           |
|-------------------------|---------------------------------------------------------------------------|
| ID                      | Stores the access ID (Primary Key).                                       |
| Access key              | Stores the access key used as a prefix for the tokens.                    |
| Property                | Stores the property ID used to create tokens based on those properties.   |
| Access Token Navigation | Navigates to the Data Access Rules screen to display the generated tokens. |
