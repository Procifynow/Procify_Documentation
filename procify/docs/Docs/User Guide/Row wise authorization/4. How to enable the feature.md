# How to enable the feature?

*By default row wise authorization is disabled in all entities, it can be enabled in [<u>Data Studio</u>](https://docs.google.com/document/d/1TZCiIbpOLvFzD4Qp6HrLiJafHC3OOKDvIcDAtmGRHbA/edit?tab=t.0#heading=h.waf0l81a3e30).*
