# Setup Procedure

- Open the working project.

> ![Screenshot](./img/customer-branding-for-ios-image10.png)

- Go to config.xml. Open the XML file with **TextEdit** as shown in the image below:

> ![Screenshot](./img/customer-branding-for-ios-image38.png)

- In the config.xml file,

> **Orange highlight:** Bundle ID/App ID can be changed here.
>
> **Yellow Highlight:** This will be the Project Name.
>
> **Red Highlight:** This depicts the App description. App defining name.

![Screenshot](./img/customer-branding-for-ios-image28.png)

If you do not change anything then proceed with the build. But, if you are changing anything in config.xml then the process will change.

In case you make a change, follow the steps below:

- Suppose you changed the bundle ID/ any other things, then you will right-click to your project folder and go to the **New Terminal at Folder** option.

> ![Screenshot](./img/customer-branding-for-ios-image48.png)

This will open a new terminal folder.

- Put the following command in the terminal window.

> Orange: **sudo -s** current directory to root directory.
>
> Green: **chmod -R 777** .: This gives the read and write access
>
> Blue: **Cordova platforms:** when you want to check the platform details.
>
> Yellow: **Cordova platform rm ios**: this is for removing the platform.
>
> ![Screenshot](./img/customer-branding-for-ios-image34.png)

**Note:** After putting sudo -s in the terminal there is a password section, put the system password in that place. (Highlighted with red)

- Once you remove the platform add the new one as shown below:

> **Orange Highlight:** **cordova platform add ios@7** the command to add platform.
>
> **Blue Highlight:** This highlight is used to make you notice that you have added the correct iOS version.

![Screenshot](./img/customer-branding-for-ios-image23.png)

- When you want to get a **bundle ID(it is an authentication identifier that is unique for any application)** from someone, use this Google file/service.

![Screenshot](./img/customer-branding-for-ios-image30.png)

- Copy and paste the bundle ID in two other places in your project folder; one under your **Project folder** and the other in your **Resources** **folder**.

![Screenshot](./img/customer-branding-for-ios-image11.png)

![Screenshot](./img/customer-branding-for-ios-image2.png)

- When you want to change the app icon, go to this folder.

![Screenshot](./img/customer-branding-for-ios-image22.png)

- The following folder highlighted should be kept in a shared folder. This will help the users get access and use it to change the size and dimension as required.

![Screenshot](./img/customer-branding-for-ios-image3.png)

- Double-click on the XCode project file which is available in your platform folder. This will open Xcode for you.

![Screenshot](./img/customer-branding-for-ios-image24.png)

- In XCode, go to **Signing &Capabilities.** Check the signing (debug) and the signing(release) checkboxes.

> ![Screenshot](./img/customer-branding-for-ios-image31.png)

- Select the certification.

![Screenshot](./img/customer-branding-for-ios-image50.png)

After selection, the authorised team will be selected.

![Screenshot](./img/customer-branding-for-ios-image25.png)

- If you have any feature or plugin based on Location, add that to your **Custom iOS Target Properties,** under Info.

![Screenshot](./img/customer-branding-for-ios-image36.png)

- Under Build Settings, change the Swift Language Version to **Swift 5.**

![Screenshot](./img/customer-branding-for-ios-image29.png)

- Select your project from the top bar.

![Screenshot](./img/customer-branding-for-ios-image45.png)

- Select the testing device.

![Screenshot](./img/customer-branding-for-ios-image35.png)

- Click on the run button to start the build process.

![Screenshot](./img/customer-branding-for-ios-image32.png)

- Once the build is triggered it will show in the place shown in the image below.

![Screenshot](./img/customer-branding-for-ios-image44.png)

- Here you can also find the number of errors that came during the build. Once you click on the error, you will be taken to the error log(list of errors).

![Screenshot](./img/customer-branding-for-ios-image43.png)

- You will see the error line. You are required to delete the error code.

> **Note:** Delete the error code.

![Screenshot](./img/customer-branding-for-ios-image49.png)

- Once the code is deleted the screen looks like this.

![Screenshot](./img/customer-branding-for-ios-image42.png)

- Once the code is removed clean the build folder.

![Screenshot](./img/customer-branding-for-ios-image51.png)

- Once again click on the build. Once the process is complete the logs will be visible in the screen below.

**Note:** These logs are from Xcode.

![Screenshot](./img/customer-branding-for-ios-image33.png)

- To debug from Safari go to **Develop\> ipad\> localhost**.

![Screenshot](./img/customer-branding-for-ios-image37.png)
