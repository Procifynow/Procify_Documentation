# App Settings — Prerequisites

**Note:** If the developers want to make any changes to the Settings Definition Screen metadata then they will have to assign **core_fw** as a dependent app to the **fw_settings1_1** app and then build the fw_settings1 flavor and reinitialize it. Only then any changes should be made.

Also for save to work, assign **is_external** for **fw_settings1** flavor as **1**. To save any changes made on the Settings Definition user needs a shared, writable app.
