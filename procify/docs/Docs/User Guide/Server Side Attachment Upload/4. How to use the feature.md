# Server Side Attachment Upload — How to use the feature

## PDF Generation and Upload

| SN | Steps |
| :---- | :---- |
| 1 | *From the server side callback function, we can generate the reports\[pdf, csv etc\] and convert it to blob object and upload it via setAttachmentP  API. Below code snippet, imports pdf-lib and generates the pdf , convert to blob object and uploads it via setAttachmentP API   // Import pdf-lib for server-side PDF generation         const { PDFDocument, rgb } \= require("pdf-lib");         // Create a new PDF document         const pdfDoc \= await PDFDocument.create();         const page \= pdfDoc.addPage(\[595, 842\]);         // Add content to the PDF         page.drawText("ORDER DOCUMENT", {             x: 50,             y: 800,             size: 18,             color: rgb(0, 0, 0),         });         page.drawText("=".repeat(80), {             x: 50,             y: 780,             size: 8,             color: rgb(0, 0, 0),         });         page.drawText(\`Order ID: \${this.order\_id \|\| "N/A"}\`, {             x: 50,             y: 750,             size: 12,             color: rgb(0, 0, 0),         });         page.drawText(\`Order Description: \${this.order\_desc \|\| "N/A"}\`, {             x: 50,             y: 730,             size: 12,             color: rgb(0, 0, 0),         });         page.drawText(\`Created Date: \${new Date().toLocaleDateString()}\`, {             x: 50,             y: 700,             size: 12,             color: rgb(0, 0, 0),         });         page.drawText(\`Created Time: \${new Date().toLocaleTimeString()}\`, {             x: 50,             y: 680,             size: 12,             color: rgb(0, 0, 0),         });         // Save the PDF to bytes         const pdfBytes \= await pdfDoc.save();         // Create a Blob object from PDF bytes (required by setAttachmentP)         const blob \= new Blob(\[pdfBytes\], { type: "application/pdf" });         // Set file name         const fileName \= \`order\_\${this.order\_id \|\| "new"}\_\${Date.now()}.pdf\`;         // Upload the PDF using setAttachmentP         await this.attach.setAttachmentP(blob, fileName);*  |

## Updating Existing PDF

| SN | Steps |
| :---- | :---- |
| 1 | *From the server side callback function, We can retrieve the previously generated PDF reports and modify them. Below code snippet, that retrieves the pdf, modified it and uploads it via setAttachmentP API  // Import pdf-lib for server-side PDF modification         const { PDFDocument, rgb } \= require("pdf-lib");         // Load the existing attachment from server (returns Uint8Array)         const existingAttachment \= await this.attach.getAttachmentServerLoadP();         if (\!existingAttachment) {             throw new Error("No attachment found to update");         }         // Load the existing PDF document directly from Uint8Array         const pdfDoc \= await PDFDocument.load(existingAttachment);         // Get the first page (or add a new page if needed)         const pages \= pdfDoc.getPages();         const firstPage \= pages\[0\];         // Add updated/modified content to the PDF         firstPage.drawText("\*\*\* UPDATED \*\*\*", {             x: 50,             y: 650,             size: 14,             color: rgb(1, 0, 0), // Red color to indicate update         });         firstPage.drawText(\`Last Modified: \${new Date().toLocaleString()}\`, {             x: 50,             y: 630,             size: 12,             color: rgb(0, 0, 1), // Blue color         });         firstPage.drawText(\`Modified Order Description: \${this.order\_desc \|\| "N/A"} \- MODIFIED\`, {             x: 50,             y: 610,             size: 12,             color: rgb(0, 0, 0),         });         // Save the modified PDF to bytes         const modifiedPdfBytes \= await pdfDoc.save();         // Create a Blob object from modified PDF bytes         const modifiedBlob \= new Blob(\[modifiedPdfBytes\], { type: "application/pdf" });         // Generate updated file name         const updatedFileName \= \`order\_\${this.order\_id \|\| "new"}\_updated\_\${Date.now()}.pdf\`;         // Upload the modified PDF using setAttachmentP         await this.attach.setAttachmentP(modifiedBlob, updatedFileName);*  |
