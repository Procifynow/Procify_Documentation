# Server Side Attachment Upload — API Details

| API Name | setAttachmentP of attachment qualifier |
| :---- | :---- |
| **Parameter 1** | *File Blob* |
| **Parameter 2** | File name |
|  |  |
| **Parameter** | **Description** |
| *File Blob* |  *blob object of the attachment that needs to be uploaded*  |
| file\_name | Name of the file with extension Example: report.pdf |

## BOL API: Attachment Qualifier

The following BOL API methods are available on any entity property with the attachment qualifier. In server-side callbacks they are called on the property through this, for example this.attach where attach is the property name.

### setAttachmentP()

setAttachmentP(fileBlob, fileName): Promise\<void\>

#### **ParametersfileBlob** (Blob): Blob object of the attachment to upload.

**fileName** (string): Name of the file, including the extension. Example: report.pdf

#### **Returns**

Promise\<void\>: resolves once the file is uploaded to the attachment property.

#### **Description**

Uploads a file to the attachment qualifier property. It supports uploads from both server side and client side. On the server side, generate the report (PDF, CSV and so on), convert it to a Blob object and pass it to this method.

#### **Example**

const pdfBytes \= await pdfDoc.save();  
const blob \= new Blob(\[pdfBytes\], { type: "application/pdf" });  
const fileName \= \`order\_\${this.order\_id \|\| "new"}\_\${Date.now()}.pdf\`;  
await this.attach.setAttachmentP(blob, fileName);

### getAttachmentServerLoadP()

getAttachmentServerLoadP(): Promise\<Uint8Array\>

#### **Returns**

Promise\<Uint8Array\>: content of the file currently stored in the attachment property. The value is empty when no attachment exists.

#### **Description**

Loads the existing attachment from the server so that it can be read or modified in a server-side callback. To save the changes, upload the modified file again with setAttachmentP.

#### **Example**

const existingAttachment \= await this.attach.getAttachmentServerLoadP();  
if (\!existingAttachment) {  
    throw new Error("No attachment found to update");  
}  
const pdfDoc \= await PDFDocument.load(existingAttachment);  
// modify the PDF, then upload it again  
const modifiedBlob \= new Blob(\[await pdfDoc.save()\], { type: "application/pdf" });  
await this.attach.setAttachmentP(modifiedBlob, "order\_updated.pdf");
