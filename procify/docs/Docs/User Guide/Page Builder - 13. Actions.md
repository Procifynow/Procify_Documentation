# Page Builder — Actions

## 11.1. Page Actions: {#11.1.-page-actions:}

To add an action for the page, [add an aggregation](#add-new-aggregation:) **“kloAction”** for the page. Once the kloAction is added, [create a new button control](#create-new-control:) for the action. After adding a control add properties for that button control.

## 11.2. Section Actions: {#11.2.-section-actions:}

Similar to page actions we can add actions to our sections. To add actions for our sections [kloToolbar needs to be added](#10.0.-klotoolbar) for that section. After adding kloToolbar [add an aggregation kloAction](#add-new-aggregation:) for the kloToolbar. After adding kloAction aggregation follow the same steps as [page actions](#11.1.-page-actions:).
