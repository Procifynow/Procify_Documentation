# Properties

| **NAME**                    | **TYPE**        | **DEFAULT VALUE** | **DESCRIPTION**                                                                                                                                                                                                                                                                                                                                                                                                                                   |
|-----------------------------|-----------------|-------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **fileName**                | string          | DataDownload      | Specifies the downloaded Excel file name.                                                                                                                                                                                                                                                                                                                                                                                                         |
| **templateFileName**        | string          | \-                | Specifies the template file name which needs to be downloaded                                                                                                                                                                                                                                                                                                                                                                                     |
| **downloadSectionTemplate** | string          | \-                | Specifies the section name to which the template needs to be downloaded                                                                                                                                                                                                                                                                                                                                                                           |
| **uploadSectionTemplate**   | string          | \-                | Specifies the section name to which the data needs to be uploaded                                                                                                                                                                                                                                                                                                                                                                                 |
| **allColumnsUpload**        | string          | false             | Specifies whether all columns present in the entity should be considered while uploading.                                                                                                                                                                                                                                                                                                                                                         |
| **allColumnsDownload**      | string          | false             | Specifies whether all columns present in the entity should be downloaded.                                                                                                                                                                                                                                                                                                                                                                         |
| **vhDownloadformat**        | Array of Object | \-                | The vhDownloadFormat property lets developers configure how individual Value Help (VH) fields are exported during the standard Excel download by specifying key, description, or key + description for each VH field (for example: \[\{"my_key":"key"\},\{"country_code":"desc"\},\{"state_code":"key-desc"\}\]). Only the VH fields listed in this property follow the configured format, while all other VH fields use the default download behavior. |
