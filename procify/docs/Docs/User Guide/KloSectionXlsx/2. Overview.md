# Overview

**Class**: KloSectionXlsx

Extended from **sap.ui.core.Control**.

KloSectionXlsx lets the developer provide configuration of excel upload and download.

For further information review the upload and download actions of [*KloSectionToolbar*](https://docs.google.com/document/d/1T8IgYkQ5A-2hVF-Kcv1MPPt3atkyFEf4hYbI66TTTkI/edit#heading=h.9di0jn24rnr).
