# Critical Implementation Requirements

IMPORTANT: Transnode Binding Requirements

> For Excel download functionality to work correctly, the following binding requirements MUST be followed:

The section with Excel download must be bound to an EntitySet transnode

> All controls within the section MUST be bound to properties of the same EntitySet transnode

Controls MUST NOT be bound to properties of a different transnode using dsrc (data source) binding

Correct Implementation Example

| **✓ Correct Binding**                                                                                                                                                                                                                            | **✗ Incorrect Binding**                                                                                                                                                                                                                             |
|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Section:** Bound to 'CampaignContacts' (EntitySet)**Column 1:** ContactName → CampaignContacts.ContactName**Column 2:** Email → CampaignContacts.Email**Column 3:** Status → CampaignContacts.Status**Result:** Excel download works correctly | **Section:** Bound to 'CampaignContacts' (EntitySet)**Column 1:** ContactName → CampaignContacts.ContactName**Column 2:** Email → ContactDetails.Email (dsrc binding)**Column 3:** Status → CampaignContacts.Status**Result: Excel download FAILS** |
