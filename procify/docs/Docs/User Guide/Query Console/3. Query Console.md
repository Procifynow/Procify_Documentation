# Query Console — Query Console

The Query Console tool enables users to validate and run complex SQL SELECT queries, displaying the results in an organized table format. It also supports the use of EXPLAIN and EXPLAIN ANALYZE for query analysis and optimization insights. Output records are listed immediately after execution. Results can be downloaded as an Excel file with a single click for easy sharing or further analysis. Only SELECT-style queries are permitted.

**Note: DML/DDL keywords (INSERT, UPDATE, DELETE, DROP, etc.) are automatically blocked and will be cleared from the screen.**
