# Resolving Conflicts (If Any)

- If there are **conflicts**:

  - GitHub will display the files with conflicts.

  - Review the conflicts in the **index.html** file by the help of the application team and framework team and manually resolve them to ensure the code merges correctly.

  - Once resolved, commit the changes, and proceed with the merge process.
