Part D — App Branching and Merging

D.1 — Why Branch?​

A Branch creates a parallel ACTIVE copy of your application. Use it when you need to work on next-phase enhancements while the current version is being tested in QA. The branch is fully isolated — changes in the branch don't affect the main RELEASED version until you explicitly merge them.

ScenarioUse Branch?
Bug fix on the current version in QA❌ No — fix directly in main, create new minor version
New feature development while current is in QA✅ Yes — branch from current ACTIVE version
Experimental UI changes for client review✅ Yes — branch lets you show without committing to main

D.2 — Step-by-Step: Creating a Branch​

1Go to Procify Workspace Hub → My Apps
Locate customer_complaints_<prid>. The app must be in ACTIVE status to create a branch.
2Click Branch
In the app detail view, click the Branch button (visible only when status = ACTIVE).
The platform creates a new Branch Flavor automatically.
The branch version appears in the My Apps list with a branch indicator.
3Assign Users to the Branch
Click the branch version to open its detail.
Go to the Roles & Users tab → click Edit.
Assign ALL three test users and your developer account to their respective roles.
⚠ Users are NOT copied automatically from the parent — you must assign them manually in the branch.
4Develop in the Branch
Open Data Studio or Page Builder.
In the App dropdown, select the BRANCH version (not the main version).
Make your changes. Save and test independently.

D.3 — Branch Merge Workflow (Summary)​

When the branch is ready to be merged back into the main release cycle:

1Export Both ZIPs
Procify Workspace Hub → Export section.
Download ZIP of the main RELEASED version (Set 1) and the branch version (Set 2).
2Open App Compare & Merge
Procify Workspace Hub → App Compare & Merge.
Upload Set 1 (main) as Left and Set 2 (branch) as Right.
Click Compare.
3Review the Differences
The tool lists differences per component: entities, pages, queries, VH, menus, etc.
For each difference, select which version to keep: Set 1 (main), Set 2 (branch), or a Custom combination.
4Download Merged ZIP
Once all decisions are made, click Download to export the merged ZIP.
5Create New Version and Import
In Procify Workspace Hub, create a new Major or Minor version from the current RELEASED main version.
Import the merged ZIP into the new version.
Run Update Schema, Full Build, and test before releasing.
