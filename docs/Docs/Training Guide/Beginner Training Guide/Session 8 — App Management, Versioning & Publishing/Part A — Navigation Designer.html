Part A — Navigation Designer

A.1 — What Is the Navigation Designer?​

The Navigation Designer (also called Menu Builder per PROC-26419) is the tool you use to define the navigation structure visible to users in the hamburger menu of the application at runtime. Without a menu entry, users cannot navigate between screens — they would need to know URLs manually.

Access path: Running app → Hamburger menu (☰) → App Builder → Navigation Designer.

A.2 — Menu Fields Reference​

FieldDescriptionRules / Notes
Menu IDUnique identifier for this menu item.ONLY alphanumeric + underscores. NO hyphens ( - ). NO spaces. Case-sensitive. Wrong: mn-complaints. Correct: mn_complaints.
Target PagePage ID the menu item navigates to.Use the Value Help (VH) icon to pick from existing pages. Do NOT type the page ID manually.
Menu TextLabel shown to the user in the hamburger menu.Keep it short. Title case. Localisation supported.
Page ParametersOptional JSON for navTo params (SS, QP, D, Mode).Leave blank for simple page nav. Not needed for the Complaints entry.
Menu IconSAP icon URI displayed alongside the text.Format: sap-icon://<icon-name>. Must be a valid SAP UI5 icon name. Example: sap-icon://customer-and-contacts.
SequenceSort order in the menu. Lower number = appears first.Use multiples of 10 (10, 20, 30) to leave room for future items.
RolesRestrict visibility to specific application roles.Leave BLANK = visible to ALL roles. Fill role IDs (comma-separated) to restrict.
Test NavigationValidates the menu item navigates correctly.Always click Test Navigation before saving — catches target page errors early.

A.3 — BRD Menu Structure to Implement​

Menu FieldValue
Menu IDmn_complaints
Target Pagep_complaints (select from VH)
Menu TextComplaints
Menu Iconsap-icon://customer-and-contacts
Sequence10
RolesLeave blank — visible to ALL roles (Employee, Manager, IT Team)
Page ParametersNot required — leave blank

A.4 — Step-by-Step: Creating the Application Menu​

1Open Navigation Designer
In the running application, open the hamburger menu (☰ top-left). Go to App Builder → Navigation Designer.
2Select the Application
In the App dropdown at the top of the Navigation Designer, select customer_complaints_<prid>.
Click the Edit button (pencil icon ✏). The menu table becomes editable.
3Add a Header Group
Click Add (+) → Add Header.
Fill in:
Menu ID: hdr_main
Menu Text: Main
Sequence: 10
Roles: leave blank
Click OK.
(A Header groups child items visually in the menu.)
4Add the Complaints Child Menu Item
Select the hdr_main row in the table.
Click Add (+) → Add Child.
Fill in:
Menu ID: mn_complaints
Target Page: p_complaints (use VH picker)
Menu Text: Complaints
Menu Icon: sap-icon://customer-and-contacts
Sequence: 10
Roles: leave blank
Click OK.
5Test the Navigation
Click Test Navigation on the mn_complaints row.
p_complaints should open correctly.
If a 'Page not found' error appears — check that the Target Page is exactly p_complaints (no typos).
6Save
Click the Save button (disk icon 💾).
Wait for the busy dialog to close. A success toast confirms the menu is saved.
7Verify with All Personas
Log out and log in separately as emp_<prid>, mgr_<prid>, and it_<prid>.
In each session, open the hamburger menu. The 'Complaints' item must be visible and navigate to p_complaints for ALL three test users.
⚠ Important
Common Navigation Designer Mistakes
Hyphen in Menu ID: mn-complaints causes the item to save but NEVER appear in the app. Always use underscore: mn_complaints.
Typing Target Page manually: Always use the VH picker. Manual typos cause silent navigation failures.
Saving without testing: Always click 'Test Navigation' before saving. It catches missing pages early.
Role restriction accident: If the menu item is set to a specific role, other personas cannot see it. Leave Roles blank for all-role visibility.
