IPA build with Organization Developer Account

3.1.Bundle ID creation using Firebase​

3.1.1.Firebase account access​

  • Get the Firebase account access from the infra team.

  • Select the Go to Console.

  • Once you are inside your Firebase project screen, you can create a new project or you can use the existing one (click on Add Project to create a new project). Here we are using the existing one.

Note: In case you want to create a new project contact the infra team.

3.1.2.Create a new bundle ID​

  • Click on the Create button as shown below.

  • Select the ios from the platform list as shown below.

  • Fill in the bundle ID as shown below.

  • Download the GoogleService-Info.plist as shown below.

  • Click the next button as shown below.

  • Click the next button as shown below.

  • Click on the Continue to Console button.

  • Click the button as shown below to see all the bundle IDs.

  • Click on the setting icon button of your bundle ID to see the details as shown below.

  • Click on the Cloud Messaging tab for configuration.

  • Click on Upload to continue with the APNs Authentication Key(For the FCM plugin).

  • Upload the APN auth key as shown below (For the FCM plugin).

  • Fill in all the Key Id and Team Id and click on upload (For FCM plugin).

  • Once the above things are done your bundle ID is ready with the FCM configuration. (For FCM plugin).

3.2. Key ID and Team ID creation using Apple developer account​

3.2.1.Apple developer account access​

  • Get the Apple developer account details from the infra team.

  • Give the Two-factor authentication from Piyush PatilSir.

  • Click on Trust in this browser.

  • Select the Account from the tab.

  • Now you have the Apple developer account.

3.2.2.Key ID Creation​

  • Click the keys as shown below

  • Click the ( + ) button to create a new key as shown below.

  • Fill in the key name field and select the APN service, then click the Continue button.

  • Click the Register button to continue as shown below.

  • Copy the key ID, download the APN auth key and then, click on the Done button to complete the process.

  • You can check the new key in your key list as shown below.

3.2.3.Team ID Creation​

  • Click the ( + ) button to create a new team ID in the Identifiers screen.

  • Select the App IDs and click continue.

  • Select App as type and continue.

  • Fill in the Description field and bundle ID as shown below.

  • Select the Push Notifications and click the Continue button.

  • Copy the App ID prefix and click Register to complete the process.

  • You can search for the identifier as shown below.

3.2.4.Add UDID​

3.2.4.1.Get the UDID of the device​

  • Connect the ios device to the mac.

  • Sync the device.

  • Check the device is visible as shown below. If it’s not visible, select the song option from the menu and select the device again.

  • Double-click the iPad Pro - 123.49.gb to see the UDID.

3.2.4.2.How to Add UDID for project​

  • Go to the Device screen which is present inside the developer screen and click the (+) to add a new UDID.

  • Fill in your UDID and device name as shown below and click continue.

  • Check the details and click Register to register the device.

  • Click the done button to finish the process.

  • Now you can see your UDID in the list.

3.3.Build IOS project​

3.3.1.Get a working project​

  • Get the working sample project from here. The structure of the project looks as shown below.

3.3.2.Change the config file​

  • Go to config.xml. Open the XML file with TextEdit as shown in the image below.

  • In the config.xml file,

  • Orange highlight: Bundle ID/App ID can be changed here.

  • Yellow Highlight: This will be the Project Name.

  • Red Highlight: This depicts the App description. App defining name.

If you aren't making any changes, proceed with the build. However, if you're making any changes to the config.xml, be sure to modify and save it first.

3.3.3.Remove the platform​

  • Put the following command in the terminal window.

  • Orange: sudo -s current directory to root directory.

  • Green: chmod -R 777 .: This gives the read and write access

  • Blue: Cordova platforms: when you want to check the platform details.

  • Yellow: Cordova platform rm ios: this is for removing the platform.

Note: After entering sudo -s in the terminal, you'll be prompted for a password. Enter the system password in that field (Highlighted with red).

3.3.4.Add the platform​

  • Once you remove the platform, add the new one as shown below.

  • Orange Highlight:cordova platform add ios@7 ,the command to add platform.

  • Blue Highlight: This highlight is used to make you notice that you have added the correct iOS version.

3.4.Create IPA file​

3.4.1.Change the archive type​

  • As shown below, navigate to the Scheme screen.

  • Change the Archive build configuration to "Debug" as shown below, then click the close button.

3.4.2.Archive and create the IPA file​

  • Click on Archive.

  • Click on the Distribute app.

  • Select the Development option and click the next button.

  • Select all compatible device variants from the list and click on the next button.

  • Select the Automatically manage signing and click the next button.

  • Click the Export button to export to your folder.

  • Select the folder location and export it.

  • Check your folder; your IPA is ready.
