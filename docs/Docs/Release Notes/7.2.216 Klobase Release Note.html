This Release contains new features/changes for the below areas of the framework.

Note for the App Team Developers/Managers​

There is an ask from Google Play store to upgrade our Mobile App to latest API versions and existing App will be stopped from 1-Sep-2025. To address this there is a Mobile App update also released and it works on Klobase version 7-2-208 or higher.

The new Mobile App version will be uploaded to Play store by 5-Sep-2025

***Please make sure all the systems are upgraded to klobase version 7-2-208 or higher.

Reference: https://support.google.com/googleplay/android-developer/answer/11926878

2. Module: Dev Tools​

Below are the list of new features/bug fixes developed as a part of the release in this module.

FeatureAdoptionTool & Short Description
PROC-18584 UI Editor: Device need to be added in "Preview In" and existing needs correctionNoTools - UI Editor
Enhanced preview functionality by adding new device options to "Preview In" feature and corrected existing device preview settings for better responsive design testing.
Status: **Tested**
PROC-20605 UI Editor: Coping a existing page to a different App, changes the id of the controls copied to previous id+"_copy01"NoTools - UI Editor
Fixed issue where copying pages between apps resulted in incorrect control ID naming convention. Controls now maintain proper unique IDs when copied across applications.
Status: **Tested**
PROC-20474 Wizard: Update through wizard is not working for child entityNoTools - UI Editor
Resolved wizard update functionality for child entities. Updates to child entities through wizard interface now work correctly.
Status: **Tested**
PROC-19513 Primary key update should be restricted (UI editor)NoTools - UI Editor
Implemented restrictions on primary key updates in UI editor to prevent data integrity issues and maintain referential consistency.
Status: **Tested**
PROC-21284 Please update the package.json "libphonenumber-js": "^1.12.9" to the vsixNoBOL - Private Node (VS Code)
Updated libphonenumber-js package to version 1.12.9 in VSIX package for improved phone number validation and formatting capabilities.
Status: **Tested**
PROC-19721 Feature Request – Read-Only Code Checkout for a UserNoBOL - Private Node (VS Code)
Developers can access and analyze the application's code and structure to debug or investigate issues. However, code modifications are restricted unless the app is explicitly assigned to them. Only developers have permission to save files within the app. While referencing logic is allowed during custom development, existing workflows can be explored safely without the risk of unintended changes.
Status: **Tested**

Below are the list of new features/bug fixes developed as a part of the release in this module.

FeatureAdoptionTool & Short Description
PROC-18928 Transport : check should be added to confirm the klobase version in configNoBOL - Transport
Added version validation checks in transport configuration to ensure Klobase version compatibility during transport operations.
Status: **Done - Closed**
PROC-20336 VH :- Unable to add deleted values again in vhc, throwing error "Cannot read properties of null (reading '_pm')"NoBOL
Deleted VH entries with the same key can now be re-added, even if the key differs only by case.

PROC-20067 Excel upload and download for object type and rollup status in BOL editorNoBOL
Implemented Excel import/export functionality for object type and rollup status configurations in BOL editor, enabling bulk data management.
Status: **Tested**
PROC-19104 If build is taking very long time, then it should be marked as FAILEDNoBOL - Flavor Build
Added timeout mechanism for build processes. Builds exceeding specified time limits (e.g., 20 minutes) are now automatically marked as FAILED.
Status: **Tested**
PROC-20917 Bol Editor: Where used List, if no data found show it in a messageBoxNoBOL Editor
Enhanced user experience by displaying an informative message box when "Where Used" functionality finds no references instead of showing empty tables.
Status: **Tested**
PROC-20748 VH Config: Adding duplicate keys(id) should be supportedNoBOL
Enhanced Value Help configuration to allow duplicate key IDs when business requirements necessitate multiple entries with same identifier.
Status: **Tested**
PROC-19496 BOL Editor :- If we are creating or copying any status or config entity and navigating to any other entity it is getting removed from where we addedNoBOL Editor
Fixed data persistence issue where newly created or copied status/config entities were lost when navigating between entities in BOL Editor.
Status: **Tested**
PROC-20281 Column Sort with loadAll true needs to be handledNoBOL
Enhanced column sorting functionality to properly handle scenarios where loadAll property is set to true, ensuring consistent data ordering.
Status: **Tested**
PROC-20265 Column Filter is not working based on the Key-IDNoBOL, KloTouch
Fixed column filtering functionality to work correctly with Key-ID based filtering, improving data search and display capabilities.
Status: **Tested**
PROC-20821 oData - Error Handling is not properNoBOL
Improved oData error handling mechanisms to provide better error messages and graceful failure recovery for data service operations.
Status: **Tested**
PROC-21117 Addition of VH Config Item: Please add "KloRemarks" as key and text in base_control propertytype p_vh_id value helpNoBOL
Added "KloRemarks" configuration item to base_control property type value help for enhanced control documentation and metadata management.
Status: **Tested**
PROC-17273 In app notificationNoBOL
Implemented in-app notification system for real-time user communication and system status updates within the application interface.
Status: **Tested**
