FeatureAdoptionTool & Short Description
PROC-16925
Excel upload and Download should be consistent in UI screen and Bol Editor
Tools:Bol Editor		NoExcel upload and download in both UI and BOL editor will now use the short label for column names. When downloading, the file will be saved with the property’s short label.
If a short label is unavailable, the property ID will be used instead. The property ID has been replaced with the short label for column names.

Below are the list of new features/bug fixes developed as a part of the release in this module.

FeatureAdoption docShort Description
PROC-15283
VH Consolidated phase 1
PROC-15284
VH Consolidated phase 2
Bol		NoValue Help (VH) is a feature in applications that offers a list of valid values for users to select from, ensuring only acceptable input is entered. New features are added for VH.
For more details Refer- VH guide
PROC-16889
Upgrading Node packages/libraries - Phase 1 - cleanup of Unused packages
Bol		NoCleaned up the package.json by removing unused packages and retaining only the packages that are actively being used.
PROC-16246
Review of the Behaviour in Upsert and Create APIs
BOL		NoWhen an empty string is set to a date or date-time property in createEntityP() and upsertEntityP(), it will now be set as null.
In DataTypeUtil.ts (getTypedPropVal()), if the data type is date and the value is an empty string, it will be converted to null.
PROC-14857
Node.js version upgrade to 22 (LTS)
BOL		YesUpgraded the Node.js version to 22.13.1. A new Procify IDE is now available for the upgraded Node version.

Attachment upload "From Gallery" option not available in IPA, only "Take Photo" and "Capture Video" and upload option is available
BOL		NoAdded a 'Browse' option to upload files in the popover for KloAttach on iOS, available in both preview and non-preview modes.
PROC-16662
Transport: New screen for script exection log (klobase & App)
BOL - Transport		NoIntroduced a screen to view scripts executed in the current landscape.
A screen (Migration Logs) is present under the sys monitor menu where you can find the scripts which are executed during the app movement.
For more details, refer to the documentation.
Details: Application Script Maintenance
PROC-16661
Transport: Scripts execution status while installing/upgrading the app
BOL - Transport		NoWhenever a new app or version containing a script is moved, the Transport will execute the script and display its status.
For more details, refer to the Transport
PROC-16489
Need to review the build process in case of BOL version downgrade
BOL - Flavor Build		NoImplemented standardized handling of Framework (FW) versions during build processes. Teams are advised to follow the defined guidelines to ensure consistency and compatibility across environments.
Refer:Publish or validate screen 7.0
PROC-16762
Zips generated during devBuild should contain d.ts (definition) files for proper intellisense in vs code.
BOL - Flavor Build		NoDefinition files for TypeScript (ts) have been added to the zip file generated during the devBuild process. After the devBuild, the cdn_app flavor zip will now include these definition files.
It is recommended that SAP-deployed applications use the zip from the cdn_app/release_build path zip for uploading to SAP after the prodBuild of the flavor
PROC-16952
Icon woff2 file is corrupting on build / save to repository
Bol -Private node(VS Code)		NoUsers can now save woff2 and other supported file formats, with a maximum size limit of 19 MB.
Details: Custom Icon Pool-User guide

On save of code, compilation errors, if any, to be shown and save to be restricted.

6. Module: KloTouch​

Below are the list of new features/bug fixes developed as a part of the release in this module.

FeatureAdoption docShort Description
PROC-15457
openUI5 library upgrade to latest version which has LTS(1.120.27)
KloTouch		NoUpgraded the openUI5 library from version 1.108.18 to 1.120.27, now used by the kloTouch runtime.
Refer: Release Note
Key Points
PROC-16742
UI Editor : Card Modeller improvements
KloTouch: UI Editor		NoThe busy indicator will no longer interrupt modeling while using the Tabular Modeler. Upon closing the dialog, any changes will be reflected on the screen. Resizing the detail tab will also resize the modeler. Additionally, restrictions have been added to prevent selecting the Modeler tab in the detail view, ensuring that changes in the modeler are not reverted.
PROC-16363
O2C: Adding Tooltip in Column Header
KloTouch		NoAdded a new 'Tooltip' property to KloGridItemConfig.ts.
The column header tooltip will now display the label if provided; otherwise, it will fall back to the shortLabel, or remain empty if neither is available.
