1. Overview​

1.1 What are the changes?​

This Release contains new features/changes for the below areas of the framework.

AreaHas Changed?Adoption Required?
Dev Tools (UI Editor, BOL editor, menu, Online Code editor, App Cache-Control)YesNo
Dev Config ToolsNoNo
UI ControlsYesNo
BOLYesNo
KloTouchYesNo
ADMYesNo
Account ConsoleYesYes
System AdminNoNo

1.2. Strategic Focus: For developers​

Developers have to follow below steps after the FW updates are installed;

  • Each landscape should generate a new version of their currently running flavors using the latest klobase version.

  • A new private node needs to be set up for further developments.
