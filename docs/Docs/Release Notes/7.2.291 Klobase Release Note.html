2. Module: Dev Tools​

Below are the list of new features/bug fixes developed as a part of the release in this module.

FeatureAdoptionTool & Short Description
PROC-23717 Access token recalculation should be allowed from transport without navigating to cockpit screenNoAdmin Tools Enhanced transport functionality to allow access token recalculation directly from transport interface without requiring navigation to cockpit screen. Simplifies token management workflow for administrators. Status: Tested
PROC-23397 Dev Tools: Permissions: Wrong permission added because the detail screen didn't refresh after new app selectionNoDev Tools Fixed issue where permission detail screen did not refresh when selecting different applications, causing permissions to be added to wrong apps. Detail subscreen now properly updates based on newly selected flavor. Status: Tested
PROC-24013 UI Editor: Show deprecated name also for object_page screentype similar to flexible_columnNoUI Editor Added deprecation indicator to object_page screentype in UI Editor, displaying as "Object Page (Deprecated)" similar to flexible_column. Users are now clearly informed that Tab screentype is recommended instead. Status: Tested
PROC-22690 If the screen type is set to Grid while creating the screen through the Wizard, configurations are still being created for auto_gridNoUI Editor Fixed UI Wizard to avoid creating auto_grid configurations when user explicitly selects Grid screentype during screen creation. Configurations now properly match user's selected screen type. Status: Tested

3. Module: UI Controls​

No features are developed as a part of the release in this module.

4. Module: BOL​

Below are the list of new features/bug fixes developed as a part of the release in this module.

FeatureAdoptionTool & Short Description
PROC-23903 Calendar: VH Values of CalendarView should be changed because the current values are wrongNoBOL Corrected Value Help values for CalendarView property. Changed from uppercase (Day, Month, Week, Work_Week) to lowercase (day, month, week, work_week) to match proper naming conventions. Status: Tested
PROC-23811 Config properties should be created for any entity if enabled only in child app instead of enabling in parent & child appsNoBOL Enhanced flavor inheritance to properly create config properties, object types, status fields and values when enabled only in child flavor, without requiring parent flavor enablement. Fixes issues where child-only configurations were not properly supported. Status: Tested
PROC-23759 Modelled query: when selecting same property multiple times with different aggregation, only one is being added in the transient entityNoBOL Fixed modelled query to properly create multiple properties in transient entity when same source property is selected with different aggregations (e.g., SUM, AVG, COUNT). All aggregated properties now correctly appear in transient entity. Status: Tested
PROC-23703 On deselect of mandatory ⭐ sign primary key is also getting deselectedNoBOL Fixed issue where toggling mandatory indicator on primary key field also deselected the primary key status, converting it to normal column. Primary key status now remains unchanged when modifying mandatory setting. Status: Tested
PROC-23690 BOL Editor: While saving a query, if it includes a property from a return entity, show a Warning messageNoBOL Editor Added warning message when saving query that includes properties from return entity: 'The added property is not in the parent entity and will not appear in the Data Browser.' Helps developers understand data browser limitations. Status: Tested
PROC-22938 Attachment: cleanupTempAndDeletedAttachments is failingNoBOL Fixed failure in cleanupTempAndDeletedAttachments scheduled job. Job now properly executes attachment cleanup operations for temporary and deleted attachments. Status: Tested
PROC-22750 Permission (Access control): in the permission group's entity permission screen, it doesn't filter based on ENABLED if entering the detail for the first time from the listNoTools - Other Fixed permission group entity permission screen to properly filter and display only ENABLED entities when first entering detail screen from list. Previously showed all entities regardless of enabled status on initial load. Status: Tested
PROC-21554 VSIX Save: Validation for entity file import in case of parent and childNoBOL - Private Node (VS Code) Enhanced VSIX extension validation for entity file imports in parent-child relationships. Properly validates that entity file extends correct entity_gen (child's entity_gen if present, otherwise parent's entity_gen). Status: Tested
PROC-20811 Where used list: Phase 2NoDev Tools Implemented Phase 2 of where-used list functionality in BOL Editor. Enhanced capability to track and display usage locations of BOL elements including entities, properties, queries, and value helps across the application. Status: Tested

5. Module: KloTouch​

Below are the list of new features/bug fixes developed as a part of the release in this module.

FeatureAdoptionTool & Short Description
PROC-23809 Calendar: Need a Property to Disable the Appointment Selection Popover in SinglePlanningCalendarNoKloTouch Added new property to disable appointment selection popover in SinglePlanningCalendar control. Provides flexibility to control popover behavior based on application requirements. Workaround using custom CSS is no longer needed. Status: Tested
PROC-23782 Default Grid Refresh Functionality Inconsistent With Expected BehaviourNoKloTouch Fixed grid refresh button behavior to properly clear column filters when advanced search is cleared. Previously, refresh button incorrectly retained column filter state even after filters were removed from UI. Status: Tested
PROC-23779 Pivot Modeller: In pivot Data source when clicking on any list item it is navigating to homepageNoKloTouch Fixed pivot data source screen navigation issue where clicking list item links caused navigation to homepage instead of opening detail section. List item navigation now correctly opens corresponding detail view. Status: Tested
PROC-23556 Timeline section Avatar line is showing in top of Advanced Search when openedNoKloTouch Fixed z-index layering issue where Timeline section avatar line appeared on top of Advanced Search dialog when both were present in same screen. Advanced Search now properly displays without visual artifacts from other screen sections. Status: Tested
PROC-23510 CardList: Description based fuzzy search is not workingNoKloTouch Implemented description-based fuzzy search functionality for CardList control in mobile mode. Users can now filter CardList records based on description field when fuzzy search is enabled in BOL Editor. Status: Tested
PROC-22669 Copying a page in UI Editor takes too long to processNoDevTools UI Editor Optimized page copy operation in UI Editor to significantly reduce processing time. Page duplication now completes faster, improving developer productivity when creating similar pages. Status: Tested
PROC-22319 CSS Customization Support on Application LayerNoKloTouch Added 'procify-app-container' CSS wrapper class to main application container in index.html. Enables application-specific styling customization without affecting standard OpenUI5 classes or requiring platform-level changes. Supports client-specific branding requirements. Status: Tested
PROC-21632 New Wizard Feedbacks: Error handling and performance improvementsNoDevTools UI Editor Fixed multiple issues in new screen creation wizard including: error resolution during Next button clicks, duplicate entry prevention in metadata, and improved performance for wizard operations. Screen creation through wizard now more stable and faster. Status: Tested

6. Module: ADM​

Below are the list of new features developed as a part of the release in this module.

FeatureAdoptionTool & Short Description
PROC-24017 Option to Navigate to the Scanner page from Login Page [Registration]NoBOL - Client ADM Added button for cleaning up the application data, eliminating need for users to delete and reinstall app to access scanner. Improves user experience during device registration process. Status: Tested
PROC-23884 Support user sign up without user entry in madm_user if it is maintained in configurationsNoBOL - Client ADM Implemented anonymous user signup capability when server configuration allows signup without pre-existing madm_user entry. Users can now self-register when anonymous signup is enabled in server settings. Anonymous_Registration_User_Guide.docx. Status: Tested
PROC-23247 TCT Mobile Application: Logging in automatically once the application is being killed or cache clearedNoBOL - Client ADM / Infra Fixed automatic re-login issue that occurred after app was killed or cache was cleared. Users now properly remain on login screen after app termination or cache clearing operations. Status: Tested
PROC-22363 Need to change the error msg if user is not signed up but trying to do forgot passwordNoBOL - Client ADM Enhanced error messaging for forgot password flow when user account doesn't exist. Provides clearer guidance to users attempting password recovery for non-existent accounts. Status: Tested
