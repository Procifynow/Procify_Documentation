FeatureAdoptionTool & Short Description

PROC-28143 BOL Node 512 MB : Query Execution node memory analysisNoProcify Data Studio Completed a memory analysis of the query execution node under the 512MB profile, reviewing garbage-collection timing after query execution across batching, large result-set, and parallel-request scenarios. Important Notes​

The following manual steps are required after taking the Klobase 7-2-350 update:

  1. api.json has changed — WildFly restart is mandatory on all target landscapes

  2. VSIX pipeline is run to publish new version

  3. Restart WildFly after all changes have been deployed

Please review all release notes between your current version and the latest one, as there may be important changes or adoptions in the interim.
