PROC-18515
UI Editor : Need custom color for background
Tools - UI Editor		NoTo apply CSS (e.g., background color) to an entire grid cell, follow these steps:
1. Add a user-defined class to a control within the grid section.
2.use :has Pseudo-class, and do required styling
Example: as given below:
td:has(.invAmountColorWholeCell) {
background: #0c8123;
}
Details: UI Editor- User Guide 7.0

PROC-12891
New Wizard User Feedbacks: Part1 and Part2: UI Editor
Tools - UI Editor		NoThis release introduces major upgrades to the Wizard, enabling code-free creation of intuitive, visually cohesive, and high-performance screens. With automated layout, data binding, component setup, and responsive design, teams can build fully interactive, production-ready screens faster.
Key improvements include the new Tiles control (replacing Card List) and support for page areas, boosting performance and layout flexibility. While new screens still have section limits, existing screens can now switch screen types for greater customization. These enhancements reflect top developer requests and significantly improve development efficiency on Procify.

Implementation of Copy and Paste Functionality in Role & Status for an Entity

Users can now copy entries from the Status and Config tables and paste them into the same or other entities' Status/Config tables.
This enhancement helps streamline the workflow, reduces manual effort, and improves overall performance.
Note: Robust validations are in place to detect and prevent duplicate entries, helping to minimize human error during the copy-paste process.

7. Module: ADM​

Below are the list of new features/bug fixes developed as a part of the release in this module.

FeatureAdoption docShort Description
PROC-19072
During registration , if the user has old registration in other device that will be deboarded , user should receive a consent popup
Client ADM		NoDuring registration, if the user has an active session that needs to be terminated, they will be prompted to provide consent. If the user agrees, the old session will be terminated; otherwise, the registration process will be halted.
If a user is configured to allow a maximum of 3 browser sessions, attempting to register a 4th session will trigger the deboarding of the oldest existing session. Any queued messages intended for the deboarded session will fail with the error: Source Endpoint is either deboarded or not found.

PROC-18856
O2C: Requirement for Session Persistence Across Tabs
BOL Client ADM		NoIf a user has an active session, opening the application in a new tab or window (within the same browser profile) won’t prompt for login again. However, if the user has logged out, any new tab, window, or external link (e.g., from an email) will require the user to log in again.
