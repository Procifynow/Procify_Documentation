7. Module: ADM​

Below are the list of new features/bug fixes developed as a part of the release in this tool.

FeatureAdoption docShort Description
PROC-12782
Need a clear cache all data api at clientGlobal level and local storage set item failed handling		NoIntegrated Rollbar logging to track errors that may occur while setting data in local storage. This will help us identify if users encounter any issues. Additionally, the team has implemented an API to allow the
clearing of all client-side data.
PROC-12415
Cordova iOS: Status bar coming white.		NoThe status bar in the iOS application was appearing white instead of the expected blue color. This issue was identified based on the Jira screenshot. The status bar color has now been corrected to blue as intended.)
PROC-12402
Cordova APK: Procify logo is coming oval shape.		NoIn Android application, Procify logo is coming oval shape instead of circle(logo was stretching) and is rectified.
PROC-12140
Parallel calls after token expiry SPEC		NoWhen the access token expires (401 error), multiple requests can trigger concurrent refresh attempts, causing a login redirect. We’ve fixed this by ensuring only one token refresh happens at a time.
PROC-10452
Handling multiuser default bolversion upgrade.		NoAfter upgrading to the default Klobase version, the application was getting corrupted on devices and browsers when more than one user was logged in. This issue was fixed by triggering the update for all endpoints except the active one, ensuring smooth operation across multiple users.
PROC-9886
Update require config failing to be handled		NoIf the update require config fails, an option to reinstall the application should be provided to the user. This ensures they can resolve any issues and restore the app to a working state.
PROC-9633
Parallel calls after token expiry		NoWhen the token expires, a refresh token call is made. Previously, multiple parallel refresh calls would trigger an unwanted page refresh. This was fixed by allowing parallel requests but ensuring only one refresh token call is made at a time.
PROC-11878
Generic App - Login - Scan QR functionality improvements		NoIn both APK & IPA ,Scan QR function is now enhanced with the upload from gallery feature.
