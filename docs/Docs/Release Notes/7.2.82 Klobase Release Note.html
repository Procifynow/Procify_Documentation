PROC-15286
Proper message should be displayed if there is no internet connection and user tries to do any action
Tool:UI Editor		NoIn the Ui Editor, if the internet connection is unavailable and any network calls are triggered, a proper message will be displayed to the user.
PROC-15238
BOL Editor : Inner join with same entity is not working properly
Tool:Bol Editor		NoWhen performing an inner join with the same entity, both aliases were initially the same, making differentiation impossible. The aliases have now been set correctly to allow proper differentiation.
PROC-15114
show the warning message if anyone is trying to start a job manually from a public node which is already in running state.
Tool: Job Scheduler		NoIn the job instance list, selecting multiple running jobs and clicking "Start Selected" prompts a warning about running new instances. Pressing "Ok" runs the job again, while "Cancel" prevents it.
In the job instance screen, clicking "Start" on a running job shows a similar warning. "Ok" reruns the job, and "Cancel" stops it.
PROC-14950
Job Log Screen Modifications
Tool: Job Scheduler		NoIn the Job Log, the status in the advanced search has been changed to a value help (VH), and a start date-based date range filter has been added. In the list view, a busy indicator is now included in the quick filter for better data loading, filter operations are added for each attribute header, all operations are based on the start date, and the refresh button has been repositioned correctly.
PROC-14814
version field should not be editable in active flavour.
Tool - Account Console		NoPreviously, the version could be changed in edit mode, but it is now non-editable. Users must select the version at the beginning of the app creation process.
PROC-15281
Increase the width of fuzzy search
Tool - Bol Editor		NoThe width of the fuzzy search has been increased. When focused, it will expand to take up the entire available space of the toolbar. When focus is lost, it will revert to its original width of 125px.
A new property, fuzzyWidth, has been added to the section toolbar, which accepts a CSS size.
PROC-15380
add device id in about page (device id will be present in local storage)
Tool - Admin Tools		NoIn the About page, device Id is present and can be seen.
PROC-15664
Log into the google log for the count of a single job multiple instance running number.
Tool: Job Scheduler		NoIn the job scheduler, the number of parallel instances running for a single job can be viewed in the Google log. Each time a job starts, a log entry is generated showing the parallel instance count for that job.
PROC-15261
Back button in Server Queue Monitor not working properly
Tool: Server Queue Monitor		NoPresently,in the Server Queue Monitor, clicking the back button now correctly returns users to the respective failed or success message list, instead of the "In Queue" tab.

5. Module: BOL​

Below are the list of new features/bug fixes developed as a part of the release in this module.

FeatureAdoption docShort Description
PROC-7491
Unhandled exceptions should also be printed in google logs		NoUnhandled rejections are now logged in Google logs, providing more detailed information.
PROC-15309
App sequence should be auto corrected during BUILD (via URL or UI screen)		NoDuring the build process, it is mandatory for the parent app to be built first, followed by the child app. However, if the users do not follow this build sequence, the app sequence will be automatically corrected during the build even if the user uses the app utility screen or build url.
PROC-12776
SaaS Setup in QA & Production Environment		YesA SaaS setup supports scalable servers, both horizontally (by adding more servers) and vertically (by upgrading existing servers), to handle high loads. When server demand increases, new servers can be added without disrupting normal operations, effectively reducing latency and maintaining smooth performance for users.
Details:Configuration changes for message processing
PROC-15433
The lower case should be done during the construction of the key. in unique validation		NoIn Bol Editor, Unique key validation should be case insensitive for string data.

Below are the list of new features/bug fixes developed as a part of the release in this module.

FeatureAdoption docShort Description
PROC-15496
KloTouch: Relative import correction		NoIn KloTouch, all relative imports have been updated to use absolute paths starting with the "klo" module instead of relative paths.

O2C: File Preview working for PNG, but not PDF		NoPreviously, PDF download was not available, but now PDFs can be downloaded on desktop, Android, and iOS devices.

7. Module: ADM​

Below are the list of new features/bug fixes developed as a part of the release in this module.

FeatureAdoption docShort Description
PROC-14652
Change push user default auth code to COMMON instead of FW DEV		NoThe default auth code for pushUser and pushUserGroup api have been changed to "COMMON" to streamline it with account console behaviour.
If user does not provide r_manage_grp parameter in the apis, by default the user or the user group will get created with auth code "COMMON"

8. Module: Account Console​

Below are the list of new features/bug fixes developed as a part of the release in this module.

FeatureAdoption docShort Description
PROC-14427
Branches should be allowed to created only from release version		NoPreviously, branches were created from the active app version, and there were no constraints when releasing an app.
In the current implementation, branches can only be created from the released version. Additionally, when releasing a child app, all parent flavors must be released first.

No features are developed as a part of the release in this module.

10. Module: Cordova​

Below are the list of new features/bug fixes developed as a part of the release in this module.

FeatureAdoption docShort Description
PROC-14257
Icon is getting loaded everytime on menu change		NoWhenever we navigated to a different menu, the icon was being downloaded, which caused delays. Since the icon was not necessary for the APKs, it has been removed to improve build efficiency.
