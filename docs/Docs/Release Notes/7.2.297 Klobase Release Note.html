4. Module: BOL​

Below are the list of new features/bug fixes developed as a part of the release in this module.

FeatureAdoptionTool & Short Description
PROC-24672 Raw sql changes for Business AINoBOL Implemented raw SQL support for Business AI. AI can send SQL/JSON which will be converted into corresponding BOL/Knex queries. Handles all scenarios including row-wise authorization and permissions. BOL regression testing passed. Status: Tested
PROC-24628 NestJS Pipeline ImprovementsNoBOL / Server - wildfly Fixed failing pipeline in klopass2025. Improved NestJS build and deployment process. Pipeline execution verified and passing. Status: Tested
PROC-24344 Compilation Errors Fix in Tools: BOL EditorNoBOL Editor Fixed compilation errors in BOL Editor. Comprehensive 6-hour testing completed. BOL Editor reliability and stability enhanced. Status: Tested
PROC-24302 BOL/ Metadata : Need to remove leading spaces for exit_id column in m_exits & m_queryeventsubscriptions tablesNoBOL Removed leading spaces in exit_id column in m_exits table. Removed leading spaces in exit_id column in m_queryeventsubscriptions table. Improved data consistency and query accuracy. Status: Tested
PROC-24139 DeepRefresh(refreshP(true)) is not fetching newly added entity data in relationNoBOL Fixed deepRefresh / refreshP(true) to fetch newly added entities in relations. Now properly fetches related entity sets even when initially empty. Handles both scenarios: existing relation data and empty relations. Status: Tested
PROC-23142 Filter Clause Value for entity property is going as string in queryNoBOL Fixed filter condition where property-to-property comparison was treated as string. Now correctly compares entity properties in WHERE clauses. Example: WHERE table1.column1 < table2.column2 (instead of treating as string literal). Status: Tested
PROC-23387 We need a sequence-order column for the query for sortingNoBOL Added dedicated seq_order field to queries. Enables predefined sorting order control. Replaces dependency on cust_id and booking_start_time for sorting. Status: Tested
PROC-24142 REL_25/49-51 BOL Editor :- Status VH not visible for below scenarioNoBOL / BOL Editor Fixed Status Value Help (VH) visibility issue in BOL Editor. VH entries now remain visible after deletion of other entries with same object type. Multiple VH configs with same object type now properly supported. Status: Tested
PROC-23907 REL_25/49-51 Attachment :- status of attachment in transaction table is not being fro TEMP to PERMANENT even after save for IPA,Browser,APK ALLNoBOL Fixed attachment status update issue in transaction table. Status now correctly changes from TEMP to PERMANENT after save. Applies to IPA, Browser, and APK. Prerequisite: Entity with Attachment Property and filesystem storage_type. Status: Tested
