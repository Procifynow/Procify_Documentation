App services :- change the flavor selection event to onchange
Tool:Admin Tools		NoUnder App Services,changed the flavor selection event from selectionchange to change.
The flavor selection event has been changed from selectionchange to change because the selectionchange event was being triggered when a selected flavor was removed manually.

Edit Permissions: Edit permissions for the job instance screen are now restricted to managers of the associated scheduled task.

5. Module: BOL​

Below are the list of new features/bug fixes developed as a part of the release in this module.

FeatureAdoption docShort Description
PROC-12776
SaaS Setup in QA & Production Environment
Bol- Middleware 		YesA SaaS setup supports scalable servers, both horizontally (by adding more servers) and vertically (by upgrading existing servers), to handle high loads. When server demand increases, new servers can be added without disrupting normal operations, effectively reducing latency and maintaining smooth performance for users.
Details:Configuration changes for message processing
PROC-15760
Deployment Incompatible change Errors are not notified on App Transport
Bol -Transport		NoIn Bol Transport,Incompatible changes have been addressed, and an option to force update the schema has been provided to continue with the transport process.
Details: Transport User Guide
PROC-14440
r_dependant_flavors of child flavors needs to be updated if parent flavor is being changed for a flavor
Bol -App Hierarchy		NoIf a parent flavor is added or removed from a flavor, all its child flavors need to be updated. To ensure that all flavors are published, the "Publish" option needs to be selected.
Details: App Hierarchy
PROC-14101
Generate Sequence button required
Bol -App Hierarchy		NoA new button, 'Generate Sequence,' has been added to generate the hierarchy sequence for the app.
This was introduced because, in some cases, the 'Save' function was not generating the sequence. The new button has been created in the UI under the App Hierarchy detail section and implemented in the controller file.
Details: App Hierarchy
PROC-13006
can improve the navigation of flavours while in edit mode of the job definition screen.
Bol -Scheduler		NoImproved navigation of flavors in edit mode.Previously, after canceling an app switch, the app selection area incorrectly displayed the second app instead of remaining on the current app. The fix ensures the correct app is always shown, enhancing the user experience and preventing confusion when navigating between apps.
PROC-15522
Unable to sort the data based on alias name.
Bol		NoFixed an issue where sorting data based on the alias name was not possible. The Sort Order functionality now allows properties of related or joined entities to be included by adding a join in the query. This ensures that the properties of the joined entity are correctly displayed under the respective entity tab in the Sort Order.
PROC-10241
Role & Auth pending changes
Bol		NoRuntime changes for permissions & row wise authorization are made where Permissions is a feature provided to control the access to application resources and Row-wise authorization is a security feature that restricts access to specific rows of entity data based on the user's permissions.
Details: Row wise authorization-User guide
