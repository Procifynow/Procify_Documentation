2. Module: Dev Tools​

Below are the list of new features/bug fixes developed as a part of the release in this module.

FeatureAdoptionTool & Short Description
PROC-17119
Introduce a merged status for App branches
Tools - App Merge		NoAfter a merge is completed, if the source is a branch, the user will be prompted to confirm whether they want to change the status to "Merged." If they agree, the status will be updated, which will result in the unassignment of the app from all users.
Additionally, after the merge, if the source is a branch, the user will be able to change the branch status to "Merged.
Details: App Merge
PROC-17120
App Branching Improvements Phase 2
Tools - App Merge		NoMerge Button: Label changed from "Merge" to "Save".
Properties Table:
•
•
Middle Table: "Status" column renamed to "Resolution Status".
Navigation: Blocked when there are unsaved changes.
Row Navigation: Replaced link navigation with row-based navigation.
Build Retry: 'Retry' is disabled if a build is already in progress (over 15 minutes).
Details: App Merge
PROC-16940
App merge Improvements Phase 2
Tools - Dev Tools(Except BOL and UI Editor)		NoDeveloped the App Merge Log screen to display records of previously completed merges, allowing users to review the details of past merge activities.
Details: App Merge
PROC-15919
Roles & Permissions Tools - Custom Permissions screen for roles & permission.		NoNew Screen – Permissions: This screen is used for creating and managing permission groups and configuring permissions. It is intended for development environments only and can be accessed via Dev Tools.
Details: Permissions - User Guide
PROC-15928
Roles & Permissions Tools - Entity Access tokens
Tools - Admin Tools		NoA new "Entity Access Tokens" menu has been added under the Access Control menu group. This screen allows users to view the access tokens of an application and includes a recalculate option to regenerate the tokens for users.
Details: Permissions - User Guide
PROC-17382
Roles & Permissions Tools - User Access tokens - screen for roles & permission
Tools - Admin Tools		NoAdded a new "User Access Tokens" menu under the "Access Control" section. This screen displays access tokens assigned to each user for an application's entities and includes a "Recalculate" button to refresh and reassign tokens for the selected app and its entities.
Details: Permissions - User Guide
PROC-17153
App Merger : It should not show Conflict for the deleted Items( both in source & Branch)
Tools - App Merge		NoIf entities, properties, screens, or other items are deleted in both the source and target, they will not be displayed on the App Merge screen.

6. Module: KloTouch​

Below are the list of new features/bug fixes developed as a part of the release in this module.

FeatureAdoption docShort Description
PROC-17214
Need error message when user selects invalid file type.
KloTouch		NoIn the kloAttach type of control, users will receive an error message upon selecting an invalid file type. That is, a file type not included in the allowed list.
PROC-16694
All FW dialogs should be compact (sapUiSizeCompact)
KloTouch		NoOpenUI5 offers two options for margin and padding:
•
•
Currently, all dialogs and popovers are set to "Cozy." Going forward, the framework will set all dialogs and popovers to "Compact"
(KloTouch screens are already using the compact option).
PROC-12905
Kloavatar random color
KloTouch;Tools - UI Editor		NoAssigned distinct background colors to avatars based on their titles, rather than initials, when backgroundColor is set to "Random".
Revised the background color logic for avatars by using avatar titles instead of initials when backgroundColor is set to "Random".
PROC-17204
new Control: KloSegmentedButton needed
KloTouch		NoKloSegmentedButton is a custom control that extends sap.m.SegmentedButton. It uses KloSegmentedButtonItem in its item aggregation, which supports data binding.
Details: KloSegmentedButton
PROC-16959
Issue with Navigation Affecting History Across Tabs
KloTouch		NoPreviously, when a user duplicated a tab and refreshed it, the system would display the most recently accessed screen across any tab.
Now, when a tab is duplicated and refreshed, the system retains the navigation history of that specific tab and displays the last screen viewed in that tab, rather than reflecting the latest screen accessed in other tabs.

7. Module: ADM​

Below are the list of new features/bug fixes developed as a part of the release in this module.

FeatureAdoption docShort Description
PROC-17245
FW Scheduler for device queue clean-up
Client ADM		NoA new method deboardInactiveUsersForScheduler(days: number = 15, channel: ChannelType = ChannelType.BOTH) has been added to the AdmUser2.ts file and the AdmServer class. This method deboards users based on the specified number of inactive days and the provided channel type.
Currently, a scheduler named deboardInactiveUsers is available in cockpit_6-0-59 that runs this method. If users wish to use the deboarding feature, they need to import this job and enable it accordingly.
