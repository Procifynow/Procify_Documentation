Below are the list of new features/bug fixes developed as a part of the release in this module.

FeatureAdoptionTool & Short Description
PROC-25230 Phase 1: Adding attachment to Email NotificationNoTools - Dev Tools (Notification Editor) Email notifications can now include file attachments in Phase 1 of the attachment feature. Users configuring notifications via the Notification Editor can attach files to outgoing emails, enabling richer notification content for end users. Status: Tested
PROC-24605 Tools Name ChangesNoTools - Dev Tools Updated menu names and screen titles of the framework tools to improve clarity and consistency, enhancing usability and creating a more cohesive user experience. This sheet references the updated names: LINK. Status: Tested
PROC-24489 Restrict App build in case of any validation errorsNoTools - UI Editor The application build process is now blocked when validation errors are present in screen configuration. Users attempting to build with unresolved validation errors will be prevented from proceeding, ensuring only valid configurations are deployed. Status: Tested

Status: Tested

4. Module: BOL​

Below are the list of new features/bug fixes developed as a part of the release in this module.

FeatureAdoptionTool & Short Description
PROC-25597 Node Cache Master BottleneckNoBOL / Server - Server The same node was acting as both a processing node and cache master, creating a bottleneck and causing significant delays. Implemented a dedicated Cache Master isolation so the cache master process runs separately from application processing nodes, improving throughput and response times. Status: Tested
PROC-25082 API Validation: System Endpoints should not get DEBOARDED from ADM APIsNoBOL Added API-level validation to prevent system-level endpoints (TENANT, SAP_LOCAL, SAP_ONLINE) from being deboarded via ADM APIs. Previously, these critical system endpoints could be inadvertently removed, causing platform instability. Status: Tested
PROC-24945 Middleware: Implement retry logic for failed messages in case of deadlockNoBOL - Middleware Enhanced middleware resilience: Messages now automatically retry up to 3 times with 2 seconds of delay by default when encountering database deadlock or lock timeout errors. The retry settings can be configured via config.json: "MiddlewareRetrySettings": {
"DeadlockRetryCount": 3,
"RetryDelaySeconds": 2
}
Document Link: Message Monitoring 7.0 User Guide - Point No. 5.
Status: Tested
PROC-24594 BOL Node 512 MB: Node Master Isolation (Cache/Middleware/Scheduler)NoBOL Isolated the BOL Node Master from serving application data. The Master node is now dedicated exclusively to orchestration tasks (Cache/Middleware/Scheduler), freeing application nodes to serve user requests without contention from master-level operations. Status: Done - Closed
PROC-24581 Add Validation or Info Message on change of Query Type to AggregateNoBOL Editor Added a validation/informational message when a developer changes a query type to Aggregate in the BOL Editor. Previously, switching query types could cause wizard failures due to column mismatches in transient return entities. The message now alerts developers to review their screen configuration before proceeding. Status: Tested
User Guide: BOL Editor - User Guide 7.0
PROC-24422 Updated child relations data not getting fetched when main list is refreshedNoBOL / KloTouch Fixed an issue where updated child entity data was not being fetched when the parent list was refreshed using the default refresh button on the section toolbar. Child relation data is now correctly reloaded on list refresh. Status: Tested
PROC-24281 Private Node: A popup should be shown when tokens are expiredNoBOL - Private Node (VS Code) A popup notification is now displayed to the developer when the session expires in the Private Node. Previously, session expiry caused silent failures. Users are now prompted to create a new private node session. Status: Tested
PROC-22651 Entity Relation ImprovementsNoBOL Fixed a behavior in aggregate relationships between entities where, if the relation mapping property in Table A was null, the system would fetch all records from Table B by default. This unrestricted fetch is now blocked, aligning with the expected relationship behavior. Status: Tested
PROC-22647 PROD: Transport Screen is not loading because adm flavor is assigned as a tester in the source landscapeNoTools - Other (Transport) Fixed transport screen loading issue where querying source system apps failed due to ADM flavor not assigned to transport users. The transport screen now loads correctly regardless of the adm flavor assignment to the transport user. Status: Tested

Important Notes​

Post-Update Action Required – Dedicated Cache Master:

Since the new dedicated Cache Master spawns a new process internally, after taking the Klobase update the following steps must be performed manually:

  1. Take Klobase update

  2. Stop the services

  3. Kill the Cache Master process

  4. Start the services
