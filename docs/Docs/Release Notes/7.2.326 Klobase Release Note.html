2. Module: BOL Editor / Dev Tools

Below are the new features, improvements, and bug fixes delivered in this release for BOL Editor and Dev Tools.

Issue No.DescriptionAdoption / Script
PROC-25909BOL Editor: Auto Number Behaviour Is Not Consistent
Fixed an inconsistency in the Auto Number field where generated numbers occasionally started from 1001 instead of the expected sequence. The auto-number generator now produces a reliable, consistent sequence.		N/A
PROC-25839Show Warning / Error If Two Properties Use the Same Label in the Same Entity
BOL Editor now raises a warning when two properties within the same entity share an identical label, preventing ambiguity at runtime and improving data quality during schema design.
User Guide: Data Studio- User Guide 7.0		N/A
PROC-26051Entity Creation via Excel Sheet: Support for Config VH Creation (s_status etc.)
The Excel-based entity creation utility now supports creation of config-type value helps (e.g. s_status) in addition to regular entities, significantly reducing manual setup steps for new entities.
User Guide: Data Studio- User Guide 7.0		N/A
PROC-23549Training: Incorrect Automatic Import When Typecasting Using Private Node Suggestion
Fixed the code editor's auto-import logic when accepting a typecast suggestion from Private Node. The incorrect import statement is no longer inserted; the correct module path is used.		N/A

3. Module: UI Editor / Wizard

Below are the improvements and bug fixes delivered in this release for UI Editor and Notification Modeler.

Issue No.DescriptionAdoption / Script
PROC-24424UI Editor Wizard: Integer/Decimal Column Headers and Cell Content Should Be Right-Aligned in Grid and Tree
In the UI Editor Wizard, columns configured with Integer or Decimal property types now correctly right-align both header text and cell content in Grid and Tree screen types, matching standard numerical display conventions.
Reference document : Page Builder- User Guide 7.0		N/A
PROC-26821Add Validation to Restrict Template ID Length to 25 Characters in Notification Modeler
The Notification Modeler now enforces a maximum length of 25 characters for Template IDs at validation time, preventing downstream processing errors caused by oversized template identifiers.		N/A

4. Module: kloReact / React Runtime

Below are the bug fixes and improvements delivered in this release for the kloReact / React runtime, covering both web and mobile UI issues.

Issue No.DescriptionAdoption / Script
PROC-26727kloReact APK/IPA: Notification Red Dot Not Removed After Marking All Notifications as Read
Fixed a defect in kloReact APK and IPA builds where the notification red dot badge persisted even after all notifications were marked as read, causing confusion for mobile users.		N/A
PROC-26726kloReact BOL Editor: Change Icon on VH Screen Does Not Open Icon Dialog
Resolved a bug where clicking the 'Change' icon button on the VH (Value Help) screen in the BOL Editor under a kloReact environment did not open the icon picker dialog.		N/A
PROC-26725kloReact: UI-Type VH Is Not Editable in Specific Scenario
Fixed a scenario in kloReact where a Value Help of UI type was rendered as read-only when it should have been editable, preventing users from updating the VH value.		N/A
PROC-26719kloReact: Upgrade Banner Click Throws Error as Alert
Resolved an issue where clicking the upgrade banner in kloReact displayed a JavaScript error as a browser alert popup instead of handling it gracefully.		N/A
PROC-26718kloReact: Menu Became Blank on Desktop During Parallel Mobile Testing with Same User
Fixed a race condition in kloReact where the desktop menu became blank when the same user account was simultaneously active in a mobile session, caused by conflicting menu state updates.		N/A
PROC-26716kloReact: Create Button Alignment and Checkbox Size Mismatch in User Collections
Corrected a CSS mismatch between kloTouch and kloReact runtime in the User Collections screen — the Create button alignment and individual check/tick-box size are now consistent.		N/A
PROC-26714kloReact: User Details Not Showing After Navigating to About Page Then Logging Out
Fixed an issue where navigating to the About page and then logging out caused user details to be absent on the next login, due to stale session state not being cleared.		N/A
PROC-26713kloReact: Incorrect Alignment on Login Page
Corrected layout alignment issues on the kloReact login page, ensuring consistent positioning across screen sizes and device types.		N/A
PROC-26158React Phase 01: SAP Icons Should Not Be Shown for React Flavors in Any Tool
SAP-specific icon sets are no longer displayed in Dev Tools for React-type flavors, as SAP icons are not applicable to React runtime environments.		N/A
PROC-25987React Phase 01: Delay Should Not Be Used for Loading kloTouch Files
Removed artificial delays used when loading kloTouch files in the React runtime. Files are now loaded via a proper event-driven mechanism, improving startup performance and reliability.		N/A
PROC-21063No Internet Connection Banner: UI Improvement
Improved icons, responsiveness and alignment of No Internet Connection and Upgrade banners for better display across mobile and desktop resolutions.		N/A
PROC-23390navByQuery Not Working in Mobile Application When Navigating with kloGuid Control
Fixed a bug preventing navByQuery from functioning correctly on mobile applications when navigation was triggered via a kloGuid control, restoring expected deep-navigation behaviour.		N/A

5. Module: BOL Node / Server / Middleware

Below are the improvements and bug fixes delivered in this release for BOL Node 512 MB, server-side message processing, and middleware.

Issue No.DescriptionAdoption / Script
PROC-24595BOL Node 512 MB: Middleware Message Dispatch
Messages are now correctly excluded from dispatch to dedicated nodes and master node for processing when running in the 512 MB BOL Node configuration, preventing unnecessary processing overhead.		N/A
PROC-24592BOL Node 512 MB: Server-Side Query Streaming (Rules / Scheduler / AppService)
Implemented server-side query streaming for Rules, Scheduler, and AppService executions in the 512 MB BOL Node environment, enabling efficient processing of large result sets without memory overflow.		N/A
PROC-25937Message Monitoring: Queries Need to Be Optimised
Optimised the server queue monitor queries that were causing slowdowns due to 3.1 million records in the ma_tenant_log_q table. Indexes and query refactoring significantly reduce monitor execution time.		N/A
PROC-26584More Than One Master Found: Service cacheMaster
Fixed a parallel election race condition in middleware where multiple nodes started simultaneously and each declared itself master. The election protocol now correctly ensures a single master is elected.		N/A

6. Module: Mobile (APK / IPA)

Below are the bug fixes delivered in this release for the mobile APK and IPA builds. Note: an APK/IPA rebuild is required for PROC-24144.

Issue No.DescriptionAdoption / Script
PROC-24144Unnecessary Permission Requests in APK for KloRemark and Document Upload
Removed spurious permission prompts in the Android APK: KloRemark no longer requests microphone permission on screen load without user interaction, and Document Upload no longer triggers unnecessary storage permissions. Both now request permissions only at the point of use.		APK/IPA rebuild required

7. Module: Account Console / Permissions / Notifications

Below are the improvements delivered in this release for Account Console role management and push notifications.

Issue No.DescriptionAdoption / Script
PROC-26524Enhancement: Enforce Default Permissions and Validation for New Roles
At DEV Systems, after a new role creation, a warning box will be shown on the screen, to inform the developers about maintaining the permissions for that new role, to avoid Access Denied scenario for the respective users belonging to that role.
Document: LINK .		N/A
PROC-25592Push Notification: Improvements
When a notification is clicked by a different user, the app shows a Switch User message with notification user details and switch information about switching accounts and possible unsaved data loss. If there are unsaved changes, an additional warning note is also displayed. Also, once the intended user logs back in, missed notifications can be reviewed anytime from the Notification Centre (🔔).
Document: LINK .		N/A

8. Module: Server-Side Pivot / Report / Chart

Below are the new features delivered in this release for PIVOT, REPORT, and CHART screen types.

Issue No.DescriptionAdoption / Script
PROC-25423Phase 01 Runtime: Server-Side Pivoting for PIVOT / REPORT / CHART Screens
Pivoting operations for PIVOT, REPORT, and CHART screen types are now executed server-side rather than on the client, significantly improving performance for large datasets and reducing browser memory usage.		N/A

9. Module: Business AI

Below are the new features delivered in this release for the Business AI module.

Issue No.DescriptionAdoption / Script
PROC-26816Business AI: Application Workflow Context Implementation — POC and Phase 1
Completed POC and Phase 1 implementation of application workflow context for Business AI. The AI assistant can now understand and reason about the workflow state of the current application, enabling context-aware suggestions.		N/A
PROC-26745Business AI: VH Query Suggestion Display to User
Business AI now surfaces Value Help query suggestions to the user during data entry. When a VH Query field requires idata, the AI fires a query matching on key or description and presents the best matches for user selection.		N/A
