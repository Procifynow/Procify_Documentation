4. Module: BOL​

Below are the list of new features/bug fixes developed as a part of the release in this module.

FeatureAdoptionTool & Short Description
PROC-25084 Attachment: cleanupTempAndDeletedAttachments is not deleting the deleted folder in S3NoBOL Fixed the cleanupTempAndDeletedAttachments scheduled job to properly delete the corresponding deleted folders in AWS S3 storage. Previously the job cleaned up database records but left orphaned S3 folders. Ensures complete S3 storage cleanup. Status: Tested
PROC-25081 Include User id in case the user doesn't have permission assigned while throwing errorNoBOL Enhanced permission error messages to include the affected User ID. Provides administrators and developers with directly actionable information to identify and resolve permission assignment issues faster. Status: Tested
PROC-24976 Unique key validation not thrown for parent unique key property when making the parent dirty in childNoBOL Fixed unique key validation to correctly trigger for parent entity unique key properties when the parent record is made dirty from within a child record context. Prevents duplicate key violations from being silently bypassed in parent-child entity hierarchies. Status: Tested
PROC-24934 txn.$SYSTEM.date is giving date in milliseconds instead of dateNoBOL Fixed txn.$SYSTEM.date system variable to return a properly formatted date value instead of a raw millisecond timestamp. Consumers of this system variable now receive consistent, human-readable date output without requiring manual conversion. Status: Tested Example : Tue Mar 10 2026 14:32:18 GMT+0530 (India Standard Time)
PROC-24814 DOC: Action Required – Update and Publish oData DocumentationNoBOL Updated and published the oData API documentation covering current endpoint specifications, supported query options, and usage guidelines. Ensures developers and integration partners have accurate and current reference material. Status: Done - Closed ODATA SERVICES User Guide
PROC-24810 Option to download Console, Network, Local/Session Storage etc. for Error AnalysisNoBOL Implemented a diagnostic download utility allowing users to export browser , Network logs, cache logs and Local/Session Storage data in a single action. Significantly accelerates error analysis and reduces back-and-forth during support escalations. Status: Tested
Click here for more details
PROC-24738 this.errors is coming undefined in serverside callbackNoBOL Fixed this.errors reference which was returning undefined inside server-side callback functions. Developers can now reliably use this.errors within server-side callbacks for validation and error propagation without runtime failures. Status: Tested
PROC-24591 BOL Node 512 MB: Permission recalculationNoBOL Optimized permission recalculation process to operate within the 512 MB BOL Node memory constraint. Prevents out-of-memory failures during permission recalculation on large landscapes. Status: Done - Closed
PROC-24590 BOL Node 512 MB: SaveEpApps optimizationNoBOL Optimized the SaveEpApps function to reduce memory consumption and execution time, ensuring reliable operation within 512 MB BOL Node environments. Resolves timeout and memory issues during EP App saves on constrained landscapes. Status: Done - Closed
PROC-24407 Using Microsoft AD for authentication instead of AWS CognitoNoBOL / Server Implemented support for Microsoft Active Directory (Azure AD) as an authentication provider, as an alternative to AWS Cognito. Enables enterprise customers using Microsoft identity infrastructure to authenticate directly without requiring AWS Cognito setup. Status: TestedSocial login azuread for NestJS configuration- User Guide
PROC-24200 VH: Server side call of getSuggestionItemsP() throws "Cannot read properties of undefined (reading _em)"NoBOL Fixed a runtime error in the Value Help server-side getSuggestionItemsP() call triggered when operating on system status properties. The undefined _em reference is now correctly resolved, preventing crashes during VH server-side suggestions for system status fields. Status: Tested
PROC-24075 Fix OnValidate() Function to Return ValidationError[] Instead of UndefinedNoBOL - Private Node (VS Code) Fixed the OnValidate() function type contract to return ValidationError[] instead of undefined when no errors are present. Eliminates type inconsistency issues for developers implementing server-side validation in VS Code private node extensions. Status: Tested
PROC-23826 Extend Date Qualifier to Support $Global System StringsNoBOL Extended the date qualifier functionality to accept $Global system string variables (e.g., $SYSTEM.date, $SYSTEM.time) as filter values. Allows dynamic, system-driven date filtering in queries without hardcoding date values. Status: Tested
PROC-23492 _mapKeys should be separate for VHsNoBOL - Isolating entity and Value Help caches, This prevents cache mixing when the same entity Value Help is used within the same entity screen.
Example: VH updates the cache after a Value Help load that overrides earlier query results. Status: Tested
PROC-22846 Transport should not allow pulling child flavor without pulling parent flavorNoBOL - Transport Added validation in Transport Manager to prevent pulling a child flavor to a target landscape if the corresponding parent flavor has not been pulled first. Prevents incomplete or inconsistent transport states in parent-child flavor setups. Status: Tested
PROC-22293 System Registry for Accounts Users via O2C prodNoBOL / Server Implemented System Registry support for Account Users operating via O2C (Order-to-Cash) production landscape. Enables proper user registration and tracking within the system registry for O2C-provisioned accounts. Status: Tested
PROC-22238 Support of Number Formatting for Price and QuantitiesNoBOL / KloTouch Introduced number formatting support for price and quantity type properties across both BOL and KloTouch layers. Developers can now configure locale-aware number formatting (thousands separator, decimal precision) for numeric fields representing monetary values and quantities. Status: Tested
PROC-21931 NestJs and Wildfly: API for decaching the api.json file detailsNoBOL / Server - NestJS & Wildfly Implemented a dedicated API endpoint for clearing the api.json file cache in both NestJS and Wildfly server configurations. Allows administrators to force cache refresh without requiring a full server restart, reducing downtime during configuration updates. Status: Tested
PROC-21640 PRD - O2C - Job scheduler screenNoBOL - Scheduler Fixes 1. Popup title corrected to display the appropriate title.
2. Job Instance GUID replaced with Job Description for better readability. 3. Enable action message corrected and changed from a toast notification to a message box. 4. Updating job details no longer resets the selection to the first index or selects another job.
Status: Tested
PROC-24580 Access Logs and Server Logs for NestJsNoBOL / Server - NestJS Implemented access log and server log generation support for the NestJS server runtime. Provides consistent logging parity with Wildfly, enabling structured access and error log capture for NestJS-based deployments.
Config Guide- User Guide- NESTJS server log and access log
Status: Tested
