For Application Team: App Utility Screen Enhancement

Please be aware of the important changes to the Publish and Validate process. The validation of the flavor will occur first, and if any metadata inconsistencies are detected, validation errors will be triggered, preventing the build from proceeding. The build can only continue once all metadata issues are corrected. Additionally, validation for multiple flavors is now supported. This is a critical change, and the app team should take note, as they will not be able to build the application until all validation errors are resolved.

5. Module: BOL​

Below are the list of new features/bug fixes developed as a part of the release in this tool.

FeatureAdoption docShort Description
PROC-10730
Entity JSON should have circular data validation.		NoIn bol editor a primary relation can only be established between child entities, while two different entities will have an aggregate relationship, not a primary one.
PROC-12988
many instance of scheduler is running problem		NoIn the job scheduler,if a job is already running and you click the start button, a message will say, "Job is already running, start cannot be initiated." Similarly, if you select a running job and click "Start Selected," a message will show, "Start cannot be initiated for the following job," and the other selected jobs will start.
PROC-11241
SEAM4: Unwanted Entity and Service call		NoIn the SAP server, some service calls like processRequestObject, getFCMClientConfig, alive, admUpdateAppStatus, and ValidateEndpoint aren't needed. However, these calls are required for the Klarion server.
As a solution, we'll check if the system is SAP. If it is, we'll skip these service calls. But if it's Klarion, we'll send all of them.
PROC-9272
Transport should ask whether to take shared flavor update or not		An option has been provided to move shared items, along with any items moved from DEV to QA or from QA to PRD.
Updated transport user guide maintaining shared flavor update as well.
PROC-7180
Issue with Deleting Line Items
in Procify		NoValidation for mandatory fields should only be triggered on save, not on delete. This means users can delete data without validation, but they must fill out all required fields before saving or submitting.
PROC-11182
Attachment is showing duplicate entry in google logger but save is working fine		NoThe upserEntityP method is used to update the data, preventing the occurrence of a duplicate entry by updating the existing record instead of throwing an error.
PROC-12886
Upgrade process P4		NoSome bootstrapped files, like index.html and fw-sw.js, were not getting updated during upgrades because they were cached on the client's device. Now, these files will be updated as well during each upgrade.
