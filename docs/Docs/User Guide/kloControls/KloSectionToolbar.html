KloSectionToolbar

Class: KloSectionToolbar

Overview​

Extended from sap.m.OverflowToolbar

Customised to add additional functionalities to the screens created by klotouch editor which would otherwise require complex coding in the controllers. Users can utilise the inbuilt functionalities of the KloSectionToolbar to add them to their screens. They get to configure the visibility of each of the actions available in it.

Framework Version Information​

6.0

Usage​

KloSectionToolbar can be used in all sections except the default section.

It is to be used if additional functionality is required for the subscreen like showing the title of the subscreen, adding additional actions and defining their functionality, and using the existing actions in the toolbar itself. In the page area, KloSectionToolbar and its aggregation KloAction can be used to add actions to it.

To add the toolbar, the user can right-click on the section or pagearea, and then click on the Add toolbar from the context menu.
