Overview

This document is a guide to “KloTriState” control.

TriState control is for searching attachment. It has three states as follows:

  • ON: attachment_id is not null

  • OFF: attachment_id is null

  • NA: do not add as search param (DEFAULT)

On state. (Indicates attachment “IS_NOT_NULL”)

Off state. (Indicates attachment “IS_NULL”)

Neutral state. (Indicates no search params set)

Properties​

NAME

TYPE

DEFAULT VALUE

DESCRIPTION

state

null

Default state of the control.( null, true, false)

type

attachment

Type of state check. (Ex. attachment, boolean)

defaultStateIcon

sap.ui.core.URI

sap-icon://question-mark

To set the default/null state icon.

falseStateIcon

sap.ui.core.URI

sap-icon://accept

To set the false state icon.

falseStateIcon

sap.ui.core.URI

sap-icon://decline

To set the true state icon.
