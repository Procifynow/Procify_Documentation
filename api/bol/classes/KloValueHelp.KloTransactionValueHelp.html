getSuggestionItemsP

  • getSuggestionItemsP(): Promise<KloEntitySet<KloEntity>>

  • Returns Promise<KloEntitySet<KloEntity>>

    Promise that resolves to a KloEntitySet containing the suggestion items

    Description

    Loads and returns the suggestion items for the value help. This method intelligently manages caching - it returns cached items if already loaded, otherwise it loads the suggestion items based on the configured query and value help type. The method also handles dependent property filtering and fuzzy search filtering.

    Example

    // Basic usage
    let suggestionItems = await valueHelp.getSuggestionItemsP();
    suggestionItems.forEach(item => {
        console.log("Key:", item[valueHelp._vhInfo.key]);
        console.log("Display:", item[valueHelp._vhInfo.displaytext]);
    });

    // With filtering
    valueHelp.suggestionItemsFilter = "ABC";
    let filteredItems = await valueHelp.getSuggestionItemsP();

    See

    • suggestionItems to get already loaded items without triggering a load
    • suggestionItemsFilter to set filtering criteria

    Inherited from KloValueHelp.getSuggestionItemsP

getValueHelp

  • getValueHelp(propertyName, vhInfo, parentProxy, flavor?, version?, txn?): Promise<KloValueHelp>

  • Parameters

    NameTypeAttributesDescription
    propertyNamestring

    The name of the property for which value help is required

    vhInfoany

    Either the value help ID string or a complete value help metadata object

    parentProxyKloEntity | KloQuery<KloEntity>

    The entity or query instance that owns the property

    flavorstring<Optional>

    Optional flavor name; if not provided, uses the parent's flavor

    versionstring<Optional>

    Optional version; if not provided, uses the parent's version

    txnKloTransaction<Optional>

    Optional transaction; if not provided, uses the parent's transaction

    Returns Promise<KloValueHelp>

    Promise that resolves to a fully initialized KloValueHelp instance

    Description

    Creates and initializes a value help instance manually for a specified entity property. This static method allows you to create value help objects programmatically when you need to work with value helps outside of the normal entity property binding flow.

    Example

    // Create value help for an entity property
    let customerVH = await KloValueHelp.getValueHelp(
        "customer_id",
        "vh_customers",
        orderEntity,
        "sales",
        "1.0",
        transaction
    );

    // Use the value help
    let suggestions = await customerVH.getSuggestionItemsP();
