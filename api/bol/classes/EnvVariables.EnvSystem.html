Accessors

appVars

  • get appVars(): any

  • Returns any

    Proxy object for application variables

    Description

    Gets the application variables proxy object for storing custom application data. This allows you to store and retrieve custom variables that persist across the application session. Variables are stored in a proxy object that synchronizes with the global application state.

    Example

    // Set a custom variable
    envSystem.appVars.customFlag = true;
    envSystem.appVars.userPreference = "dark_mode";

    // Get a custom variable
    let flag = envSystem.appVars.customFlag;
    console.log("Custom flag:", flag);

    Description

    Property to access the KloTransaction instance associated with the current environment system. This provides direct access to the transaction without calling a method.
