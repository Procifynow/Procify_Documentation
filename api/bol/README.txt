PROCIFY API reference (TypeDoc output) goes in this folder.

Copy the contents of the generated "bol" folder here, so that these files exist:

  static/api/bol/index.html
  static/api/bol/modules/EndpointBean.html
  static/api/bol/classes/...
  static/api/bol/enums/...
  static/api/bol/assets/...

Then the "API Document Link" menu and the Documentation page open the reference
from this site (/Procify_Documentation/api/bol/index.html).

Delete this README.txt once the files are in place.
